This page lists the US legal data actually ingested into Vaquill's `statutes_us`
corpus, jurisdiction by jurisdiction. Statute counts are queryable live from
`GET /statutes/states`; the per-corpus matrix below is a snapshot.

<Info>
  **Snapshot date: 2026-07-17.** Statute coverage is always live via
  `/statutes/states` and `/statutes/codes`. Regulations, constitutions, and
  court rules are an expanding set, refreshed weekly.
</Info>

## How to query a jurisdiction

```bash
# Live coverage with current section counts
curl https://api.vaquill.ai/api/v1/statutes/states \
  -H "Authorization: Bearer vq_key_..."

# Statutory codes for one state (e.g. Mississippi)
curl "https://api.vaquill.ai/api/v1/statutes/codes?state=ms" \
  -H "Authorization: Bearer vq_key_..."

# Search within a state
curl -X POST https://api.vaquill.ai/api/v1/statutes/search \
  -H "Authorization: Bearer vq_key_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "landlord retaliation", "corpusType": "STATE", "state": "ms"}'
```
