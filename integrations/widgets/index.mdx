There are three widget builds. Pick the one that fits your stack and the features you need.

<CardGroup cols={3}>
  <Card title="Embedded Chat Widget" href="/integrations/widgets/embedded-chat">
    Next.js 15 + TypeScript. Streaming responses, inline citations, US-pinned. Deploy on Vercel with one env var.
  </Card>
  <Card title="Docker Widget" href="/integrations/widgets/docker-widget">
    Python FastAPI backend + Vite frontend in one container. Floating or inline embed via script tag.
  </Card>
  <Card title="Widget Pro" href="/integrations/widgets/widget-pro">
    Multi-thread sidebar, voice mode (TTS + STT), gamification, cross-tab sync, configurable citation viewers.
  </Card>
</CardGroup>

## Feature comparison

| Feature | Embedded | Docker | Pro |
|---|---|---|---|
| **Framework** | Next.js 15 | FastAPI + Vite | Next.js 15 + React 19 |
| **Deploy target** | Vercel | Docker Compose | Vercel / Railway |
| **Streaming responses** | Yes (SSE) | No | Yes (SSE) |
| **Inline citation tooltips** | Yes | Yes | Yes |
| **Embed modes** | iframe | floating, inline | iframe, floating |
| **Single-file script embed** | No | Yes | Yes |
| **Jurisdiction** | US-pinned | Configurable | Configurable |
| **Persistence** | None | None | IndexedDB / localStorage |

Only Widget Pro has a multi-thread sidebar, voice mode (TTS and STT) and cross-tab sync.

## Embedding

Each build page has its own embed snippet and options:

- Floating button (Intercom-style) and inline embed: [Docker Widget](/integrations/widgets/docker-widget#embedding).
- iframe, for maximum isolation on any HTML page or CMS: [Embedded Chat](/integrations/widgets/embedded-chat#embedding).
- Single-file loader: [Widget Pro](/integrations/widgets/widget-pro#embedding).
