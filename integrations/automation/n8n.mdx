These templates run batch statute lookups from a Google Sheet. One is for [n8n](https://n8n.io) (open source, self-hostable) and one is for [Make.com](https://make.com) (cloud, no-code).

```
Google Sheet (queries) -> Vaquill statutes search API -> Google Sheet (matching sections)
```

Source: [github.com/Vaquill-AI/integrations/n8n](https://github.com/Vaquill-AI/integrations/tree/main/n8n).

## What you get

- `n8n-workflow.json`: import into any n8n instance
- `make-blueprint.json`: import into any Make.com scenario
- A trigger on new rows in a Google Sheet, with matching sections written back
- Retry on 429 and 5xx, and a stop on 402 (insufficient credits)
- Per-query scoping by corpus or state through the request body
- Paging for broad queries

Typical uses are batch statute search, due-diligence checklists, client-intake triage and scheduled monitoring.

## Prerequisites

1. A Vaquill AI account. Sign up at [app.vaquill.ai](https://app.vaquill.ai).
2. A Vaquill API key (`vq_key_...`). Generate one in Settings > API Keys. See [Authentication](/api-guide/authentication).
3. A Google account, for Google Sheets access.
4. An n8n instance (cloud or self-hosted) or a Make.com account.

## Google Sheet setup

Create a Google Sheet with the headers `query`, `results`, `citations`, `jurisdiction` and `status` in columns A to E of row 1.
Put your queries in column A. Leave B to E empty. The automation fills them in.

Example rows:

| query | results | citations | jurisdiction | status |
|---|---|---|---|---|
| civil action for deprivation of rights | *(filled by Vaquill AI)* | | | |
| motion to dismiss for failure to state a claim | *(filled by Vaquill AI)* | | | |
| overtime exemption for executive employees | *(filled by Vaquill AI)* | | | |

## Vaquill API reference

```
POST https://api.vaquill.ai/api/v1/us/statutes/search
Authorization: Bearer vq_key_YOUR_API_KEY
Content-Type: application/json
```

Request body:

```json
{
  "query": "civil action for deprivation of rights",
  "corpusType": "USC",
  "limit": 10
}
```

| Field | Type | Description |
|---|---|---|
| `query` | string | The statute search query |
| `corpusType` | string or array | Which corpus to search, for example `"USC"` or `"CFR"`. Omit it to search every corpus. |
| `state` | string or array | A state code such as `"ca"` or `"ny"` to restrict the search to that state |
| `limit` | integer | Maximum sections to return (page through larger result sets) |

The endpoint rejects unknown fields such as `jurisdiction`.

A trimmed successful response (200):

```json
{
  "data": {
    "results": [
      {
        "actId": "USC_T42_C21_S1983",
        "citation": "42 U.S.C. 1983",
        "title": "Civil action for deprivation of rights"
      }
    ],
    "count": 1
  },
  "meta": {
    "creditsConsumed": 4
  }
}
```

Each result has more fields than shown. See the [Statutes Search API reference](/api-reference/us-statutes/search-us-statutes-constitutions-court-rules-and-executive-actions) for the full response and filters, and [Errors](/api-guide/errors) for status codes.

## Quickstart

<Tabs>
<Tab title="n8n">

<Steps>
  <Step title="Import the workflow">
    1. Open your n8n instance (cloud or self-hosted)
    2. Go to **Workflows > Add Workflow**
    3. Click the three-dot menu (top right) > **Import from File**
    4. Upload `n8n-workflow.json` from the repo
  </Step>
  <Step title="Add the Google Sheets credential">
    1. Click the **New Query Added** node
    2. Under **Credential to connect with**, click **Create New Credential**
    3. Select **Google Sheets OAuth2 API**
    4. Complete the OAuth flow and save
  </Step>
  <Step title="Add the Vaquill API key credential">
    1. Click the **Vaquill Statutes Search** node
    2. Under **Credential to connect with**, click **Create New Credential**
    3. Select **Header Auth**
    4. Set:
       - **Name**: `Authorization`
       - **Value**: `Bearer vq_key_YOUR_ACTUAL_KEY`
    5. Save
  </Step>
  <Step title="Point at your sheet">
    On the **New Query Added**, **Write Answer to Sheet**, and **Write Error to Sheet** nodes, select your spreadsheet and sheet (for example `Sheet1`).
  </Step>
  <Step title="Test and activate">
    1. Add a test query to column A of your sheet
    2. Click **Test Workflow**
    3. Verify the matching sections appear in column B
    4. Toggle the workflow to **Active** for automatic processing
  </Step>
</Steps>

**Workflow shape**

```
[New Query Added] -> [Filter Unanswered] -> [Vaquill Statutes Search] -> [Extract Response] -> [Write Results]
                                                     |
                                                 (on error)
                                                     |
                                            [Insufficient Credits?]
                                              /              \
                                        (yes: 402)       (other error)
                                             |                |
                                     [Stop Workflow]   [Write Error to Sheet]
```

| Node | Purpose |
|---|---|
| **New Query Added** | Triggers on new rows in the Google Sheet |
| **Filter Unanswered** | Skips rows that already have an answer |
| **Vaquill Statutes Search** | Calls `/statutes/search`; retries automatically on 429 / 5xx |
| **Extract Response Fields** | Pulls `results`, `citation`, `code` from the JSON response |
| **Write Answer to Sheet** | Updates the original row with results |
| **Insufficient Credits?** | On 402, stops the workflow; on other errors, marks the row as `error` |

<Steps>
  <Step title="Import the blueprint">

  </Step>
  <Step title="Add your Vaquill API key">
    1. Click the second module (**Call Vaquill statutes search API**)

  </Step>
  <Step title="Wire the writer">
    1. Click the third module (**Write Results Back**)
    2. Verify the Google Sheets connection and select the same spreadsheet / sheet
    3. The response mapping is pre-configured:

       - Column C (citations): joined citations
       - Column D (jurisdiction): `{{2.data.jurisdiction}}`

  <Step title="Test and schedule">
    1. Click **Run once** to test
    2. Check the sheet for results
    3. Click **Schedule** to enable automatic runs (e.g. every 15 minutes)

## Configuration

### Scope by jurisdiction

Set `corpusType` to `"USC"` or `"CFR"` for federal sources. Set `state` (for example `"ca"`, `"ny"`, `"tx"`) to restrict the search to one state. See [API coverage](/api-guide/coverage) for what is held.

### Page through large result sets

For broad queries, raise the `limit` field and page through results:

```json
{
  "query": "overtime exemption for executive employees",
  "corpusType": "USC",
  "limit": 25,
  "offset": 0
}
```

Increase `offset` in steps of `limit` to fetch subsequent pages.

### Rate-limit handling

- n8n: the template retries on 429 and 5xx, up to 2 times at 5-second intervals.
- Make.com: for large batches, add a **Sleep** module (for example 2 seconds) between iterations, or enable the error handler with retry.

### Extending the workflow

Both templates can feed other nodes, such as Slack, email, Airtable or a webhook to your app.

## Deployment

| Option | Best for |
|---|---|
| n8n self-hosted (Docker) | Full data control and unlimited runs. Free, but you run the servers. |
| n8n Cloud | A managed UI with no servers. |
| Make.com | Cloud only. Counts each HTTP call and each sheet row read or written, so one search uses about 3 operations. |

The same `n8n-workflow.json` imports into both n8n options.

## Troubleshooting

| Problem | Cause | Fix |
|---|---|---|
| 401 Unauthorized | Invalid or missing API key | Verify the key starts with `vq_key_` and the `Bearer ` prefix is included |
| 402 Payment Required | No credits remaining | Top up at [app.vaquill.ai/settings/billing](https://app.vaquill.ai/settings/billing) |
| 429 Too Many Requests | Rate limit hit | Add delays between requests |
| Empty results | Query too vague or out of scope | Rephrase; check that `corpusType` and `state` are set correctly |
| Google Sheets auth error | OAuth token expired | Re-authenticate the Google Sheets connection |
| Workflow not triggering | Trigger not activated | In n8n, toggle the workflow to **Active**; in Make.com, click **Schedule** |
