Use Vaquill AI from Claude, ChatGPT, an IDE or a Google Sheet.
All integrations call the same [Vaquill statutes API](/api-reference/us-statutes/search-us-statutes-constitutions-court-rules-and-executive-actions). They are open source and can be self-hosted.

## Pick an integration

| If you want to... | Use |
|---|---|
| Search US statutes from Claude / Cursor / VS Code | [Vaquill MCP](/integrations/mcp/vaquill) |
| Batch-process legal questions from a Google Sheet | [n8n / Make.com](/integrations/automation/n8n) |

## Keys

One API key (`vq_key_...`) from your [dashboard](https://app.vaquill.ai/settings) works for all of them. The Claude connector signs in with OAuth instead.

## Build your own

To connect a tool we do not ship (Slack, Outlook, a CRM, an internal portal):

1. Generate a key in your [dashboard](https://app.vaquill.ai/settings).
2. `POST /api/v1/us/statutes/search` with `{ "query": "..." }` and `Authorization: Bearer vq_key_...`.
3. Show the returned results (citation, title, excerpt and `actId`).
4. Pass filters (`corpusType`, `state`, `code`) to narrow them.

See [Authentication](/api-guide/authentication) for key setup and [Errors](/api-guide/errors) for status-code handling.
