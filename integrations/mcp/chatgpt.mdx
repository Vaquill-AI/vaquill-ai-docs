The same MCP server that serves Claude also serves ChatGPT and Codex. It uses the same endpoint, credit balance and US primary-law corpus.

## Connect

```
https://mcp.vaquill.ai/mcp
```

Add it as a remote MCP server over Streamable HTTP. Leave any API key or header field empty. The endpoint uses OAuth 2.1, so you sign in with your Vaquill AI account.

In Codex and other terminal clients, register it as a remote MCP server the way that client documents, then finish the browser sign-in.

## The search and fetch pair

Research clients, including ChatGPT deep research and company-knowledge connectors, look for two tools named `search` and `fetch`. This server provides both:

| Tool | Returns |
| --- | --- |
| `search` | `{id, title, url}` records across every US corpus, ready to cite |
| `fetch` | `{id, title, text, url, metadata}` for one section, by `id`, source URL, or a Bluebook citation such as `42 U.S.C. 1983` |

If your client can call the typed tools, prefer them. `search_us_statutes` filters by jurisdiction, corpus, date and status. The generic pair cannot.

<Warning>
  `url` is always a non-empty string, because research clients show a citation only when it is present. Every result carries its official government source URL.
</Warning>

## Verify it works

A connected status does not prove the server works. Make one real call. The cheapest is free:

> "List statutes coverage for California."

`list_statutes_coverage` costs 0 credits.

## Costs

Each call is charged against your credit balance. Reads cost 1 to 6 credits. `list_statutes_coverage`, `get_credit_balance` and `get_pricing` are free. Each response reports `creditsConsumed`, and a backend failure returns `503` and is refunded.

New accounts include 1,000 free credits. See [pricing](https://www.vaquill.ai/legal-api) and [API coverage](/api-guide/coverage) for the corpora.
