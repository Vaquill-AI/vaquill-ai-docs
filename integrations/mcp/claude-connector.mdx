The Vaquill connector adds US primary law to Claude with a **Connect** button. You sign in with your Vaquill account. There is no API key to create or paste.
It is listed in the [Claude Connectors Directory](https://claude.ai/directory/vaquill-ai-primary-law) as Vaquill AI Primary Law.

<Note>
  This is the only path that works in Cowork. A Cowork session runs in an Anthropic cloud container that cannot see your machine's environment, so a key in `~/.zshenv` cannot reach it. See the [comparison below](#which-one-should-i-use).
</Note>

## Connect

<Steps>
  <Step title="Open Claude's connector settings">
    On claude.ai: **Settings > Connectors > Add custom connector**.
    On Claude Desktop: the same **Connectors** panel.
    In Claude Code: run `claude mcp add --transport http --scope user vaquill https://mcp.vaquill.ai/mcp`, then `/mcp` to sign in.
  </Step>
  <Step title="Paste the URL">
    ```
    https://mcp.vaquill.ai/mcp
    ```

    Leave the API key and header fields empty. This URL uses OAuth, and a key pasted here is ignored.
  </Step>
  <Step title="Click Connect and approve">
    Claude sends you to Vaquill to sign in, then shows a consent screen. Approve it once. Reconnecting later does not ask again.
  </Step>
  <Step title="Make one live call">
    See [Verify it works](#verify-it-works).
  </Step>
</Steps>

## Verify it works

<Warning>
  <ConnectedNotProof />
</Warning>

Make one live call. The cheapest is free:

> "Use Vaquill to list statutes coverage for California."

`list_statutes_coverage` costs 0 credits. A normal response means you are done. An error means the connection has no identity. Reconnect and finish the consent screen.

Test each surface separately. Claude Code, claude.ai, Claude Desktop and Cowork use different code paths. Cowork loads its tools at session start, so start a new Cowork session instead of reloading.

## API key and billing

The connector uses the same credit balance as any other key.

<Accordion title="What happens to my API key">
  On your first connect, Vaquill creates a key for the connector and holds it server-side. Claude never sees it.

  - It does not count against your plan's key cap (2 active keys, or 5 on Business).
  - It does not appear in your dashboard key list, so you cannot revoke it there. Disconnecting in Claude stops Claude using it. Contact support to revoke it outright.
</Accordion>

## Scope: United States only

The connector serves the US corpus. See [API coverage](/api-guide/coverage) for what it holds.

The India corpus is not available over OAuth. It is served at `https://mcp.vaquill.ai/in/mcp` and needs a `vq_key_` API key in an `Authorization` header. See [Vaquill MCP](/integrations/mcp/vaquill#india-mount) for setup.

## Which one should I use

| | Connector | [Plugin](/integrations/mcp/claude-plugin) | [API key](/integrations/mcp/vaquill) |
| --- | --- | --- | --- |
| Setup | Click Connect | Install from marketplace, set an env var | Paste a key or header |
| Works in Cowork | Yes | No | No |
| Works in claude.ai / Desktop | Yes | n/a | Yes |
| Works in Claude Code | Yes | Yes | Yes |
| Works in Cursor, VS Code, Windsurf | No | No | Yes |
| Adds slash commands and a research skill | No | Yes | No |
| Key to manage | None | Yours | Yours |

Use the connector for Claude with no setup, and in Cowork. Use the plugin in Claude Code for the ten slash commands and the research skill. Use an API key for any client that is not Claude.

Running the connector and the plugin together adds nothing. Both expose the same tools.

## Troubleshooting

| Symptom | Cause |
| --- | --- |
| Connected, but every tool call fails | The connection has no identity. Reconnect and finish the consent screen |
| Asked to approve twice | Approve the second one. It is remembered from then on |
| 402 on every call | Out of credits. Top up in the console |
| 429 | Rate limited. Honor `Retry-After` |
| 503 | Backend unavailable. The call was refunded. Retry later |
| Tools missing in Cowork | Start a new session |
| An empty result | An outage returns 503, so an empty 200 is a real answer. Check [coverage](/api-guide/coverage) before assuming no law exists |
