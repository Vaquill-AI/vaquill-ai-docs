The `primary-law` plugin adds the Vaquill MCP server, ten research commands and a research skill to Claude Code. It installs from the Vaquill plugin marketplace.

Source: [github.com/Vaquill-AI/vaquill-plugin](https://github.com/Vaquill-AI/vaquill-plugin).

<Note>
  The plugin works in Claude Code only. For Cowork, claude.ai and Claude Desktop, use the [Claude Connector](/integrations/mcp/claude-connector).
</Note>

## Install

<Steps>
  <Step title="Add the marketplace">
    ```bash
    /plugin marketplace add Vaquill-AI/vaquill-plugin
    ```
  </Step>
  <Step title="Install the plugin">
    ```bash
    /plugin install primary-law
    ```
  </Step>
  <Step title="Set your API key where a new shell will see it">
    The plugin reads `VAQUILL_API_KEY` from the process environment. Create a key at [app.vaquill.ai/settings](https://app.vaquill.ai/settings) under **API Keys**, then:

    ```bash
    echo 'export VAQUILL_API_KEY="vq_key_YOUR_KEY"' >> ~/.zshenv
    chmod 600 ~/.zshenv
    ```

    Use `~/.zshenv`, not `~/.zshrc`. Only `~/.zshenv` is read by every zsh invocation. On bash, use `~/.bash_profile` plus `~/.bashrc`.

    Check that a new shell sees it:

    ```bash
    zsh -c 'echo ${VAQUILL_API_KEY:+PRESENT}'    # must print PRESENT
    ```

    Use the `:+` form. `${VAR:-...}` prints the key itself.
  </Step>
  <Step title="Fully quit and relaunch Claude Code">
    Claude Code reads the environment once, at process start. `/reload`, reconnecting MCP servers, a new session in the same window and reinstalling the plugin do not pick up a new variable.

    Quit with `/exit` or Ctrl+D, then run `claude` again. `pgrep -f claude` must return a different pid than before.
  </Step>
  <Step title="Make one live call">
    See [Verify it works](#verify-it-works).
  </Step>
</Steps>

Never write the key into `.mcp.json`, a committed `.env`, or any file under version control.

## Verify it works

<Warning>
  <ConnectedNotProof />

  This is true even with no `Authorization` header, an unexpanded `${VAQUILL_API_KEY}` template or an invalid key. `claude mcp list` showing `Connected` proves nothing about the key.
</Warning>

Make one live call. The cheapest is free:

> "Use Vaquill to list statutes coverage for California."

`list_statutes_coverage` costs 0 credits. A 401 means the key never reached the server. A normal response means setup is done.

## Commands

The plugin adds ten slash commands.

| Command | What it does |
| --- | --- |
| `/research` | Find the controlling US law on a question, answering only from the text the tools return |
| `/verify-citations` | Check every citation in a file, selection or pasted text against the official source text |
| `/as-of` | Read a section as it stood on a given date |
| `/changed` | List what changed in a corpus or jurisdiction since a date |
| `/authority` | Trace the link between a statute and its implementing regulations, in either direction |
| `/compare-states` | Compare how states word the same rule |
| `/coverage` | Show what Vaquill holds for a jurisdiction |
| `/guidance` | Find federal agency guidance on a topic and how much weight it carries |
| `/adjudications` | Search federal administrative adjudications |
| `/rulemaking` | Track a Federal Register rulemaking: proposed, final, and when comments close |

## The research skill

The plugin also includes a `us-statute-research` skill. Claude loads it when a question calls for primary law. It covers how to scope a search and when to resolve a citation first. It also covers why an empty result is more often a malformed `act_id` than a gap in coverage.

## Key caps and rotation

- Business allows 5 active keys. Every other plan allows 2. The console Playground can create a key, so one integration key plus Playground use can reach a cap of 2.
- Business can create the new key before revoking the old one. Other plans must revoke first and accept downtime.

A key created by the [Claude Connector](/integrations/mcp/claude-connector) does not count against the cap.

## Troubleshooting

| Symptom | Cause |
| --- | --- |
| 401 on every tool | Key missing, malformed, or the `Bearer ` prefix was dropped |
| 401 right after revoking a key | Key validation is cached for about 60 seconds |
| 401 with a healthy `/mcp` | The variable never reached the process. Check that `pgrep -f claude` changed after relaunch |
| 402 | Out of credits. Top up in the console |
| 429 | Rate limited. Honor `Retry-After`. `X-RateLimit-Limit` under-reports on Business keys |
| 503 | Backend unavailable. The call was refunded. Retry later |
| Tools missing entirely | The server failed to connect. Check `/mcp` before blaming the key |
| Nothing works in Cowork | Expected. Use the [connector](/integrations/mcp/claude-connector) |

An outage returns 503, so an empty 200 is a real answer, not an auth problem.
