The [Model Context Protocol](https://modelcontextprotocol.io) lets AI assistants call external tools. The Vaquill MCP exposes Vaquill's US statute corpus: the US Code, the CFR, all 50 state statute codes, the U.S. Constitution, the Federal Rules, and Executive Orders.

## What it covers

The Vaquill MCP serves Vaquill's statute corpus: 273,787 federal sections (US Code 54,855 sections across 53 titles, CFR 218,932 sections across 49 titles) plus roughly 1.3M state sections, for 1.6M+ statute sections total. Corpus is the 2024 edition and refreshes monthly.

Use the Vaquill MCP when you want your AI assistant to search and pull statute text by citation, code, and section across federal and all 50 state codes.

## Supported clients

The server works with any MCP-compatible client. Tested with:

- Claude Desktop
- Claude Code
- Claude.ai web (remote MCP support)
- Cursor
- VS Code (GitHub Copilot)
- Windsurf
- ChatGPT Desktop
- Continue
- Any HTTP-MCP or stdio-MCP client

## Hosted vs self-hosted

| Server | Hosted endpoint | Self-host |
|---|---|---|
| Vaquill MCP | `https://mcp.vaquill.ai/s/<your-key>` | `uvx vaquill-mcp` |

Hosted is the fastest path: paste a URL into your client and start using the tools. Self-hosting gives you control over rate limits, audit logging, and network egress.

## Authentication model

| Server | What you provide | How |
|---|---|---|
| Vaquill MCP | Vaquill API key (`vq_key_...`) | Header (`Authorization: Bearer ...`) or path token |
