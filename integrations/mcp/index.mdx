The [Model Context Protocol](https://modelcontextprotocol.io) lets AI assistants call external tools. Vaquill publishes three MCP servers covering US, Canadian, and Indian legal data, plus a meta-server for our own corpus.

## Which one should I use?

| If you want... | Use |
|---|---|
| One MCP that covers US + India + Canada with Vaquill's RAG | [Vaquill MCP](/integrations/mcp/vaquill) |
| Direct, unmediated access to the CourtListener API surface | [CourtListener MCP](/integrations/mcp/courtlistener) |
| Direct, unmediated access to the CanLII API surface | [CanLII MCP](/integrations/mcp/canlii) |

The Vaquill MCP is the highest-level interface - it adds retrieval, ranking, and answer synthesis on top of upstream sources. The CourtListener and CanLII MCPs forward your request directly to the upstream API so you get the full feature surface that each provider publishes (every filter, every field, every endpoint). Use the upstream MCPs when you want exact, unmediated access to what the source publishes; use Vaquill MCP when you want an AI-grounded answer or a cross-jurisdiction interface. CourtListener is operated by the [Free Law Project](https://free.law/) - a US 501(c)(3) non-profit; please consider [supporting their work](https://free.law/donate/).

All three servers work with any MCP-compatible client. Tested with:

- Cursor
- VS Code (GitHub Copilot)
- Windsurf
- ChatGPT Desktop
- Continue
- Any HTTP-MCP or stdio-MCP client

## Hosted vs self-hosted

| Server | Hosted endpoint | Self-host |
|---|---|---|
| Vaquill MCP | `https://mcp.vaquill.ai/s/<your-key>` | `uvx vaquill-mcp` |
| CourtListener MCP | `https://courtlistener-mcp.vaquill.ai/mcp/` | Docker / `uv run` |
| CanLII MCP | `https://canlii-mcp.vaquill.ai/mcp` | Docker / Node / Cloudflare Workers |

Hosted is the fastest path - paste a URL into your client and start using the tools. Self-hosting gives you control over rate limits, audit logging, and network egress.

## Authentication model

The three servers handle credentials differently:

| Server | What you provide | How |
|---|---|---|
| Vaquill MCP | Vaquill API key (`vq_key_...`) | Header (`Authorization: Bearer ...`) or path token |
| CourtListener MCP | Your own CourtListener token | Per-request header (`X-CourtListener-Token`) - BYOK |
| CanLII MCP | Your own CanLII API key + MCP gate token | Two headers - BYOK |

BYOK ("bring your own key") means Vaquill never sees or stores your upstream credential. The hosted endpoint forwards your key on every request.
