The [Model Context Protocol](https://modelcontextprotocol.io) lets AI assistants call external tools. The Vaquill MCP exposes Vaquill AI's US primary-law corpus: the US Code, the CFR, every state and territory statutory code, state and federal regulations, court rules, constitutions, agency guidance and adjudications, session laws and the Federal Register, plus the law-change alert tools.

There are two Vaquill MCP servers, and they expose completely different things.

</Note>

The two share no credential and no host. A statutes key is refused by the Workspace server and the reverse is also true, so pick the one that matches what you want the assistant to reach.

## What it covers

The Vaquill MCP is built from the Developer API's own OpenAPI document, so it reaches **the whole US corpus, not just statutes**: the US Code and every state and territory statutory code, the CFR and state administrative regulations, court rules, state and federal constitutions, agency guidance and adjudications, session laws and the Federal Register. It also carries the law-change alert tools. Every corpus is ingested from its own official source and re-pulled on a recurring cycle - daily for the CFR, a weekly check for a new annual US Code edition, and every 7 days or monthly for a state depending on how it publishes its code. See [API Coverage](/api-guide/coverage) for the live matrix and current counts.

Use the Vaquill MCP when you want your AI assistant to search primary law, resolve a citation to an exact provision, pull authoritative text to ground an answer, read a section as it stood on a past date, or watch a body of law for changes.

## Supported clients

The server works with any MCP-compatible client. Tested with:

- Claude Desktop
- Claude Code
- Claude.ai web (remote MCP support)
- Cursor
- VS Code (GitHub Copilot)
- Windsurf
- ChatGPT Desktop
- Continue
- Any HTTP-MCP or stdio-MCP client

## Hosted vs self-hosted

| Server | Hosted endpoint | Self-host |
|---|---|---|
| Vaquill MCP | `https://mcp.vaquill.ai/s/<your-key>` | `uvx vaquill-mcp` |

Hosted is the fastest path: paste a URL into your client and start using the tools. Self-hosting gives you control over rate limits, audit logging, and network egress.

## Authentication model

| Server | What you provide | How |
|---|---|---|
| Vaquill MCP | Vaquill API key (`vq_key_...`) | Header (`Authorization: Bearer ...`) or path token |
