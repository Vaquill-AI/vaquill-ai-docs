The [Model Context Protocol](https://modelcontextprotocol.io) lets AI assistants call external tools. The Vaquill MCP exposes Vaquill AI's US primary-law corpus: the US Code, the CFR, every state and territory statutory code, state and federal regulations, court rules, constitutions, agency guidance and adjudications, session laws and the Federal Register, plus the law-change alert tools.

The Vaquill MCP is available three ways: as a Claude connector, as a Claude Code plugin, and as a key-based server for any other MCP client. All three reach the same US primary-law tools.

## What it covers

The Vaquill MCP is built from the Developer API's own OpenAPI document, so it reaches the whole US corpus, and statutes are only part of it. See [API Coverage](/api-guide/coverage) for the live matrix and current counts.

Use it to have an assistant search primary law, resolve a citation to an exact provision, pull authoritative text to ground an answer, or read a section as it stood on a past date.

<Accordion title="How often the corpora refresh">
  Every corpus is ingested from its own official source and re-pulled on a recurring cycle: daily for the CFR, a weekly check for a new annual US Code edition, and every 7 days or monthly for a state, depending on how it publishes its code. The [coverage page](/api-guide/coverage) is the source of truth if this drifts.
</Accordion>

## Supported clients

The server works with any MCP-compatible client. Tested with:

- Claude Desktop
- Claude Code
- Claude.ai web (remote MCP support)
- Cursor
- VS Code (GitHub Copilot)
- Windsurf
- ChatGPT Desktop
- Continue
- Any HTTP-MCP or stdio-MCP client

## Hosted vs self-hosted

The hosted server is at `https://mcp.vaquill.ai/mcp` (OAuth) or takes a Bearer key (`Authorization: Bearer vq_key_...`). Self-host with `uvx vaquill-mcp`.
Hosted is the fastest path. Paste a URL into your client and the tools appear. Self-hosting gives you control over rate limits, audit logging and network egress.
See [Vaquill MCP](/integrations/mcp/vaquill#authentication) for the key options and [Authentication](/api-guide/authentication) for the full model.
