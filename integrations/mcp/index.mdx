The [Model Context Protocol](https://modelcontextprotocol.io) lets AI assistants call external tools. The Vaquill MCP gives an assistant access to US primary law. That includes the US Code, the CFR, state and territory codes, regulations, court rules, constitutions, agency guidance, session laws and the Federal Register.

You can use it as a Claude connector, as a Claude Code plugin, or as a key-based server for any other MCP client. All three reach the same tools.

## What it covers

The whole US corpus, not only statutes. See [API Coverage](/api-guide/coverage) for the current matrix.

Use it to search primary law, resolve a citation, get source text for an answer, or read a section as of a past date.

## Supported clients

It works with any MCP client. Tested with:

- Claude Desktop
- Claude Code
- Claude.ai web (remote MCP support)
- Cursor
- VS Code (GitHub Copilot)
- Windsurf
- ChatGPT Desktop
- Continue
- Any HTTP-MCP or stdio-MCP client

## Hosted or self-hosted

The hosted server is at `https://mcp.vaquill.ai/mcp`. It uses OAuth or a Bearer key (`Authorization: Bearer vq_key_...`). Paste the URL into your client and the tools appear.
To self-host, run `uvx vaquill-mcp`. That gives you control over rate limits, audit logging and network egress.
See [Vaquill MCP](/integrations/mcp/vaquill#authentication) for key options and [Authentication](/api-guide/authentication) for the full model.
