The [Model Context Protocol](https://modelcontextprotocol.io) lets AI assistants call external tools. The Vaquill MCP gives an assistant access to US primary law. That includes the US Code, the CFR, state and territory codes, regulations, court rules, constitutions, agency guidance, session laws, the Federal Register and case law.

You can use it as a Claude connector, as a Claude Code plugin, or as a key-based server for any other MCP client. All three reach the same tools.

## Which server do I add?

Vaquill runs three separate MCP servers. Add each one you need as its own connector.

| What you need | Server URL | How to authenticate |
| --- | --- | --- |
| [US primary law and case law](/integrations/mcp/vaquill#quickstart) | `https://mcp.vaquill.ai/mcp` | Sign in with a Vaquill account, or send `Authorization: Bearer vq_key_...` |
| [India primary law and case law](/integrations/mcp/vaquill#india-server): Central and State Acts, court judgments, tribunal records | `https://in-mcp.vaquill.ai/mcp` | Sign in with a Vaquill account, or send an API key as a bearer token |
| [India regulatory publications](/integrations/mcp/vaquill#regulatory-server): circulars, notifications and orders from regulators such as SEBI and RBI | `https://reg-mcp.vaquill.ai/mcp` | Sign in with a Vaquill account, or send an API key with the `reg:read` permission as a bearer token |

- You sign in once per server. The same API key and credit balance work on all three.
- Only the US server is listed in the Claude and ChatGPT directories. Add the India and regulatory servers as a custom connector by URL, for example **Settings > Connectors > Add custom connector** on claude.ai.
- Each server also accepts the key in the URL path, such as `https://in-mcp.vaquill.ai/s/vq_key_...`. On the US server that form still works but is deprecated, so send the key as a bearer header instead.

## What it covers

Statutes, regulations, case law and the rest of the US corpus. See [API Coverage](/api-guide/coverage) for the current matrix.

Use it to search primary law, resolve a citation, get source text for an answer, or read a section as of a past date.

## Supported clients

It works with any MCP client. Tested with:

- Claude Desktop
- Claude Code
- Claude.ai web (remote MCP support)
- Cursor
- VS Code (GitHub Copilot)
- Windsurf
- ChatGPT Desktop
- Continue
- Any HTTP-MCP or stdio-MCP client

## Hosted or self-hosted

The hosted server is at `https://mcp.vaquill.ai/mcp`. It uses OAuth or a Bearer key (`Authorization: Bearer vq_key_...`). Paste the URL into your client and the tools appear.
To self-host, run `uvx vaquill-mcp`. That gives you control over rate limits, audit logging and network egress.
See [Vaquill MCP](/integrations/mcp/vaquill#authentication) for key options and [Authentication](/api-guide/authentication) for the full model.
