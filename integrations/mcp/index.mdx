The [Model Context Protocol](https://modelcontextprotocol.io) lets AI assistants call external tools. The Vaquill MCP exposes Vaquill AI's US statute corpus: the US Code, the CFR, all 50 state statute codes plus DC and Puerto Rico, the U.S. Constitution, the Federal Rules, and Executive Orders.

There are two Vaquill MCP servers, and they expose completely different things.

<CardGroup cols={1}>
  <Card title="Vaquill MCP" icon="scale-balanced" href="/integrations/mcp/vaquill">
    Search and retrieve US statutes: the US Code, the CFR, all 50 state codes plus DC and Puerto Rico, the U.S. Constitution, the Federal Rules, and Executive Orders. Backed by the Vaquill statutes API.
  </Card>
  <Card title="Workspace MCP" icon="briefcase" href="/workspace-api/mcp">
    Your own matters, documents and work product: create matters, upload and read documents, run a playbook review, generate drafts, build matrices. Backed by the Legal Workspace API and gated by its scopes.
  </Card>
</CardGroup>

The two share no credential and no host. A statutes key is refused by the Workspace server and the reverse is also true, so pick the one that matches what you want the assistant to reach.

## What it covers

The Vaquill MCP serves Vaquill AI's statute corpus: 279,284 federal sections (US Code 60,170 sections across 53 titles, CFR 219,114 sections across 49 titles) plus roughly 2.0M state sections, for 2.2M+ statute sections total. Every corpus is ingested from its own official source and re-pulled on a recurring cycle - daily for the CFR, a weekly check for a new annual US Code edition, and every 7 days or monthly for a state depending on how it publishes its code. See [API Coverage](/api-guide/coverage) for the full matrix.

Use the Vaquill MCP when you want your AI assistant to search and pull statute text by citation, code, and section across federal law and all 50 state codes plus DC and Puerto Rico.

## Supported clients

The server works with any MCP-compatible client. Tested with:

- Claude Desktop
- Claude Code
- Claude.ai web (remote MCP support)
- Cursor
- VS Code (GitHub Copilot)
- Windsurf
- ChatGPT Desktop
- Continue
- Any HTTP-MCP or stdio-MCP client

## Hosted vs self-hosted

| Server | Hosted endpoint | Self-host |
|---|---|---|
| Vaquill MCP | `https://mcp.vaquill.ai/s/<your-key>` | `uvx vaquill-mcp` |

Hosted is the fastest path: paste a URL into your client and start using the tools. Self-hosting gives you control over rate limits, audit logging, and network egress.

## Authentication model

| Server | What you provide | How |
|---|---|---|
| Vaquill MCP | Vaquill API key (`vq_key_...`) | Header (`Authorization: Bearer ...`) or path token |
