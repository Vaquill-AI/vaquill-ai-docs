A running log of meaningful changes to the Vaquill platform, API, and docs. For breaking changes, watch the **Breaking** tag. For new endpoints, watch **API**. For platform features, watch **Product**.

<Update label="May 2026" description="Integrations relaunch" tags={["Docs", "Integrations"]}>
  - New **Integrations** tab covering MCP servers, chatbots, widgets, browser extensions, and automation templates.
  - First-party MCP server documented end-to-end: **Vaquill MCP**.
  - Six chatbot integrations: **Slack**, **Discord**, **Microsoft Teams**, **Telegram**, **WhatsApp**, **Signal** - each with platform setup, deployment recipes, and troubleshooting.
  - Three widget builds: **Embedded Chat** (Next.js, US-pinned), **Docker Widget** (FastAPI + Vite, floating or inline), **Widget Pro** (multi-thread sidebar, voice mode, gamification).
  - **Chrome Extension** and **n8n / Make.com** templates for browser-based research and Google Sheets automation.
  - All integration source code at [github.com/Vaquill-AI/integrations](https://github.com/Vaquill-AI/integrations) under MIT.
</Update>

<Update label="May 2026" description="US-first positioning" tags={["Docs", "Product"]}>
  - Documentation now leads with US coverage across every page. Citation formats default to Bluebook; examples use US statutes and case law (`42 USC 1983`, `FRCP 12(b)(6)`, `Marbury v. Madison`).
  - Jurisdiction coverage section in [Introduction](/introduction) updated: US federal and state case law.
  - All pricing standardized to USD.
</Update>

<Update label="May 2026" description="Citation network depth and treatment" tags={["API"]}>
  - [Traverse the citation network](/api-reference/citations/traverse-the-citation-network) now supports `depth` and `treatment` filters, top-citer aggregation, and a US-focused quickstart.
  - New [List US statutes coverage](/api-reference/statutes/list-us-statutes-coverage) and [List US state codes](/api-reference/statutes/list-us-state-codes) endpoints document the breadth of the US corpus.
</Update>

<Update label="April 2026" description="Pricing alignment with Dodo PAYG" tags={["API", "Pricing"]}>
  - API pricing aligned with the new pay-as-you-go billing flow. Each endpoint's credit cost is now documented inline on its API reference page.
  - Error codes consolidated across the platform - see [Errors](/errors).
</Update>

<Update label="April 2026" description="Dedicated MCP repo" tags={["Integrations"]}>
  - **Vaquill MCP** ([vaquill-mcp](https://github.com/Vaquill-AI/vaquill-mcp)) covers the full Vaquill corpus from any MCP-compatible client.
</Update>

<Update label="March 2026" description="Agent Mode, Skills, Memories, MCP Client" tags={["Product"]}>
  - [Agent Mode](/guides/agent-mode) - autonomous multi-tool research across up to 5 iterations.
  - [Skills](/guides/skills) - expert legal playbooks (Contract Review, NDA Triage, Risk Assessment, Privacy Compliance, Statute Analysis, Case Brief, Legal Notice, Contract Redlining).
  - [Memories](/guides/memories) - persistent cross-session memory that learns your jurisdiction, practice areas, and citation preferences.
  - [MCP Client](/guides/mcp-client) - connect external MCP servers (Notion, GitHub, custom) into Vaquill chats.
</Update>

<Update label="March 2026" description="Postman collection + Docs MCP" tags={["Docs"]}>
  - Public [Postman collection](https://www.postman.com/priyansh-57bdb803-2033693/vaquill-ai/collection/52997016-86d6f62d-ef53-4feb-85f4-915ef7a933cb/?action=share&creator=52997016) for the Vaquill API.
  - Docs MCP endpoint added so AI assistants can read these docs directly via [vaquill.ai/docs/mcp](https://vaquill.ai/docs/mcp).
</Update>
