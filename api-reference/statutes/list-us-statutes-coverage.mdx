---
openapi: GET /api/v1/statutes/states
description: "Discover the 50 US states + DC + federal jurisdictions covered by /statutes/search, each annotated with ingested section counts."
---

Use this endpoint to size your queries before calling
`/statutes/search`. Returns one row per state plus a `federal` entry
covering USC and CFR. Each row has `sectionCount` and a `hasData`
boolean. Cost: 1 credit per call.
