---
openapi: GET /api/v1/statutes/codes
description: "List the distinct codes (Penal, Civil, Health & Safety, Education, ...) ingested for a given US state. Returned actId values plug into /statutes/search filters."
---

Pass `state=tx` (or any 2-letter state code) to get the list of codes
we cover for that state, each annotated with its section count. Use
the returned `actId` values to scope `/statutes/search` calls.
