**`404`** `document-not-found`

No document with that id is usable here. The matter in the path was already authorized before this check ran, so the matter is the one part of the URL you did not get wrong. This also covers a document that is real and yours but filed under a different matter, and a document named more than once in the same request.

## What to do

List the documents in the matter you meant and take the id from there. Two other cases share this status and say so in `detail`: documents still being processed, which need their ingest operation to finish first, and documents uploaded by a person in the web app rather than through this API, which the comparison worker cannot open. Upload those through the API if you need to compare them.

Full error reference: [Errors](/workspace-api/concepts/errors)
