**`404`** `chat-not-found`

No conversation with that id is readable under the matter in the path. Another organization's conversation, a conversation under a different matter, a malformed id and a conversation you have already deleted all answer the same way, so the status code cannot be used to confirm that an id exists somewhere.

## What to do

List `GET /v1/matters/{matterId}/chats` for the matter you meant and take the id from there. A conversation belongs to one matter for its whole life, so if you have the id but not the matter, the conversation is under a different one than the path names.
