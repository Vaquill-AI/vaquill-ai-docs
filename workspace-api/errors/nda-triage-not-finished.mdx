**`409`** `nda-triage-not-finished`

The triage exists and has not produced anything to render yet. The `detail` names the status it is in.

## What to do

Poll the operation that started the triage, and export once it reports `succeeded`.

<Note>
Only the export refuses. Reading the triage itself answers `200` at any point, with the current status and an empty `criteria` list until there are criteria, because "not finished" is a true and useful answer to "show me the triage".
</Note>
