**`404`** `workflow-run-not-found`

No workflow run with that id is readable under the matter in the path. A run from another organization, a run under a different matter of yours, and a malformed id all come back the same, so the response cannot be used to discover runs you cannot already list.

## What to do

List the runs on the matter you meant, or keep the run id from the launch response together with its matter id. A workflow id and a run id are different things: the run id identifies one execution and looks like `wfr_` plus 32 hex characters, while the workflow id is the catalog slug you launched it from.
