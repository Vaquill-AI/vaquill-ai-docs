**`404`** `template-not-found`

No template with that id is available to your organization. It covers a template that never existed, one belonging to someone else, and one that has been archived or deleted and is therefore no longer runnable. Template run ids that cannot be resolved answer with this same type.

## What to do

List your templates and take a currently active id. A template that worked last month and fails today has almost certainly been archived in the web app, which is worth checking before you suspect the credential: nothing about a template being retired changes the answer, and reactivating it in the web app restores the call.

Full error reference: [Errors](/workspace-api/concepts/errors)
