**`401`** `wrong-product-credential`

You sent a key beginning `vq_key_`. That authenticates the Legal Data and API product, which is a separate product with a separate credential namespace. The Workspace API only accepts credentials beginning `vq_ws_`.

## What to do

Issue a workspace credential from the automation console and send that instead. The two never overlap in either direction, and neither one can be converted into the other. If your service holds both, check that whatever picks a credential is keyed on the host you are calling: this is the single most common mistake when a customer runs both products.
