Totals as of 2026-11-22.

A case record usually means one decision. Some decisions have more than one record, so counts are rounded down and can include repeats.

For live figures by court, call the courts endpoint. It is free.

```bash
curl "https://api.vaquill.ai/api/v1/us/courts?include=coverage&limit=100" \
  -H "Authorization: Bearer vq_key_..."
```

Add `include=coverage.years` for a count per year.
A listed court can have no decisions yet, so check its coverage before you rely on it.

## Court codes

Every court has a `courtId`, such as `US_FED_CA9` or `US_CA_SUPREME`.

- Search takes a list in `courtIds`.
- List endpoints take `courtId`.
- `state` includes federal trial and bankruptcy courts in that state. For state courts only, add `courtSystem` in search or pass `courtId` values to list endpoints.
- A court code does not include the separate codes of its districts. `US_TX_APPEALS` ends in 2019. For newer Texas appeals decisions, use the district codes from `GET /us/courts?state=TX&system=state&level=appellate`.

## Citation formats

[Citation lookup](/api-guide/case-law-search#look-up-citations) reads `volume reporter page`.
Spacing and periods in common reporters can vary: `U.S.`, `U. S.` and `US` are the same.

| Type | Example |
|---|---|
| US Reports | `410 U.S. 113` |
| Supreme Court Reporter | `93 S. Ct. 705` |
| Federal Reporter | `347 F.3d 1000` |
| Federal Supplement | `100 F. Supp. 3d 1` |
| Bankruptcy Reporter | `500 B.R. 1` |
| Regional reporter | `200 A.3d 153` |
| State reporter | `5 Cal. 5th 1` |
| Public domain citation | `2018 CO 12` |

In a list of citations, write a hyphenated citation with spaces: `2019 Ohio 1234`.
