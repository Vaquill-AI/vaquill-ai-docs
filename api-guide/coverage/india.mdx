**64,000+ acts and 745,000+ sections.**
That covers Union legislation, the legislation of every State and Union Territory we hold, and instruments issued by statutory regulators.

```bash
# The live answer. Free, and authoritative over this page.
curl https://api.vaquill.ai/api/v1/in/acts/coverage \
  -H "Authorization: Bearer vq_key_..."
```

No `corpusType` token from the US API applies here.

A section is one provision of an act.
Passage counts on `GET /acts/coverage` count retrieval chunks, not sections.

## What the corpus holds

`category` is the top-level split. Use it to filter a whole class of instrument.

| `category` | What it covers |
|---|---|
| `state` | Legislation of a State or Union Territory legislature, and state subordinate instruments. The `state` filter narrows within this. |
| `central` | Legislation of the Union Parliament, and central subordinate instruments made under it. |
| `regulatory` | Instruments issued by a statutory regulator (SEBI, RBI, MCA, TRAI, IRDAI and others). The `department` filter narrows within this. |

`repealed` and `spent` are also accepted as `category` values. They select acts the publisher records as repealed or spent in any jurisdiction.
`GET /acts/filters` returns the live filter values with counts, free.

Subordinate instruments are rules, regulations, notifications and orders made under a parent act.
Include or exclude them with the `isSubordinate` filter on search.
Each response that names a parent resolves it by title match and says so in `matchBasis`.

## Jurisdictions

The `state` column is the value to pass to the `state` filter.
Acts filed under `category=regulatory` have no jurisdiction value, so reach them with `category`.

## Amendments and status

Amendment history exists only for some acts.
Amendments are not applied to the served text, so there is no point-in-time text and no `asOf` parameter.
An empty event list can mean we have no record, so check the `coverage` block in the response.

`GET /acts/{actId}/status` returns three separate statements:

| Field | What it is |
|---|---|
| `publisherStatus` | The publisher's claim. |
| `servedStatus` | Our serving decision. For a retired act it is `retired`, with a reason. |
| `repealClaim` | The repeal record, including `commencementVerified`. |

`goodLawStatus` is `unknown` when a repeal claim is unverified or when `statusConflict` is `true`.

## Known limits

- Status is the publisher's claim. A recorded repeal may never have commenced.
- `GET /acts/list` is a dated snapshot. A newly added act may appear in `POST /acts/search` first.
- Citation-graph counts are a floor. Read `totalIsExact`.
- The IPC to BNS mapping is not exhaustive. An absent section is not necessarily unchanged.

## Endpoints and what they cost

All routes are under `https://api.vaquill.ai/api/v1/in/acts`.
`GET /api/v1/in/api-credits/pricing` is free and needs no key.
The Credits column is a snapshot. The live pricing matrix is authoritative.

<LivePricing />

| Route, under `/api/v1/in/acts` | Credits | What it answers |
|---|---:|---|
| `GET /coverage` | **0** | What the corpus holds, by jurisdiction, regulator and status. |
| `GET /filters` | **0** | The live filter values with counts. |
| `POST /search` | 2 | Search Central, State and regulator legislation down to the section. |
| `GET /list` | 1 | Browse enactments by jurisdiction, regulator, year and status. |
| `GET /{actId}/status` | 1 | Whether an enactment is still law, as three separate statements. |
| `GET /corresponding-provisions/{actCode}` | 1 | IPC to BNS and CrPC to BNSS section mapping. |
| `GET /{actId}/structure` | 2 | The act's table of contents. |
| `GET /{actId}/sections/{n}` | 2 | One provision: its citation, its place in the act, and what it refers to. |
| `GET /{actId}/sections/{n}/history` | 2 | Every amendment recorded against one provision. |
| `GET /{actId}/text` | 3 | The source text URLs for one enactment. |
| `GET /{actId}/sections/{n}/body` | 3 | The full text for one provision. Refunded when the text cannot be reproduced. |
| `GET /{actId}/amendments` | 5 | The amendment history recorded for a whole enactment. |
| `GET /resolve` | 2 | Resolve a citation string (`u/s 302 IPC`, `Art. 21 Constitution`) to provisions. |
| `POST /resolve` | 2 each | The same, in batch. An unresolvable citation is refunded. |
| `GET /{actId}/sections/{n}/references` | 2 | The acts and sections one provision cites. |
| `GET /{actId}/cited-by` | 2 | Provisions elsewhere in the corpus that cite this act. |
| `GET /{actId}/subordinate` | 2 | Rules, regulations and notifications recorded under this act. |
| `GET /{actId}/definitions` | 2 | Defined terms in the act, and the provisions that define them. |

A filter value outside the published vocabulary returns 422 and costs nothing.
The response names the parameter and the accepted values.

Full request and response shapes are in the India API Reference tab, generated from the [India OpenAPI document](https://api.vaquill.ai/in/openapi.json).

## Sources

The corpus is built from India Code, the Government of India's official repository of Central and State legislation, and from statutory regulators' own publications.
