Five `GET` routes, one key, one scope.

<Note>
  This is the **India regulatory publications** corpus: what regulators issued.
  For Indian acts and sections, see [India legislation](/api-guide/coverage/india).
  For matters before tribunals such as NCLT and ITAT, see [India tribunals](/api-guide/india-tribunals-quickstart).
</Note>

## 1. What is in there

`/sources` is free and needs no filters.

```bash
curl https://api.vaquill.ai/api/v1/in/reg/sources \
  -H "Authorization: Bearer vq_key_..."
```

You get every publisher, every source under it, and when each was last checked.
The ids it returns are what the other routes filter on.

## 2. Search

```bash
curl -G https://api.vaquill.ai/api/v1/in/reg/documents \
  -H "Authorization: Bearer vq_key_..." \
  --data-urlencode "q=insider trading" \
  --data-urlencode "docType=circular" \
  --data-urlencode "limit=20"
```

Filter by publisher, source, document type, and date.
To select more than one value, **repeat the key**:

```bash
  --data-urlencode "publisherId=4" \
  --data-urlencode "publisherId=7"
```

A comma list is rejected with a 400.

## 3. Read one document

```bash
curl "https://api.vaquill.ai/api/v1/in/reg/documents/48211/detail?include=body" \
  -H "Authorization: Bearer vq_key_..."
```

`include` accepts `body` (the extracted text), `versions` (every observation of this document) and `diff` (what changed between the last two).

## 4. Get the file

```bash
curl -L "https://api.vaquill.ai/api/v1/in/reg/documents/48211/file" \
  -H "Authorization: Bearer vq_key_..." \
  -o circular.pdf
```

Check `fileAvailability` on the document first.
Two failures look similar and mean opposite things:

| Code | Status | Means | Retry? |
|---|---|---|---|
| `content_not_archived` | 404 | We never held these bytes. | No, never. |
| `archive_unavailable` | 502 | We hold them, and our archive failed. | Yes. |

Do not retry the 404. Do retry the 502.

## 5. Follow what changes

The feed is resumable. Store the cursor and send it back to get what you have not seen.

```bash
# first call
curl -G https://api.vaquill.ai/api/v1/in/reg/changes \
  -H "Authorization: Bearer vq_key_..." \
  --data-urlencode "limit=50"

# later: resume from where you stopped
curl -G https://api.vaquill.ai/api/v1/in/reg/changes \
  -H "Authorization: Bearer vq_key_..." \
  --data-urlencode "cursor=<nextCursor from the last call>"
```

Keep calling while `hasMore` is true.
Do not poll with a date filter instead, because a date window misses documents that arrive late or change quietly.

<Warning>
  `total` on the changes feed is always `null`, which means not counted. Read `items` and `hasMore` to see whether anything is new.
</Warning>

## Scopes

One scope, `reg:read`, covers every publisher, document and route above.

## Errors

| Code | Status | Means |
|---|---|---|
| `invalid_request` | 400 | A parameter is malformed. The message says which. |
| `unauthorized` | 401 | The key is missing or wrong. |
| `insufficient_scope` | 403 | The key is valid but lacks `reg:read`. |
| `not_found` | 404 | No document with that id. |
| `content_not_archived` | 404 | The document exists; we never held its bytes. |
| `rate_limited` | 429 | Slow down. `Retry-After` says how long. |
| `archive_unavailable` | 502 | Our archive failed on a document we do hold. |
