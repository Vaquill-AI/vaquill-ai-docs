The Go client covers the statutes, session law, watch, board, credit and pricing operations of the US Data API and behaves like the [Python SDK](/api-guide/sdks/python).
For shared options and the operations without a method yet, see the [SDKs overview](/api-guide/sdks/overview#which-calls-cost-credits).

## Install

Requires Go 1.23 or newer.

```bash
go get github.com/Vaquill-AI/vaquill-sdks/go
```

```go
import vaquill "github.com/Vaquill-AI/vaquill-sdks/go"
```

Source: [`Vaquill-AI/vaquill-sdks`, `go/`](https://github.com/Vaquill-AI/vaquill-sdks/tree/main/go) on GitHub.

## Quickstart

```go
client, err := vaquill.NewClient() // reads VAQUILL_API_KEY
if err != nil {
	log.Fatal(err)
}
defer client.Close()

res, err := client.Statutes.Resolve(ctx, "42 U.S.C. 1983", nil)
if err != nil {
	log.Fatal(err)
}
fmt.Printf("%+v\n", res)
```

Every method takes a `context.Context` first, returns a typed value and an error, and never panics.
Optional request fields are pointers, so use `vaquill.Ptr("wa")`.
Fields that accept one value or a list use `vaquill.StringOrList{"wa", "ca"}`.

Client options: `WithAPIKey`, `WithBaseURL`, `WithTimeout` (0 disables), `WithMaxRetries`, `WithHTTPClient`, `WithDefaultHeaders`, `WithUserAgentSuffix`, `WithMaxCredits`, `WithAutoIdempotencyKeys`, `WithLogger`.
Per-call options: `WithRequestTimeout`, `WithRequestMaxRetries`, `WithIdempotencyKey`, `WithRequestHeader`, `WithResponse`.

Read the status, request id and credits of a call with `WithResponse`.

```go
var info vaquill.ResponseInfo
res, err := client.Statutes.Count(ctx, req, vaquill.WithResponse(&info))
fmt.Println(info.StatusCode, info.RequestID, info.CreditsChargedThisCall(), info.IdempotentReplayed)
```

`Header`, `Body`, `RateLimit` and `CreditsConsumed` are on the same value.
`CreditsChargedThisCall` is zero on an idempotent replay.
`client.Raw` sends any request and returns the undecoded body.

## Errors

All SDK errors implement `vaquill.Error`.
HTTP failures are typed per status and per machine `code`. Every one unwraps to `*vaquill.APIError`, which carries `StatusCode`, `Code`, `RequestID`, `Retryable`, `RetryAfterSeconds`, `Errors`, `Body` and `Headers`.

```go
var rl *vaquill.RateLimitError
switch {
case errors.As(err, &rl):
	time.Sleep(time.Duration(*rl.RetryAfterSeconds) * time.Second)
case errors.Is(err, vaquill.ErrInsufficientCredits):
	// top up
case errors.Is(err, vaquill.ErrNotFound):
}
```

Other types: `ConnectionError`, `TimeoutError`, `ResponseParseError` (a malformed 2xx body), `SpendGuardError`, `ConfigError` and `WebhookVerificationError`.
A 422 message lists the first validation reasons.
`IdempotencyKeyReused` is also an unprocessable-entity error, and `IdempotencyInProgress` is also a conflict.

## Retries and idempotency

<RetryRules />

Go specifics:

- 501 is not retried.
- A transport error is retried only for GET and HEAD, or when an idempotency key is set.
- A 5xx on a charged call is not retried without an idempotency key.

<IdempotencyKeys />

Charged POSTs get a generated UUID key unless you pass one.

```go
client.Statutes.Search(ctx, req, vaquill.WithIdempotencyKey("report-2026-10-29-search"))
```

Keys must be 16 to 255 visible ASCII characters.
`ResponseInfo.IdempotentReplayed` is true when the server replayed a stored response and charged nothing new.

## Spend guard

```go
client, _ := vaquill.NewClient(vaquill.WithMaxCredits(25))
```

Once the cap is reached, the next charged call fails with `*vaquill.SpendGuardError` without sending a request.
`client.CreditsSpent()` reads the running total. See [the spend guard](/api-guide/sdks/overview#spend-guard).

## Pagination and batch helpers

Paginated endpoints return a `*Paginator[T]` built on `iter.Seq2`.

```go
pager, _ := client.Statutes.IterSearch(ctx, &vaquill.StatuteSearchRequest{Query: "negligence"},
	vaquill.WithMaxPages(3), vaquill.WithMaxItems(100))
for item, err := range pager.All() {
	if err != nil {
		return err
	}
	fmt.Println(item.ActID)
}
fmt.Println(pager.Truncated(), pager.Stuck())
```

`Pages()` yields whole pages and `Collect()` returns a slice.

<Warning>
  Charged endpoints spend credits on every page. Always set `WithMaxPages` or `WithMaxItems`.
</Warning>

`Truncated` is true when a limit stopped the walk early. `Stuck` is true when the server repeated its offset or cursor, and the SDK stopped.

Iterators: `Statutes.IterSearch`, `IterDivisions`, `IterSectionChanges`; `SessionLaws.IterSearch`, `IterList`, `IterBody`, `IterChanges`; `Boards.IterList`; `Watches.IterList`, `IterChanges`.

Batch helpers split large inputs, remove duplicates and derive a per-chunk idempotency key.

| Helper | Items per request |
| --- | --- |
| `Statutes.ResolveBatchAll` | 500 |
| `Statutes.GetSectionsAll` | 50 |
| `SessionLaws.GetBatchAll` | 200 |

## Webhooks

Deliveries follow the Standard Webhooks scheme. Verify the raw request body, never a re-encoded one.

```go
ev, err := vaquill.UnwrapWebhook(body, r.Header, "whsec_...")
if err != nil {
	http.Error(w, "bad signature", http.StatusBadRequest)
	return
}
```

Secrets are `whsec_` plus base64.
Pass several secrets to `VerifyWebhookSecrets` or `UnwrapWebhookSecrets` while rotating.
An empty secret returns `ErrEmptyWebhookSecret`. A `whsec_` secret that is not valid base64 returns `ErrInvalidWebhookSecret`. Test both with `errors.Is`.
The default timestamp tolerance is 5 minutes (`WithWebhookTolerance`).
`WithLegacySignature` accepts the older `X-Vaquill-Signature` header, which has no replay protection.
`SignWebhook` produces headers for your own tests.

See [Alerts](/api-guide/alerts) for the payload and delivery behavior.

## Versioning

The SDK follows semantic versioning, and `vaquill.Version` holds the version. The released version is in the [SDKs overview](/api-guide/sdks/overview) table.
While the major version is 0, minor releases may change the API.
`vaquill.Operations` lists every operation with its method, path and whether it is charged.
