title: "Quickstart"
description: "Search US statutes and fetch a section in a few minutes"

This guide walks through a first search, then fetches one section's metadata and full text using the `actId` from the results, and finally checks what is queryable.

Every path is prefixed with `/api/v1` and every request needs an `Authorization: Bearer vq_key_...` header.

<Steps>
  <Step title="Get an API key">
    Create a key in your [dashboard](https://app.vaquill.ai/settings) under **API Keys**. Copy it right away, because it is not shown again. See [Authentication](/api-guide/authentication) for details.
  </Step>

  <Step title="Make your first search">
    Send a natural language query to `POST /us/statutes/search`. Scope it with `corpusType` and `state` for tighter results.

    <CodeGroup>
    ```bash cURL
    curl -X POST https://api.vaquill.ai/api/v1/us/statutes/search \
      -H "Authorization: Bearer vq_key_..." \
      -H "Content-Type: application/json" \
      -d '{"query": "civil rights deprivation under color of law", "corpusType": "USC", "limit": 5}'
    ```

    ```python Python
    import requests

    resp = requests.post(
        "https://api.vaquill.ai/api/v1/us/statutes/search",
        headers={
            "Authorization": "Bearer vq_key_...",
            "Content-Type": "application/json",
        },
        json={
            "query": "civil rights deprivation under color of law",
            "corpusType": "USC",
            "limit": 5,
        },
    )
    data = resp.json()
    first = data["results"][0]
    print(first["citation"], first["actId"])
    ```

    ```javascript JavaScript
    const resp = await fetch("https://api.vaquill.ai/api/v1/us/statutes/search", {
      method: "POST",
      headers: {
        "Authorization": "Bearer vq_key_...",
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        query: "civil rights deprivation under color of law",
        corpusType: "USC",
        limit: 5,
      }),
    });
    const data = await resp.json();
    const first = data.results[0];
    console.log(first.citation, first.actId);
    ```
    </CodeGroup>

    A trimmed response looks like this (captured 2026-10-22; null fields are omitted, and only the first of five results is shown). The top-level fields describe the page. Each `results` entry has a citation, an excerpt, and links to the official source.

    <Note>
      `count` is the number of results on this page. It is not a corpus-wide match count, and no such total exists, because the API ranks a bounded candidate set rather than scoring the whole corpus. Use `hasMore` to decide whether to fetch the next page. See [Pagination](/api-guide/pagination).

      The response also carries `total`, a deprecated alias for `count` kept for backward compatibility. Its name suggests a corpus-wide total, but it never was one. Read `count` in new code.
    </Note>

    <Note>
      `creditsConsumed` is what this call actually cost. Failed and refunded work bills 0, and `includeBody: true` bills each row that returns text on top of the search, so read the field instead of assuming a list price. `GET /api-credits/pricing` returns the live matrix.
    </Note>
  </Step>

  <Step title="Fetch the section and its body">
    Take an `actId` from the results (for example `USC_T42_C21_S1983`). Call `GET /us/statutes/section/{actId}` for metadata, and `GET /us/statutes/section/{actId}/body` for the full text.

    <CodeGroup>
    ```bash cURL
    # Metadata
    curl https://api.vaquill.ai/api/v1/us/statutes/section/USC_T42_C21_S1983 \
      -H "Authorization: Bearer vq_key_..."

    # Full text
    curl https://api.vaquill.ai/api/v1/us/statutes/section/USC_T42_C21_S1983/body \
      -H "Authorization: Bearer vq_key_..."
    ```

    ```python Python
    import requests

    headers = {"Authorization": "Bearer vq_key_..."}
    act_id = "USC_T42_C21_S1983"

    meta = requests.get(
        f"https://api.vaquill.ai/api/v1/us/statutes/section/{act_id}",
        headers=headers,
    ).json()

    body = requests.get(
        f"https://api.vaquill.ai/api/v1/us/statutes/section/{act_id}/body",
        headers=headers,
    ).json()

    if body["available"]:
        print(body["plain"])
    ```

    ```javascript JavaScript
    const headers = { Authorization: "Bearer vq_key_..." };
    const actId = "USC_T42_C21_S1983";

    const meta = await (
      await fetch(
        `https://api.vaquill.ai/api/v1/us/statutes/section/${actId}`,
        { headers },
      )
    ).json();

    const body = await (
      await fetch(
        `https://api.vaquill.ai/api/v1/us/statutes/section/${actId}/body`,
        { headers },
      )
    ).json();

    if (body.available) console.log(body.plain);
    ```
    </CodeGroup>

    <Tip>
      The body endpoint returns `html` and `plain` text plus an `available` flag and a `source`.
    </Tip>
  </Step>

  <Step title="Discover coverage">
    Coverage grows weekly. Call `GET /us/statutes/coverage` to see the corpus legend and, for each jurisdiction, which `corpusType` tokens have data. Pass one of those tokens back into `/us/statutes/search`.

    <CodeGroup>
    ```bash cURL
    curl https://api.vaquill.ai/api/v1/us/statutes/coverage \
      -H "Authorization: Bearer vq_key_..."
    ```

    ```python Python
    import requests

    cov = requests.get(
        "https://api.vaquill.ai/api/v1/us/statutes/coverage",
        headers={"Authorization": "Bearer vq_key_..."},
    ).json()["data"]

    for j in cov["jurisdictions"]:
        if j["hasData"]:
            print(j["code"], list(j["corpora"].keys()))
    ```

    ```javascript JavaScript
    const cov = (
      await (
        await fetch("https://api.vaquill.ai/api/v1/us/statutes/coverage", {
          headers: { Authorization: "Bearer vq_key_..." },
        })
      ).json()
    ).data;

    for (const j of cov.jurisdictions) {
      if (j.hasData) console.log(j.code, Object.keys(j.corpora));
    }
    ```
    </CodeGroup>
  </Step>
