This guide runs a first search, then fetches one section's full text using the `actId` from the results.

Every path is prefixed with `/api/v1` and every request needs an `Authorization: Bearer vq_key_...` header.

<Steps>
  <Step title="Get an API key">
    Create a key in your [dashboard](https://app.vaquill.ai/settings) under **API Keys**. See [Authentication](/api-guide/authentication).

    A new account starts with a free signup credit balance, so your first calls need no purchase.
    A `401` means the key is missing or invalid. A `402` means the balance is used up. See [Errors](/api-guide/errors).

    Keep the key in an environment variable:

    ```bash
    export VAQUILL_API_KEY="vq_key_..."
    ```
  </Step>

  <Step title="Make your first search">
    Send a natural language query to `POST /us/statutes/search`. Scope it with `corpusType` and `state` for tighter results.

    <CodeGroup>
    ```bash cURL
    curl -X POST https://api.vaquill.ai/api/v1/us/statutes/search \
      -H "Authorization: Bearer $VAQUILL_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"query": "civil rights deprivation under color of law", "corpusType": "USC", "limit": 5}'
    ```

    ```python Python
    import os
    import requests

    resp = requests.post(
        "https://api.vaquill.ai/api/v1/us/statutes/search",
        headers={
            "Authorization": f"Bearer {os.environ['VAQUILL_API_KEY']}",
            "Content-Type": "application/json",
        },
        json={
            "query": "civil rights deprivation under color of law",
            "corpusType": "USC",
            "limit": 5,
        },
    )
    data = resp.json()
    first = data["results"][0]
    print(first["citation"], first["actId"])
    ```

    ```javascript JavaScript
    const resp = await fetch("https://api.vaquill.ai/api/v1/us/statutes/search", {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${process.env.VAQUILL_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        query: "civil rights deprivation under color of law",
        corpusType: "USC",
        limit: 5,
      }),
    });
    const data = await resp.json();
    const first = data.results[0];
    console.log(first.citation, first.actId);
    ```
    </CodeGroup>

    The sample is trimmed to the first of five results. Each `results` entry has a citation, an excerpt, and links to the official source.

    ```json

      "results": [
        {
          "actId": "USC_T42_C21_S1983",
          "citation": "42 U.S.C. § 1983 (2026)",
          "citationShort": "42 U.S.C. § 1983",
          "title": "Civil action for deprivation of rights",
          "corpusType": "USC",
          "state": "federal",
          "year": 2026,
          "relevanceScore": 0.863,
          "excerpt": "Every person who, under color of any statute, ordinance, regulation, custom, or usage, of any State or Territory or the District of Columbia, subjects, or causes to be subjected, any citizen of the United States or other person within the jurisdiction thereof to the deprivation of any rights...",
          "titleNumber": "42",
          "titleName": "THE PUBLIC HEALTH AND WELFARE",
          "sectionNumber": "1983",
          "breadcrumb": [
            { "type": "title", "num": "42", "label": "Title 42", "name": "THE PUBLIC HEALTH AND WELFARE" },
            { "type": "section", "num": "1983", "label": "Section 1983", "name": "Civil action for deprivation of rights" }
          ],
          "actStatus": "in_force",
          "currentThrough": "2026-09-18",
          "textUrl": "https://statutes-us.vaquill.ai/usc/olrc/119-111/sections/USC_T42_C21_S1983.txt",
          "sourceUrl": "https://uscode.house.gov/view.xhtml?req=granuleid:USC-prelim-title42-section1983&num=0&edition=prelim"

    ```

    <Accordion title="Reading count, total and creditsConsumed">
      `count` is the number of results on this page. It is not a corpus-wide match count. Use `hasMore` to decide whether to fetch the next page. See [Pagination](/api-guide/pagination).

      The live response also carries `total`, a deprecated alias for `count`, and lists null fields as `null`. The sample omits both.

      <CreditsConsumed />
      `includeBody: true` bills each row that returns text on top of the search.

  </Step>

  <Step title="Fetch the section body">
    Take an `actId` from the results (for example `USC_T42_C21_S1983`) and call `GET /us/statutes/section/{actId}/body` for the full text.
    `GET /us/statutes/section/{actId}` returns metadata only.
    To get text in the first call, send `includeBody: true` in step 2.

    <CodeGroup>
    ```bash cURL
    curl https://api.vaquill.ai/api/v1/us/statutes/section/USC_T42_C21_S1983/body \
      -H "Authorization: Bearer $VAQUILL_API_KEY"
    ```

    ```python Python
    import os
    import requests

    headers = {"Authorization": f"Bearer {os.environ['VAQUILL_API_KEY']}"}
    act_id = "USC_T42_C21_S1983"

    body = requests.get(
        f"https://api.vaquill.ai/api/v1/us/statutes/section/{act_id}/body",
        headers=headers,
    ).json()

    if body["available"]:
        print(body["plain"])
    ```

    ```javascript JavaScript
    const headers = { Authorization: `Bearer ${process.env.VAQUILL_API_KEY}` };
    const actId = "USC_T42_C21_S1983";

    const body = await (
      await fetch(
        `https://api.vaquill.ai/api/v1/us/statutes/section/${actId}/body`,
        { headers },
      )
    ).json();

    if (body.available) console.log(body.plain);
    ```
    </CodeGroup>

    <Tip>
      The body endpoint returns `html` and `plain` text plus an `available` flag and a `source`.
    </Tip>
  </Step>

</Steps>

## Optional: discover coverage

Call `GET /us/statutes/coverage` to see which `corpusType` tokens have data for each jurisdiction (read `data.jurisdictions[].hasData` and `data.jurisdictions[].corpora`). Pass one of those tokens to `/us/statutes/search`.

```bash
curl https://api.vaquill.ai/api/v1/us/statutes/coverage \
  -H "Authorization: Bearer $VAQUILL_API_KEY"
```
