This page lists the US legal data Vaquill has ingested, by corpus type and by
jurisdiction. Vaquill covers the full stack of US primary law, not just statutes:
federal law, state statutes, state constitutions, court rules, and state
regulations.

The **Developer API** (`/statutes/*`) serves statutes, regulations, constitutions,
court rules, and executive actions, scoped with the `corpusType` filter.

Coverage is queryable live from `GET /statutes/coverage` and `GET /statutes/states`;
the per-corpus matrix below is a snapshot. In total the ingested corpus holds
**over 3.8M distinct sections** across all of these corpus types, indexed as
**more than 9.8M retrieval passages**.

<Info>
  **Snapshot date: 2026-08-06.** Statute coverage is always live via
  `/statutes/states` and `/statutes/codes`. Constitutions and court rules are an
  expanding set.
</Info>

<Note>
  Counts on this page are **distinct sections** (one per provision or document),
  the same figures `GET /statutes/coverage` returns. For retrieval, longer sections
  and documents are split into multiple passages, so the underlying index holds far
  more entries: **about 9.8M passages** across these 3.8M sections. The Federal
  Register alone (long agency rules, 13-15 passages each) accounts for over
  half of them.

  That split does not change what the API returns: a lookup by citation still
  resolves to one section with its full text.
</Note>

## What's in the corpus

<CardGroup cols={2}>
  <Card title="State statutes" icon="building-columns">
    **52 jurisdictions** (all 50 states + DC + Puerto Rico), **~2.0M sections**. Queryable via the statutes API.
  </Card>
  <Card title="Federal law" icon="landmark">
    US Code (54,853), CFR (219,447), Federal Register rules (384,794, 1995-present), Executive Orders (3,901), agency guidance (8,781), Federal Rules of Procedure incl. Supreme Court Rules (589), US Constitution (74). Queryable via the statutes API.
  </Card>
  <Card title="State constitutions" icon="scroll">
    **51 jurisdictions** (50 states + Puerto Rico), ~7.7K sections, with article/section structure and clickable citations. Queryable via the API (`corpusType=STATE_CONSTITUTION`).
  </Card>
  <Card title="Court rules" icon="gavel">
    **10 states**, ~11.9K rules (civil, criminal, appellate, and local), refreshed weekly. Queryable via the API (`corpusType=STATE_RULES`).
  </Card>
  <Card title="State regulations" icon="clipboard-list">
    **45 states**, **1.16M+ rules**, with effective dates and statutory authority. All ingested from each state's own official publisher and refreshed monthly. Queryable via the API (`corpusType=REGULATION`).
  </Card>
</CardGroup>

Every section is indexed for hybrid semantic + keyword search and mirrored in
multiple formats (HTML, PDF, XML, plain text, DOCX) where the source provides
them.

<Note>
  The Federal Register and Executive Order cadence depends on
  `federalregister.gov`, which has been throttling and rate-limiting traffic in
  2026. That can occasionally push a weekly pull later.
</Note>

<Note>
  **Agency guidance** is a registry of named sources, each independently
  filterable and each with its own `category`, folded into the single
  `corpusType=AGENCY_GUIDANCE` token: SSA Rulings (1,115), IRS Revenue
  Procedures/Rulings/Notices/Announcements (1,459), DOJ & FTC Merger
  Guidelines (2023), the DOJ Antitrust Division Leniency Policy, US Copyright
  Office Circulars (58), the DOJ Justice Manual (1,548 sections across all 9
  Titles, citable as "Justice Manual § 9-27.420"), the USCIS Policy Manual
  (456 chapters across all 12 volumes, citable as "USCIS Policy Manual, Vol.
  12, Pt. D, Ch. 3"), the USPTO Manual of Patent Examining Procedure (2,024
  sections across all 29 chapters, citable as "MPEP § 2106") and Trademark
  Manual of Examining Procedure (2,109 sections across all 19 chapters,
  citable as "TMEP § 1207.01"), and our own synthesized administrative
  guidance (SALT cap, CTC, 401(k) limits). New sources land as one registry
  entry, not a new API token.
</Note>

## Refresh cadence

How often each corpus is re-pulled from its official source. The counts above are
a snapshot; call `/statutes/coverage` or `/statutes/states` for the live count of
any jurisdiction.

| Corpus | Cadence |
|---|---|
| Federal | See the [Federal table](#federal): daily to weekly, and on amendment for the Constitution. |
| State statutes | Recurring pull from each state's official source. All 50 states plus DC and Puerto Rico are covered; a few one-time cutovers (for example Puerto Rico) are complete but not yet on an automatic refresh driver. |
| State regulations | Pulled monthly from each state's own official publisher, for all 45 states carrying regulations. |
| State court rules | Weekly, for the states that carry them. |
| State constitutions | On amendment. |

<Note>
  Pennsylvania's Consolidated Statutes are complete; its older unconsolidated
  (Purdon's) statutes are a separate later addition, prioritized for backfill.
  Constitutions and court rules roll out state by state.
</Note>

## Coming next

Federal corpora we do not serve yet. All of them are work in progress and
targeted to land by the **start of Q4 2026**. Each goes through the same
pipeline as everything above - ingested from the official source, chunked and
embedded for hybrid search, citation-linked, and put on a recurring refresh -
so it arrives queryable through the same `corpusType` filter.

### Federal law and court rules

| Source | What it adds | Official source |
|---|---|---|
| Federal Register notices | The third Federal Register document class. We carry final and proposed rules today; notices cover meeting announcements, information collections, agency determinations, and grant availability. | govinfo, federalregister.gov |
| Public Laws / Statutes at Large | Slip laws as enacted, before codification into the US Code. Public law numbers appear as a metadata field today, but the acts themselves are not served as documents. | govinfo |
| OLC and Attorney General opinions | Office of Legal Counsel opinions plus formal AG opinions - the executive branch's own binding legal interpretations. | justice.gov/olc |
| GAO decisions | Comptroller General decisions on appropriations law and bid protests. | gao.gov |

### Tax

|---|---|

| Private Letter Rulings | Taxpayer-specific rulings on the application of tax law to a proposed transaction. |
| Tax Treaty Technical Explanations | Treasury's official article-by-article commentary on each treaty. |
| US Tax Treaties | The bilateral income and estate tax treaties themselves. |

## How to query a jurisdiction

```bash
# Self-describing coverage matrix: every corpusType and its per-jurisdiction counts
curl https://api.vaquill.ai/api/v1/statutes/coverage \
  -H "Authorization: Bearer vq_key_..."

# Live coverage with current section counts
curl https://api.vaquill.ai/api/v1/statutes/states \
  -H "Authorization: Bearer vq_key_..."

# Statutory codes for one state (e.g. Mississippi)
curl "https://api.vaquill.ai/api/v1/statutes/codes?state=ms" \
  -H "Authorization: Bearer vq_key_..."

# Search within a state
curl -X POST https://api.vaquill.ai/api/v1/statutes/search \
  -H "Authorization: Bearer vq_key_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "landlord retaliation", "corpusType": "STATE", "state": "ms"}'

# Search state regulations (corpusType REGULATION, paired with a state)
curl -X POST https://api.vaquill.ai/api/v1/statutes/search \
  -H "Authorization: Bearer vq_key_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "stormwater discharge permit", "corpusType": "REGULATION", "state": "wa"}'
```

Each column in the matrix above maps to a `corpusType` filter on `/statutes/search`: statutes to `STATE`, regulations to `REGULATION`, constitutions to `STATE_CONSTITUTION`, and court rules to `STATE_RULES`. Federal Register agency rules use `FEDERAL_REGISTER` and agency guidance uses `AGENCY_GUIDANCE`.
