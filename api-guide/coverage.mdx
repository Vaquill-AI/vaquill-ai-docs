This page lists the US legal data Vaquill has ingested, by corpus type and by
jurisdiction. Vaquill covers the full stack of US primary law, not just statutes:
federal law, state statutes, state constitutions, court rules, state regulations,
and case law. The **Developer API** (`/statutes/*`) serves statutes, regulations,
constitutions, court rules, and executive actions, scoped with the `corpusType`
filter; case law is available in the platform. Coverage is queryable live from
`GET /statutes/coverage` and `GET /statutes/states`; the per-corpus matrix below
is a snapshot. In total the ingested corpus holds **~3.5M sections** across all of
these corpus types.

<Info>
  **Snapshot date: 2026-07-21**, federal counts re-verified 2026-08-01. Statute
  coverage is always live via `/statutes/states` and `/statutes/codes`.
  Constitutions, court rules and case law are an expanding set.
</Info>

<Note>
  Counts on this page are **sections**, meaning distinct provisions or documents,
  not search index entries. Longer sections are split into multiple passages
  internally so retrieval can target the relevant part, so the number of indexed
  passages is several times larger than the section counts here. That split is an
  internal retrieval detail and does not change what the API returns: a lookup by
  citation still resolves to one section with its full text.
</Note>

  </Card>

  </Card>
  <Card title="Court rules" icon="gavel">
    **7 states**, ~8K rules (civil, criminal, appellate, and local), refreshed weekly. Queryable via the API (`corpusType=STATE_RULES`).
  </Card>
  <Card title="State regulations" icon="clipboard-list">
    **45 states**, **1.1M+ rules**, with effective dates and statutory authority. 14 refreshed monthly from official publishers; 31 from a dated 2024 corpus, flagged `actStatus: "snapshot"`. Queryable via the API (`corpusType=REGULATION`).
  </Card>
  <Card title="Case law" icon="scale-balanced">
    Federal opinions from the Supreme Court through the District Courts (all 13 Circuits), plus state appellate and supreme court opinions across all 50 states, with inline citation resolution. Available in the platform.
  </Card>

Every section is indexed for hybrid semantic + keyword search and mirrored in
multiple formats (HTML, PDF, XML, plain text, DOCX) where the source provides
them.

## Refresh cadence

How often each corpus is re-pulled from its official source. The counts above are
a snapshot; call `/statutes/coverage` or `/statutes/states` for the live count of
any jurisdiction.

| Corpus | Cadence |
|---|---|
| Federal | See the [Federal table](#federal): daily to weekly, and on amendment for the Constitution. |
| State statutes | Recurring pull from each state's official source. All 50 states plus DC and Puerto Rico are covered; a few one-time cutovers (for example Puerto Rico) are complete but not yet on an automatic refresh driver. |
| State regulations, monthly | Pulled monthly from the official publisher: ID, IL, KY, MD, MN, OH, SC, VA, WA, WI. |
| State regulations, official (not yet automated) | CO, ME, and NM are ingested from the official source but not yet on the monthly cycle. |
| State regulations, 2024 snapshot | The asterisked (\*) rows: a dated 2024 corpus, `actStatus: "snapshot"`, `goodLawStatus: "unknown"`, not refreshed. |
| State court rules | Weekly, for the states that carry them. |
| State constitutions | On amendment. |

<Note>
  California, New Jersey, New York, and Vermont regulations can only ever be
  served from the 2024 snapshot tier: their administrative codes are published
  exclusively under commercial licence, with no free official full text.
  Pennsylvania's Consolidated Statutes are complete; its older unconsolidated
  (Purdon's) statutes are a separate later addition, prioritized for backfill.
  Constitutions and court rules roll out state by state.
</Note>

## How to query a jurisdiction

```bash
# Self-describing coverage matrix: every corpusType and its per-jurisdiction counts
curl https://api.vaquill.ai/api/v1/statutes/coverage \
  -H "Authorization: Bearer vq_key_..."

# Live coverage with current section counts
curl https://api.vaquill.ai/api/v1/statutes/states \
  -H "Authorization: Bearer vq_key_..."

# Statutory codes for one state (e.g. Mississippi)
curl "https://api.vaquill.ai/api/v1/statutes/codes?state=ms" \
  -H "Authorization: Bearer vq_key_..."

# Search within a state
curl -X POST https://api.vaquill.ai/api/v1/statutes/search \
  -H "Authorization: Bearer vq_key_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "landlord retaliation", "corpusType": "STATE", "state": "ms"}'

# Search state regulations (corpusType REGULATION, paired with a state)
curl -X POST https://api.vaquill.ai/api/v1/statutes/search \
  -H "Authorization: Bearer vq_key_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "stormwater discharge permit", "corpusType": "REGULATION", "state": "wa"}'
```

Each column in the matrix above maps to a `corpusType` filter on `/statutes/search`: statutes to `STATE`, regulations to `REGULATION`, constitutions to `STATE_CONSTITUTION`, and court rules to `STATE_RULES`. Federal Register agency rules use `FEDERAL_REGISTER` and agency guidance uses `AGENCY_GUIDANCE`.
