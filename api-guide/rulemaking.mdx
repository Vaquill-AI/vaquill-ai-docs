title: "US rulemaking"
description: "Regulations.gov dockets and documents, Unified Agenda history, OIRA review and CRA links, tied together by the RIN"
---

The Rulemaking API links the sources behind a federal rule by its Regulation Identifier Number (RIN, for example `2060-AV16`).
One call by RIN shows where a rule stands and what it connects to.
Sources are the Unified Agenda, OIRA review, Regulations.gov dockets, the Federal Register and the CFR.

## What is covered

| Source | What you get |
|---|---|
| Regulations.gov | Dockets and document metadata: agency, type, title, RIN, comment periods, Federal Register document numbers |
| Unified Agenda | One entry per edition that carried a RIN, from Fall 1995 onward, with the stage, priority and timetable the agency printed |
| OIRA EO 12866 review | Each review with its dates, decision, and the Federal Register document it cleared |
| Congress.gov | Congressional Review Act disapproval resolutions and rule submissions |
| GAO | Major rule reports, a partial listing |
| Federal Register, CFR, USC | Cross-links to documents, CFR parts and public laws, each with the basis and quality of the link |

Comment texts, attachments and commenter data are not included.
Dockets and documents show the current state, with the time we last saw them in `asOf`.

## Endpoints

Eight `GET` routes under `/api/v1/us/rulemaking/`.
Use an API key with the `research:read` scope, as in [Authentication](/api-guide/authentication).

| Endpoint | What it returns | Credits | Source |
|---|---|---:|---|
| `GET /us/rulemaking/dockets/{docketId}` | One docket, with document counts by type and the comment count when measured | 2 | Regulations.gov |
| `GET /us/rulemaking/dockets/list` | Dockets, most recently modified first, filtered | 1 per page | Regulations.gov |
| `GET /us/rulemaking/dockets/{docketId}/documents` | The documents of one docket in posting order | 1 per page | Regulations.gov |
| `GET /us/rulemaking/rins/{rin}` | Everything held for one RIN, with the quality of every link | 3 | All sources |
| `GET /us/rulemaking/rins/{rin}/agenda` | Unified Agenda history of one RIN, newest edition first | 1 per page | Unified Agenda |
| `GET /us/rulemaking/coverage` | What is held, per source, and how fresh it is | Free | All sources |
| `GET /us/rulemaking/committee-records/list` | Rules Committee records, most recent first, filtered | 1 per page | uscourts.gov |
| `GET /us/rulemaking/committee-records/{recordId}` | One committee record, its dockets and rule links, and a window of page text | 2 | uscourts.gov |

A page is one charge.
An empty list page is refunded (`creditsConsumed` 0), and its `note` names the filters applied.
A docket or RIN we hold nothing for answers `404`. A malformed RIN or a bad cursor answers `422` before any charge.
A `503` is refunded. See [Errors](/api-guide/errors).

## Look up a RIN

```bash
curl "https://api.vaquill.ai/api/v1/us/rulemaking/rins/2060-AV16" \
  -H "Authorization: Bearer vq_key_..."
```

The RIN is `NNNN-AANN`, and lower case is accepted.
The response below is abridged, and its values are placeholders:

```json
{
  "rin": "2060-AV16",
  "title": "...",
  "status": "linked",
  "stage": "Final Rule Stage",
  "isUmbrella": false,
  "agenda": {
    "editions": 12,
    "firstEdition": "201710",
    "lastEdition": "202510",
    "latest": { "editionId": "202510", "stage": "...", "priority": "...", "agencyAcronym": "EPA" }
  },
  "reviews": [
    {
      "reviewKey": "...",
      "dateReceived": "...",
      "dateCompleted": "...",
      "decision": "...",
      "economicallySignificant": true,
      "status": "concluded",
      "linkStatus": "linked",
      "frCitation": "..."
    }
  ],
  "dockets": [
    {
      "docketId": "EPA-HQ-OAR-2021-0208",
      "documentCount": 0,
      "openDocumentCount": 0,
      "commentCount": null,
      "sourceUrl": "https://www.regulations.gov/docket/EPA-HQ-OAR-2021-0208"
    }
  ],
  "federalRegister": [
    { "documentNumber": "2021-03456", "role": "proposed", "basis": "...", "quality": "verified" }
  ],
  "cfrParts": [{ "cfrTitle": 40, "cfrPart": "60", "basis": "...", "quality": "verified" }],
  "publicLaws": [],
  "craDisapprovals": [],
  "relatedRins": [],
  "coverage": [{ "source": "...", "held": true, "note": null }],
  "asOf": "2026-11-03T05:00:00Z",
  "creditsConsumed": 3,
  "processingTimeMs": 41.2
}
```

| Field | Meaning |
|---|---|
| `status` | How the RIN's Federal Register documents pair up: `linked` (a proposed and a final rule are paired), `final_only`, `pending`, `corrections_only`, `partial`, `ambiguous`, or `null` when no pairing is held |
| `isUmbrella` | An umbrella RIN covers many unrelated documents. No proposal-to-final pairing is claimed for it |
| `agenda` | Edition count, first and last edition, and the newest entry (`latest`) |
| `reviews[].decision` | OIRA's decision as printed |
| `reviews[].linkStatus` | `linked`, `ambiguous`, `umbrella_rin`, `no_candidate`, `no_fr_for_rin`, `pending` or `not_applicable`. `frActId` and `frCitation` are set only when it is `linked` |
| `dockets[].openDocumentCount` | Documents of that docket currently open for comment |
| `federalRegister[].role` | `proposed`, `final`, `correction`, `extension` or `other` |
| `coverage` | Per source, whether we hold anything for this RIN and why not |

### Confidence labels

Every cross-link carries a `basis`, which says how the link was made, and a `quality`:

| `quality` | Meaning |
|---|---|
| `verified` | The link rests on an identifier the sources share |
| `candidate` | A plausible link that is not confirmed. Check it before you rely on it |
| `ambiguous` | No confident link, so no pick is named. It carries no `actId` |

## Unified Agenda history

```bash
curl "https://api.vaquill.ai/api/v1/us/rulemaking/rins/2060-AV16/agenda?from=202310&limit=5" \
  -H "Authorization: Bearer vq_key_..."
```

`from` and `to` are edition ids (`YYYYMM`, for example `202510`), and `from` must not be after `to`.
`limit` is 1 to 100, default 25.
Each entry in `editions` carries these fields:

| Field | Meaning |
|---|---|
| `editionId`, `season`, `year`, `runDate` | The Unified Agenda edition the entry comes from |
| `title`, `abstract` | The agency's title and abstract |
| `stage`, `rinStatus`, `priority`, `major` | Stage, status, priority and major-rule flag as the agency printed them |
| the agency fields | The agency that carried the entry |
| `furtherInfoUrl` | Served only when it is an official `.gov` or `.mil` link |
| `publicCommentUrl` | The agency's public comment link |
| `timetable` | The agency's actions. Each has `action`, `dateRaw`, `dateValue`, `datePrecision` and, when the agency printed one, `frCitation` |

## Dockets and documents

```bash
curl "https://api.vaquill.ai/api/v1/us/rulemaking/dockets/EPA-HQ-OAR-2021-0208" \
  -H "Authorization: Bearer vq_key_..."
```

A docket carries these fields:

| Field | Meaning |
|---|---|
| `docketId`, `agencyId`, `title`, `abstract` | Identity and description from Regulations.gov |
| `docketType` | `Rulemaking` or `Nonrulemaking` |
| `rin`, `rinSource`, `spineRin` | The docket's RIN, where it came from, and a differing verified RIN from the spine (see below) |
| `lastModifiedAt` | The field the `modifiedSince` and `modifiedUntil` window reads |
| `modifyDate` | A second modification date, null when none was recorded |
| `documentCount`, `documentTypeCounts` | Documents held, in total and by type |
| `commentCount`, `commentCountAsOf` | The comment count when measured, and when it was taken |
| `sourceUrl` | The docket on Regulations.gov |

<Accordion title="How rin, rinSource and spineRin relate">
`rin` is the RIN the agency entered on the docket.
When the agency entered none, it is the single verified RIN we hold for the docket. `rinSource` says which: `regulations_gov` or `spine`.
`rin` and `rinSource` are null when neither exists, or when several RINs match.
`spineRin` is set only when our verified RIN differs from the agency's. `rin` then stays the agency's value.
</Accordion>

List dockets with filters:

```bash
curl "https://api.vaquill.ai/api/v1/us/rulemaking/dockets/list?agencyId=EPA&hasRin=true&limit=20" \
  -H "Authorization: Bearer vq_key_..."
```

| Parameter | Meaning |
|---|---|
| `agencyId` | Regulations.gov agency id, for example `EPA` |
| `docketType` | `Rulemaking` or `Nonrulemaking` |
| `rin` | One normalized RIN, for example `2060-AV16` |
| `hasRin` | `true` for dockets that carry a RIN, whether the agency entered it or the spine supplies it (see `rinSource`), `false` for those that do not |
| `modifiedSince`, `modifiedUntil` | Window on the publisher's last modified time. `modifiedSince` must be before `modifiedUntil` |
| `limit`, `cursor` | Page size 1 to 100 (default 50) and the cursor of the previous page |

The documents of one docket:

```bash
curl "https://api.vaquill.ai/api/v1/us/rulemaking/dockets/EPA-HQ-OAR-2021-0208/documents?openForComment=true" \
  -H "Authorization: Bearer vq_key_..."
```

Filters are `documentType`, `openForComment`, `postedFrom` and `postedTo`.
Each document carries these fields:

| Field | Meaning |
|---|---|
| `documentId`, `documentType`, `subtype`, `title` | Identity and kind |
| `postedAt` | When the document was posted |
| `commentStartAt`, `commentEndAt`, `openForComment`, `withinCommentPeriod`, `allowLateComments` | The comment period and whether it is open |
| `withdrawn` | Whether the document was withdrawn |
| `cfrPart`, `frPages` | The CFR part and Federal Register pages it cites |
| `frDocNum` | The Federal Register document number as Regulations.gov prints it |
| `frDocNumNorm` | The same number in the form used to join to the Federal Register (`2021-03456`) |
| `commentCount`, `sourceUrl` | The comment count when measured, and the document on Regulations.gov |

## Paging

The list routes return `nextCursor`, which is `null` on the last page.
Pass it back as `cursor` with the same filters.
A cursor is bound to the filters that produced it, and a cursor used with other filters answers `422` without a charge.
See [Pagination](/api-guide/pagination).

## Coverage

```bash
curl "https://api.vaquill.ai/api/v1/us/rulemaking/coverage" \
  -H "Authorization: Bearer vq_key_..."
```

This call is free.
Each entry in `sources` has `name`, `rowCounts`, `latestChange`, `lastRefreshAt`, `measuredAt`, `status` and `limitations`.
`status` is `ok`, `stale` or `unmeasured`.
`agendaEditions` lists the Unified Agenda editions held.

## Rules Committee records

The last two routes in the [endpoint table](#endpoints) serve records of the Judicial Conference Rules Committees (Standing, Appellate, Bankruptcy, Civil, Criminal and Evidence) from uscourts.gov.
Records include meeting minutes, agenda books, committee reports, rules packages, preliminary drafts, public comments and rules suggestions.

```bash
curl "https://api.vaquill.ai/api/v1/us/rulemaking/committee-records/list?committee=Civil&ruleSet=FRCP&rule=26&limit=20" \
  -H "Authorization: Bearer vq_key_..."
```

| Parameter | Meaning |
|---|---|
| `committee` | `Standing`, `Appellate`, `Bankruptcy`, `Civil`, `Criminal`, `Evidence` or `General` |
| `docType` | One document type; see the values below |
| `year` | Year of the record |
| `ruleSet` | `FRCP`, `FRAP`, `FRBP`, `FRCRP` or `FRE`: records that discuss a rule of this set |
| `rule` | A rule number such as `26`. Needs `ruleSet`, because five rule sets each have a Rule 5. Without it the call answers `422` before any charge |
| `docketId` | A comment docket, for example one from [Dockets and documents](#dockets-and-documents) |
| `limit`, `cursor` | Page size 1 to 100 (default 50) and the `nextCursor` of the previous page. A cursor is bound to the filters that produced it |

<Expandable title="docType values">
`meeting_minutes`, `agenda_books`, `committee_reports`, `rules_packages`, `preliminary_drafts`, `superseded_pamphlets`, `rules_comments`, `rules_suggestions`, `fjc_studies`, `past_members`, `special_projects`, `style_resources`, `transcripts_testimony`, `rules_comments_archive`.
</Expandable>

A list entry carries these fields. Page text is not in the list.

| Field | Meaning |
|---|---|
| `recordId` | `rcr_` and 24 hex characters |
| `committee`, `docType`, `title`, `year` | Which committee, what kind of record, and its title and year |
| `meetingDate`, `publishedDate` | Each comes with a precision field |
| `sourceUrl`, `itemUrl`, `filename` | Where the original sits on uscourts.gov, and its file name |
| `textWithheld`, `textStatus`, `textQuality` | Whether the text is served and how good it is (see [Withheld text](#withheld-text)) |
| `sha256`, `bytes`, `pageCount` | Fingerprint, size and pages of the source file |
| `withdrawn`, `asOf` | Whether the record was withdrawn, and when we last saw it |

```bash
curl "https://api.vaquill.ai/api/v1/us/rulemaking/committee-records/rcr_0123456789abcdef01234567?pageFrom=1&pageLimit=50" \
  -H "Authorization: Bearer vq_key_..."
```

The single record adds `dockets` (the comment dockets it is linked to), `rules` (the Federal Rules it discusses, with `actId` and `mentionCount`) and `pages`.
Every docket and rule link carries the `method` and `confidence` of the link. Treat a low-confidence link as a candidate.
`pageFrom` starts the window at a page and `pageLimit` is 1 to 200 pages (default 50).
`nextPage` continues the window and is `null` on the last one.
One call is one charge whatever the window.
A `pageFrom` past the last page returns the metadata with no pages and sets `textNotice`.
An unknown record answers `404` and is refunded.

A page with no text has `quality: blank`.
A scanned page not yet read has `quality: needs_ocr`, `textAvailable: false` and `text: null`.
`textStatus` and `textNotice` describe the record as a whole.

### Withheld text

Public comments (`rules_comments`, `rules_comments_archive`) and rules suggestions (`rules_suggestions`) name private individuals.
For these types `title`, `filename`, `sourceUrl`, `itemUrl` and all page text are `null`, `textWithheld` is `true`, and `textNotice` says why.
The record, its date, its dockets and its rule links are still served.

## Connect to the rest of the API

- **Federal Register.** `federalRegister[].actId` and `reviews[].frActId` point at the Federal Register document in the corpus. The document number is `frDocNumNorm` on a docket document. See [Federal coverage](/api-guide/coverage/federal) for what the Federal Register corpus holds.
- **CFR.** `cfrParts` gives the CFR title and part a rulemaking amends. Browse the part with the [statute hierarchy](/api-guide/concepts/hierarchy) and read the section text from `/us/statutes`.
- **US Code.** `publicLaws` and `craDisapprovals` link a rule to the public law behind it or to a Congressional Review Act resolution against it. Resolve a public law or section with [citation formats](/api-guide/concepts/citation-formats).
- **CFR section and part.** `GET /us/statutes/section/{actId}/rulemaking` lists the Federal Register documents behind one CFR section and `GET /us/statutes/part/{title}/{part}/rulemaking` those for a whole CFR part. Each costs 2 credits, and a lookup that finds nothing is not charged.
- **Law change alerts.** To be told when the CFR text changes, use [alerts](/api-guide/alerts).

## Known gaps

- A docket with no RIN cannot be found by RIN. A docket missing from a RIN page does not mean none exists.
- `commentCount` is `null` for most dockets and documents. `null` means not measured, never zero.
- The GAO major rule report listing is partial.
- Not every rule goes through OIRA review.
