The API returns rendered text from the body endpoint, plus links to the original files the publisher hosts.
Any field may be `null` when the source does not offer that format.

## Text from the body endpoint

`GET /us/statutes/section/{actId}/body` returns the section's text in several forms at once.

| Field | Contains |
|---|---|
| `html` | The whole body as HTML (string or `null`). Use it to display the section with its structure. |
| `plain` | The whole body as plain text (string or `null`). |
| `content` | The operative text only, without the credit line and notes. USC only. |
| `sourceCredit` | The publisher's credit line. USC only. |
| `notes` | The notes the publisher prints after the section. USC only. |
| `sourceUrl` | Where the government published this text (string or `null`). |
| `source` | Our storage identifier for the text. Not a citation. |
| `available` | Whether text was returned (bool). |
| `note` | An optional note when text is partial or unavailable (string or `null`). |
| `bodyUnavailable` | `true` when the publisher prints the section as images. Omitted otherwise. |
| `bodyUnavailableReason` | Present with `bodyUnavailable`. The only value is `image_only_source`. |

Check `available` first.

### When `bodyUnavailable` is `true`

- `html`, `plain` and `content` are `null` and `available` is `false`.
- `sourceUrl` points at the official copy where we may link to it.
- Nothing is charged, and a retry returns the same answer.

Search results and batch rows carry the same two fields, with `body` set to `null`.

### Law and notes in USC

For USC sections, `plain` and `html` hold the operative text, then the credit line, then the notes (historical notes, committee reports, amendments). Most of the body is often notes.
Use `content` for the operative text only, `sourceCredit` for the credit line and `notes` for the rest.

<Warning>
  If you feed sections to a model, use `content`. The full body can lead a model to quote an old amendment note as the law in force.

  CFR and the state corpora have no such split. All three fields are null there, and `plain` is the whole body.
</Warning>

### Choosing what comes over the wire: `format`

`format` selects which representations are returned.
All four values cost the same. The choice only changes payload size.

| Value | Returns |
|---|---|
| `both` | `html` and `plain`. The default. |
| `html` | `html` only. |
| `plain` | `plain` only. |
| `content` | `content`, `sourceCredit` and `notes` only. USC only. On any other corpus it returns `plain` with a `note`, and `content` is null. |

Check `content` for null and fall back to `plain` if you are not sure which corpus you have.

### Citing where the text came from

Cite `sourceUrl`, not `source`. It is null when we hold no official link for the section.

## Point-in-time text: `asOf`

Pass `asOf=YYYY-MM-DD` to get the text as it stood on that date, at the same price.
The response has an `asOf` block that says which version you hold.
See [Point-in-time law](/api-guide/point-in-time) for how to read `asOf.isBounded` before citing the text.

## Structured text and pincites

Pass `?structured=true` to `GET /us/statutes/section/{actId}/body` for two more fields, at no extra cost:

| Field | Contains |
|---|---|
| `markdown` | The body as nested Markdown lists, one level per subsection depth (string or `null`) |
| `subsections` | A tree of subsections for pincites (array or `null`) |

Each node in `subsections` has these fields:

| Field | Contains |
|---|---|
| `label` | The marker as printed, e.g. `(b)` or `(2)` |
| `pincite` | The marker path from the section root, e.g. `(b)(2)` |
| `type` | The level: `subsection`, `paragraph`, `subparagraph`, `clause`, or `subclause` |
| `citation` | The full pinpoint citation when known, e.g. `42 U.S.C. § 1981(a) (2026)` |
| `text` | The node's own text, excluding nested children |
| `children` | Nested subsections one level deeper (same shape) |

<CodeGroup>

```bash cURL
curl "https://api.vaquill.ai/api/v1/us/statutes/section/USC_T42_C21_S1981/body?structured=true" \
  -H "Authorization: Bearer vq_key_..."
```

```python Python
import requests

data = requests.get(
    "https://api.vaquill.ai/api/v1/us/statutes/section/USC_T42_C21_S1981/body",
    headers={"Authorization": "Bearer vq_key_..."},
    params={"structured": "true"},
).json()

def walk(nodes, depth=0):
    for n in nodes:
        print("  " * depth, n["pincite"], "->", (n["text"] or "")[:60])
        walk(n["children"], depth + 1)

walk(data["subsections"] or [])
```

</CodeGroup>

A section with no marked subsections returns `subsections: []`, and `markdown` equals the plain text.

## Source URL fields

Search results, section records and batch items carry these link fields. Any may be `null`.

| Field | Points to |
|---|---|
| `sourceUrl` | Where the government published this text. The link to cite. |
| `htmlUrl`, `pdfUrl`, `xmlUrl`, `textUrl`, `docxUrl` | The publisher's file in that format |
| `stateHtmlUrl` | The state legislature's own HTML page |
| `govInfoHtmlUrl` | The section on govinfo.gov (HTML) |
| `govInfoPdfUrl` | The section on govinfo.gov (PDF) |
| `externalUrl` | The publisher's own page for the section |

`stateHtmlUrl`, `govInfoHtmlUrl` and `govInfoPdfUrl` are null on much of the corpus.

`source` is not a link. It names a sub-source inside a multi-source corpus, for use as a search filter.

Where a state publishes its official text only through a commercial platform, `sourceUrl` and `externalUrl` are null, and `licenseNote` says a link exists.

<Accordion title="Publishers that need a browser">
  The Texas Administrative Code is published only through a JavaScript portal. Its link opens in a browser but returns an empty page to `curl`.
  To confirm a Texas section without a browser, use `adoptingCitations` (for example `50 TexReg 8285`) and read the text at `textUrl`.
</Accordion>

## Picking the best available format

Use the first field that is present, in this order: `sourceUrl`, `govInfoHtmlUrl`, `stateHtmlUrl`, `htmlUrl`, `govInfoPdfUrl`, `pdfUrl`, `textUrl`, `xmlUrl`, `docxUrl`, `externalUrl`.

<Accordion title="Helper that applies this order">
  <CodeGroup>

  ```python Python
  def best_source_url(result):
      for field in (
          "sourceUrl",
          "govInfoHtmlUrl",
          "stateHtmlUrl",
          "htmlUrl",
          "govInfoPdfUrl",
          "pdfUrl",
          "textUrl",
          "xmlUrl",
          "docxUrl",
          "externalUrl",
      ):
          url = result.get(field)
          if url:
              return url
      return None
  ```

  ```javascript JavaScript
  function bestSourceUrl(result) {
    const order = [
      "sourceUrl",
      "govInfoHtmlUrl",
      "stateHtmlUrl",
      "htmlUrl",
      "govInfoPdfUrl",
      "pdfUrl",
      "textUrl",
      "xmlUrl",
      "docxUrl",
      "externalUrl",
    ];
    for (const field of order) {
      if (result[field]) return result[field];
    }
    return null;
  }
  ```

  </CodeGroup>
