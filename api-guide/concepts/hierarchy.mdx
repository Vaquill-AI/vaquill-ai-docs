This page explains what each container of a law is called in the API, and which fields carry its name.
A section sits in a chapter, the chapter in a title, and some codes add subtitles, divisions, parts or articles between them.
Each container has a number or letter, and most have a heading.

## What a container is

A container is any level of a code between the code itself and a section.
The levels are the publisher's own, so no two codes have the same ladder.

<CodeGroup>

```text 42 U.S.C. § 1983
Title 42: THE PUBLIC HEALTH AND WELFARE
  Chapter 21: CIVIL RIGHTS
    Subchapter I: GENERALLY
      Section 1983: Civil action for deprivation of rights
```

```text Cal. Civ. Code § 1950.5
Code civ: Civil Code
  Division 3: OBLIGATIONS
    Part 4: OBLIGATIONS ARISING FROM PARTICULAR TRANSACTIONS
      Title 5: HIRING
        Chapter 2: Hiring of Real Property
          Section 1950.5
```

```text 17 C.F.R. § 240.10b-5
Title 17 CFR: Commodity and Securities Exchanges
  Chapter II: SECURITIES AND EXCHANGE COMMISSION
    Part 240: GENERAL RULES AND REGULATIONS, SECURITIES EXCHANGE ACT OF 1934
      Subpart A: Rules and Regulations Under the Securities Exchange Act of 1934
        (subject group) Manipulative and Deceptive Devices and Contrivances
          § 240.10b-5
```

</CodeGroup>

The same word sits at different levels in different codes.
In California a title sits below a division and a part.
In the U.S. Code it sits at the top.
New York has no titles, only articles.
Read the response rather than assuming a level.

| Container | `kind` in `/divisions`, `type` in `breadcrumb` | Request filter that lists inside it | Example |
|---|---|---|---|
| Title | `title` | `titleNumber` (U.S. Code, CFR), `title` (state codes) | 42 U.S.C. Title 42. Texas Penal Code Title 7, OFFENSES AGAINST PROPERTY |
| Subtitle | `subtitle` | `subtitle` | 6 Del. C. Subtitle I, Uniform Commercial Code |
| Division | `division` | `division` | Cal. Civ. Code Division 3, OBLIGATIONS |
| Subdivision | `subdivision` | `subdivision` | 54 U.S.C. only |
| Chapter | `chapter` | `chapter` | 42 U.S.C. Chapter 21, CIVIL RIGHTS |
| Subchapter | `subchapter` | `subchapter` | 42 U.S.C. Subchapter I, GENERALLY |
| Part | `part` | `part` | 17 C.F.R. Part 240. Cal. Civ. Code Part 4 |
| Subpart | `subpart` | `subpart` | 17 C.F.R. Subpart A. Louisiana and Mississippi regulation codes (needs `code` and the `part` it sits in) |
| Umbrella | `umbrella` | `umbrella` | State regulations only. Maine groups agencies under a department, such as `10`, Health and Human Services |
| Agency | `agency` | `agency` | State regulations only. Maine agency `144`, a Virginia agency, a Wyoming agency |
| Program | `program` | `program` | State regulations only. Wyoming prints a program between an agency and its chapters |
| Subject group | `subject_group` in `breadcrumb`, `subjectGroup` in `/divisions` | `subjectGroup` | CFR only. A heading with no number |
| Article | `article` | `article` | N.Y. Gen. Bus. Law Article 22-A. 6 Del. C. Article 2, Sales. A constitution's Article III |
| Act | `act` | `act` | Illinois 225 ILCS acts. New York's `Act GBS` |
| Code | `code` | `code` | Tex. Penal Code. New York's General Business Law |
| Rule set | `code` under `STATE_RULES` or `FEDERAL_RULES` | `code` | `frcp`. A county's local rules |

Titles, subtitles, chapters, subchapters, parts, subparts and articles have flat name fields on a section.
Every other level (division, subdivision, umbrella, agency, program, subject group, act) lives only in `breadcrumb`.
The flat fields are listed under [Where the names are](#where-the-names-are).

`kind` is also the request filter that drills into the node, with the one spelling difference in the table: a subject group is `subject_group` on a section and `subjectGroup` in a request.
Pass a node's `identifier` back as the filter its `kind` names and you list what is inside it.
[Browse the statute hierarchy](/api-guide/recipes/browse-hierarchy) walks a whole title that way.

## Where the names are

These fields carry a container's name.

| Where | Shape | What it is for |
|---|---|---|
| Flat fields on a section: `titleNumber` and `titleName`, `subtitle` and `subtitleName`, `chapter` and `chapterName`, `subchapter` and `subchapterName`, `part` and `partName`, `subpart` and `subpartName`, `articleNumber` and `articleName` | One string each | The common case: you want the chapter's name next to the citation |
| `titleName` on a code with no title level, `ruleSet` and `ruleSetCode` | One string each | `titleName` carries the code's name where a code has no title level. `ruleSet` and `ruleSetCode` identify a rule set under `STATE_RULES` or `FEDERAL_RULES` |
| `breadcrumb` | An array, broadest container first, ending with the section. Each entry is `{type, num, label, name}` | Every level, including those with no flat field: division, subdivision, subject group, act, code |
| `displayPath` | One string, `Title 42: THE PUBLIC HEALTH AND WELFARE / Chapter 21: CIVIL RIGHTS / ...` | Showing a reader where a section sits |
| `name` on each node of `GET /us/statutes/divisions` | One string | The listing of a level, before you hold a section |

Delaware divides a title into subtitles, articles and parts:

```json
{
  "actId": "STATE_DE_T6_A2_P2_S2-201",
  "citation": "6 Del. C. § 2-201",
  "titleNumber": "6",
  "titleName": "Commerce and Trade",
  "subtitle": "I",
  "subtitleName": "Uniform Commercial Code",
  "articleNumber": "2",
  "articleName": "Sales",
  "part": "2",
  "partName": "Form, Formation and Readjustment of Contract",
  "displayPath": "Delaware Code / Title 6: Commerce and Trade / Subtitle I: Uniform Commercial Code / Article 2: Sales / Part 2: Form, Formation and Readjustment of Contract / Section 2-201",
  "breadcrumb": [
    { "type": "title", "num": "6", "label": "Title 6", "name": "Commerce and Trade" },
    { "type": "subtitle", "num": "I", "label": "Subtitle I", "name": "Uniform Commercial Code" },
    { "type": "article", "num": "2", "label": "Article 2", "name": "Sales" },
    { "type": "part", "num": "2", "label": "Part 2", "name": "Form, Formation and Readjustment of Contract" },
    { "type": "section", "num": "2-201", "label": "Section 2-201" }
  ]
}
```

- `breadcrumb` is in the publisher's order, which is not always the order of the flat fields. Do not rebuild a path from the flat fields.
- `label` is the level and its number (`Article 2`), and `name` is the heading (`Sales`). `displayPath` joins them as `Article 2: Sales`.
- `chapter: "21"` is the number, and `chapterName: "CIVIL RIGHTS"` is the heading. Pass numbers and identifiers to filters, never names.

A container with no name prints only its label in `displayPath`, and its breadcrumb entry has no `name` key.
Names are printed the way the publisher prints them, and are never recased.
The code itself is a level: Texas has a `code` entry (`Code pe`, name `Penal Code`) at the top of its breadcrumb, and the `code` identifier (`tx_pe`) is the filter that lists inside it.

For this Delaware section, `GET /us/statutes/divisions?corpusType=STATE&state=de&code=de_6` has the node `{ "identifier": "2", "name": "Sales", "kind": "article", ... }`, and adding `&article=2` lists its parts.

## A null name

`name` is `null` on a listing node, and absent on a breadcrumb entry, when no heading is served for that container.
The container still exists, and its `sectionCount` and sections are unaffected.
Some publishers print a level as a number alone.

## Jurisdiction notes

| Jurisdiction | Notes |
|---|---|
| Maryland | The code is divided into articles, and only the article has a name. `titleName` carries the article's name (`Md. Code, Commercial Law`), and titles and subtitles are numbers alone. |
| New Jersey | Chapters print a number alone, so `chapterName` is `null`. Titles are named. |
| Pennsylvania | Some titles, chapters and acts have no name. |
| Texas | The `code` level is a citation label plus the code's name (`Code pe`, `Penal Code`). The `/divisions` name of a code is its citation form (`Tex. Penal Code`), and the `breadcrumb` name is `Penal Code`. |
| California | The ladder is code, division, part, title, chapter, article, and any of them can be absent. `titleNumber` and `titleName` read the level called title (`5`, `HIRING` for Civil Code § 1950.5), not the code. Chapter numbers repeat inside one code: see [Pooled numbers](#pooled-numbers). |
| New York | Laws are divided into articles, not chapters or titles, so there is no `chapterName`. `titleName` carries the law's name (`N.Y. General Business Law`), and `articleNumber` and `articleName` carry the article (`22-A`). |
| Arkansas, Georgia, Tennessee | `sourceUrl` is `null`. A few repealed chapters have `chapterName: null`. |

## Pooled numbers

Some codes reuse a number at the same level: California's Civil Code has dozens of chapters numbered `2`.
A listing asked only for `chapter=2` returns `kind: section` nodes for every chapter with that number, flat, with a `note` saying so.
Pass each ancestor the listing returned (`code`, `division`, `part`, `title`, `chapter`) to list one of them.

State regulations that print the agency above their chapters do not pool: Maine, Virginia and Wyoming list `umbrella`, `agency` and `program` nodes, and naming the agency (and the program in Wyoming) opens the right chapter.
See [Browse the statute hierarchy](/api-guide/recipes/browse-hierarchy#state-regulations-umbrella-agency-and-program) for a worked Maine example.
