---
title: "Amendment history"
description: "When a section changed, from the publisher's credit line: amendmentYears, lastAmendedYear, amendmentsCount and amendmentHistory."
---

Most statute sections carry a credit line that lists the acts that enacted and amended them.
We turn that line into fields you can filter and sort on.

These fields appear on `POST /us/statutes/search`, `GET /us/statutes/section/{actId}`, and `POST /us/statutes/sections`.
See [Response fields](/api-guide/concepts/response-fields) for which fields each corpus fills.

## The fields

| Field | Meaning |
|-------|---------|
| `amendmentYears` | Distinct years credited to the section, newest first. The year is the enactment year of the amending act, not its effective date. |
| `amendmentsCount` | How many changes the publisher recorded. |
| `lastAmendedYear` | The most recent year in `amendmentYears`. |
| `amendmentHistory` | Structured entries, where the publisher records them apart from the credit line. |
| `currentThrough` | The date the publisher says the text is current through. |

Where a publisher prints an effective date, we serve it separately. See [Status and currency](/api-guide/concepts/status-and-currency).

<Warning>
`amendmentsCount` counts amending events, not years.
Two amendments in 2019 give `amendmentYears: [2019]` and `amendmentsCount: 2`.
Use `amendmentsCount` for how many times a section changed, and `amendmentYears.length` for how many years.
</Warning>

```json
{
  "actId": "STATE_LA_Crevised-statutes_T39_S54",
  "citation": "La. Rev. Stat. § 39:54",
  "amendmentYears": [2015, 2013, 2011, 2003, 1997, 1993, 1989],
  "amendmentsCount": 7,
  "lastAmendedYear": 2015
}
```

## Differences by corpus

- Statutes include the original enactment year. A section enacted in 1991 and never amended reports `[1991]` with `amendmentsCount: 1`.
- State constitutions leave out the adoption date. A section never amended reports `amendmentYears: []`.
- Some state regulations (Oklahoma among them) include the adoption year but leave `lastAmendedYear` null until the first amendment.
- Final rules in `FEDERAL_REGISTER` carry the year the rule was published.
- Proposed rules carry no amendment years, so a year window returns none of them.
- `corpusType=STATE_AG_OPINION` returns empty `amendmentYears` and `amendmentsCount: 0`. An opinion is issued once and is not amended. For currency, see [Status and currency](/api-guide/concepts/status-and-currency).

Some jurisdictions print no credit line. For those, `amendmentYears` is empty or absent. Check [Coverage](/api-guide/coverage) for your jurisdiction.

## Using the fields

Find sections changed since a year with `yearFrom`, then read `lastAmendedYear` and `amendmentYears` on each result:

```bash
curl -X POST https://api.vaquill.ai/api/v1/us/statutes/search \
  -H "Authorization: Bearer vq_key_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "public records retention", "state": "in", "yearFrom": 2023, "limit": 10}'
```

Each result carries the fields described above:

```json
{
  "actId": "STATE_LA_Crevised-statutes_T39_S54",
  "amendmentYears": [2015, 2013, 2011, 2003, 1997, 1993, 1989],
  "amendmentsCount": 7,
  "lastAmendedYear": 2015
}
```

`yearFrom` and `yearTo` bound results by the credited amendment year, else the effective year, else the document's own publication year.
