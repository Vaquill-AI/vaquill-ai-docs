`state` accepts 56 US jurisdictions: all 50 states, plus the District of Columbia, Puerto Rico, Guam (`gu`), the Northern Mariana Islands (`mp`), the US Virgin Islands (`vi`) and American Samoa (`as`).
Federal law lives under its own `federal` jurisdiction, separate from the states.

A jurisdiction may not hold every corpus.
Read `GET /us/statutes/coverage` before you scope a search.

## How jurisdictions are keyed

- **Codes:** 2-letter strings (`ca`, `tx`, `ny`), case-insensitive. An unrecognized value returns `422`.
- **Lists:** pass several at once, such as `"state": ["ca", "ny", "tx"]`.
- **Federal:** a federal search needs only a `corpusType`, no `state`.
- **Kind:** each jurisdiction row from `/us/statutes/coverage` has a `kind` of `federal`, `state` or `territory`. DC and the five territories are `territory`.

## Reading a jurisdiction's corpora

`GET /us/statutes/coverage` returns a `{ "data": ..., "meta": ... }` response.
Each jurisdiction in `data.jurisdictions` has a `corpora` object.
Its keys are the `corpusType` tokens that have data, mapped to a document count.
`data.corpusTypes` is a legend naming every token and whether it is federal or state-scoped.

A jurisdiction that holds [state session laws](/api-guide/session-laws) also has a `sessionLaws` block with its sessions, `series`, `instrumentTypes` and approval-date span.
Session laws are not a `corpusType`.

<CodeGroup>

```bash cURL
curl https://api.vaquill.ai/api/v1/us/statutes/coverage \
  -H "Authorization: Bearer vq_key_..."
```

```python Python
import requests

resp = requests.get(
    "https://api.vaquill.ai/api/v1/us/statutes/coverage",
    headers={"Authorization": "Bearer vq_key_..."},
)
data = resp.json()["data"]

# Which corpus types does California have?
ca = next(j for j in data["jurisdictions"] if j["code"] == "ca")
print(ca["name"], ca["kind"], ca["sectionCount"])
print("available corpora:", list(ca["corpora"].keys()))
# e.g. ['STATE', 'REGULATION', 'STATE_CONSTITUTION', 'STATE_RULES']
```

</CodeGroup>

<Accordion title="JavaScript">

```javascript JavaScript
const resp = await fetch("https://api.vaquill.ai/api/v1/us/statutes/coverage", {
  headers: { Authorization: "Bearer vq_key_..." },

```

</Accordion>

For how recently a corpus was refreshed, read the free `GET /boards` (see [Law change alerts](/api-guide/alerts)).
It carries `lastRetrievedAt` and `cadence` per `(jurisdiction, corpusType)` pair.

## Listing a state's codes

`state=tx` alone searches every Texas code.
To scope below a jurisdiction, browse its codes with `/us/statutes/divisions` and pass one back as the `code` filter on search.

<CodeGroup>

```bash cURL
curl -G "https://api.vaquill.ai/api/v1/us/statutes/divisions" \
  -H "Authorization: Bearer vq_key_..." \
  -d "corpusType=STATE" -d "state=tx"
```

```python Python
import requests

resp = requests.get(
    "https://api.vaquill.ai/api/v1/us/statutes/divisions",
    headers={"Authorization": "Bearer vq_key_..."},
    params={"corpusType": "STATE", "state": "tx"},
)
for node in resp.json()["divisions"]:
    print(node["identifier"], node["name"], node["sectionCount"])
# tx_pe  Tex. Penal Code  ...
```

</CodeGroup>

Each node's `identifier` is what `code` on `POST /us/statutes/search` takes.
To drill further, pass it back to `/us/statutes/divisions` (`corpusType=STATE&state=tx&code=tx_pe` returns that code's chapters) until `isLeaf` is true, where each node carries an `actId`.

Browse supports the tokens with `browsable: true` in the coverage legend (listed on [Corpus types](/api-guide/concepts/corpus-types#tokens)).
Reach the rest with `/us/statutes/search`.
