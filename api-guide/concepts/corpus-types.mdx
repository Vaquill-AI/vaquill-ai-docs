`corpusType` chooses which body of law a search runs against.
It is the most important filter in the API.
Pass one token or a list.

For how much data sits behind each token, see [API Coverage](/api-guide/coverage).

## Scoping rules

- **Federal token:** send only `corpusType`, such as `{"query": "civil rights under color of law", "corpusType": "USC"}`.
- **State token:** send `corpusType` and `state`.
  Without `state`, the search spans every jurisdiction that has that corpus.
  `state` also accepts a list.
- **Source:** where a token folds in several bodies, narrow with `source`, such as `{"query": "tip credit", "corpusType": "AGENCY_GUIDANCE", "source": "whd_foh"}`.

```json
{ "query": "security deposit return", "corpusType": "STATE", "state": "ca" }
```

<Note>
  `titleNumber` is only valid with `corpusType` `USC` or `CFR`. Any other token returns a `422`.
</Note>

## Tokens

Call `GET /us/statutes/coverage` for live counts and for which tokens have data in which jurisdiction.
The Source codes column lists the values each token accepts in the `source` filter (see [Filtering to one named source](#filtering-to-one-named-source)).

| Token | Scope | Contains | Source codes |
|---|---|---|---|
| `USC` | Federal | United States Code, the codified federal statutes | - |
| `SESSION_LAW` | Federal | Statutes at Large: public and private laws as enacted, 1789-2026 | - |
| `STATUTE_COMPILATION` | Federal | An act's own text as amended through a stated later public law | - |
| `CFR` | Federal | Code of Federal Regulations, the current compilation | `far` (48 C.F.R. ch. 1), `dfars` (ch. 2). Other CFR results have a null `source` |
| `CFR_ANNUAL` | Federal | GPO's annual editions of the CFR, 1996-2026 | - |
| `FEDERAL_REGISTER` | Federal | Federal Register agency rules, final and proposed | - |
| `FEDERAL_REGISTER_NOTICE` | Federal | A curated set of Federal Register notices that act on a rulemaking | - |
| `EXECUTIVE_ACTION` | Federal | Executive orders, proclamations and memoranda | - |
| `AGENCY_GUIDANCE` | Federal | Sub-regulatory guidance from named agency sources | See the [source registry](/api-guide/coverage/agency-guidance) |
| `AGENCY_ADJUDICATION` | Federal | Federal matters decided by an agency | See [Federal coverage](/api-guide/coverage/federal) |
| `US_TAX_TREATY` | Federal | Bilateral income tax treaties and Treasury technical explanations. See [Treaty coverage](/api-guide/coverage/treaties) | `us_tax_treaty`, `us_tax_treaty_technical_explanation` |
| `US_TREATY` | Federal | Treaty and international agreement text, one document per article, plus the Senate treaty record. See [Treaty coverage](/api-guide/coverage/treaties) | `us_treaty`, `senate_treaty`, `senate_treaty_resolution`, `senate_treaty_document`, `senate_executive_report` |
| `SENTENCING_GUIDELINES` | Federal | US Sentencing Guidelines, current sections plus former text in Appendix B | - |
| `FEDERAL_RULES` | Federal | Federal Rules of Civil, Criminal, Appellate and Bankruptcy Procedure, Evidence, and Supreme Court Rules | `frcp`, `frcrp`, `fre`, `frap`, `frbp`, `sct` |
| `FEDERAL_RULES_ANNUAL` | Federal | Past texts of the national Federal Rules. Opt in only. Not current law | - |
| `FEDERAL_RULES_PROPOSED` | Federal | Proposed amendments to the national Federal Rules. Opt in only | - |
| `FEDERAL_LOCAL_RULES` | Federal | A federal court's own rules: courts of appeals, habeas rules, national courts and district courts | - |
| `CONSTITUTION` | Federal | US Constitution, Articles and Amendments | - |
| `STATE` | State | State statutory codes | - |
| `REGULATION` | State | State administrative codes | - |
| `STATE_RULES` | State | State court rules, including professional conduct and trial-court local rules | - |
| `STATE_AGENCY_GUIDANCE` | State | State regulator guidance, mostly insurance bulletins | `state_insurance_bulletin`, `state_financial_bulletin` |
| `STATE_AG_OPINION` | State | State Attorney General opinions. Persuasive authority, not binding law | `state_ag_opinion` |
| `STATE_CONSTITUTION` | State | State constitutions | - |
| `STATE_REGISTER` | State | State register notices: proposed, adopted and emergency rules as printed. Not codified law | - |

You can walk the tokens with `browsable: true` in the coverage legend using `/us/statutes/divisions`: `USC`, `CFR`, `STATE`, `REGULATION`, `STATE_RULES`, `CONSTITUTION`, `STATE_CONSTITUTION` and `FEDERAL_RULES`.

State session laws have no `corpusType`.
They are served by [`/us/session-laws`](/api-guide/session-laws).
`SESSION_LAW` is the federal Statutes at Large only.

The OpenAPI enum also accepts two values that are not searchable tokens today:

- `USC_ANNUAL` is GPO's retired annual edition of the US Code.
- `FEDERAL_BILL` holds text of Congressional bills, which is proposed text and never law. It is opt in only and never part of an unscoped search.

`STATE_AGENCY_GUIDANCE` holds state Department of Insurance bulletins and circular letters.
A bulletin interprets the law and is not itself the law, so it has its own token rather than sharing `REGULATION`.
Use it for insurance compliance and 50-state survey questions.

    Both sit beside `FEDERAL_RULES` and share its citations, so neither is part of an unscoped search.
    Name the token to read them.
    A stage change in a pending amendment is announced on the rule's own watch (see [alerts](/api-guide/alerts#pending-federal-rules-amendments)).

    - `FEDERAL_RULES_ANNUAL` holds superseded texts.
      The `actId` is the current rule's `actId` plus `_E` and the year, such as `{actId}_E2015`.
      Use `FEDERAL_RULES` for the rule in force.
      To ask what a rule said on a date, pass `asOf` with the current `actId` (see [Point-in-time law](/api-guide/point-in-time)).
    - `FEDERAL_RULES_PROPOSED` holds amendment documents.
      The `actId` is the current rule's `actId` plus `_P` and the cycle year, or `_PNOCYCLE` when no cycle year is set (`FRULES_FRE_R707_PNOCYCLE`).
      A proposal for a new rule (Evidence Rule 707, Bankruptcy Rule 7043) has no current rule to point at.
      `actStatus` is `proposed`, `superseded` (the amendment took effect) or `withdrawn`.
      A proposed amendment asked with `asOf` is refused as not law on any date.
      The rule in force lists its pending amendments in `pendingAmendments` (see [Federal coverage](/api-guide/coverage/federal)).
  </Accordion>
  <Accordion title="STATE_REGISTER">
    A state's official register prints each proposed, adopted or emergency rule as a notice on a date.
    `STATE_REGISTER` holds one document per printed item, cited by register volume and page (`36 Pa. Bull. 510`).
    See [Register citations](/api-guide/concepts/citation-formats#register-citations).

    The codified rule under `REGULATION` is the operative text.
    Every item is served with `goodLawStatus: "unknown"`, and `year` is the year of the issue it was printed in.
    Register notices rank below binding law in search.
    The states loaded are listed on [State and territory coverage](/api-guide/coverage/states#state-administrative-registers).
  </Accordion>
  <Accordion title="STATE_AG_OPINION">
    A formal written opinion in which a state's chief legal officer construes that state's laws for a state officer, legislator or local government.
    It is persuasive authority and does not bind a court.
    `goodLawStatus` is always `unknown`. See [Status and currency](/api-guide/concepts/status-and-currency).

    Where a jurisdiction runs more than one series, the `series` field carries the publisher's label.
    You can filter Washington's `AGO` from its `AGLO` letter opinions, or Georgia's Official from its Unofficial opinions.
    The series is also part of the `actId`.
  </Accordion>
  <Accordion title="SESSION_LAW and STATUTE_COMPILATION">
    Both carry `goodLawStatus: "unknown"`. They are historical records, not statements of current law.
  </Accordion>

## Choosing between tokens that look alike

| You want | Use | Not |
|---|---|---|
| What federal law says **today** | `USC` | `SESSION_LAW`, which is law as enacted and never updated |
| The text of an act Congress passed | `SESSION_LAW` | `USC`, which rearranges it by subject |
| An act that was never codified | `STATUTE_COMPILATION` | `USC`, which has no address for it |
| A regulation as it reads **now** | `CFR` | `CFR_ANNUAL`, which is a past published edition |
| What a regulation said in 2004 | `CFR_ANNUAL` | `CFR` with `asOf`, which reconstructs rather than reproduces |
| A Federal Rule as it reads **now** | `FEDERAL_RULES` | `FEDERAL_RULES_ANNUAL`, which is a past text, or `FEDERAL_RULES_PROPOSED`, which is a proposal |
| A Federal Rule on a past date | `asOf` on `/section/{actId}/body` with the current `actId` | Searching `FEDERAL_RULES_ANNUAL` for the date |
| What an agency **thinks** a rule means | `AGENCY_GUIDANCE` | `AGENCY_ADJUDICATION`, which is decided agency matters |
| How an agency **decided** a case | `AGENCY_ADJUDICATION` | `AGENCY_GUIDANCE` |

For asking any corpus what it said on a past date, see [Point-in-time law](/api-guide/point-in-time).

## Filtering to one named source

`AGENCY_GUIDANCE`, `AGENCY_ADJUDICATION`, `FEDERAL_RULES`, `CFR`, `US_TAX_TREATY`, `US_TREATY` and `STATE_AGENCY_GUIDANCE` each fold several independently filterable bodies into one token.
Every result carries a `source` field. Pass that value back as the `source` filter to scope to it.

```json
{ "query": "petition for writ of certiorari", "corpusType": "FEDERAL_RULES", "source": "sct" }
```

`source` accepts a single value or a list, such as `source: ["frcp", "sct"]`.
An unrecognized value returns `422`, and the error names every valid code.
The codes for each token are in the [token table](#tokens).
