The Vaquill AI statutes corpus is one index of US primary law, split into 14 named
slices. The `corpusType` filter on `POST /statutes/search` tells the API which
slice to search. Omit it and you search everything; set it and you narrow to one
body of law (federal statutes, state regulations, a constitution, and so on).

Corpus types come in two scopes. **Federal** corpora live under the single
`federal` jurisdiction. **State** corpora are keyed by jurisdiction, so you pair
them with a `state` filter (a 2-letter lowercase code like `ca` or `tx`) to
search one jurisdiction's data.

## The 14 tokens

### Federal-scoped

| Token | Contains | Scope | ~Size |
|---|---|---|---|
| `USC` | United States Code (federal statutes) | federal | 54,853 |
| `CFR` | Code of Federal Regulations, incl. the Federal Acquisition Regulation (FAR, 48 C.F.R. ch. 1, 5,537 sections) and Defense FAR Supplement (DFARS, ch. 2, 2,877 sections) - cite `FAR 52.219-14` or `DFARS 252.225-7001` directly, or filter with `source` (see below) | federal | 219,447 |
| `CONSTITUTION` | U.S. Constitution (Articles + Amendments) | federal | 74 |
| `FEDERAL_RULES` | Federal Rules of Procedure (FRCP, FRCrP, FRE, FRAP, FRBP, incl. Supplemental Admiralty and Social Security Rules) and Rules of the Supreme Court of the United States. Filter to one set with `source` (see below). | federal | 589 |
| `EXECUTIVE_ACTION` | Presidential documents (executive orders, proclamations, memos) | federal | 3,901 |
| `FEDERAL_REGISTER` | Federal Register agency rules, final and proposed | federal | 384,794 |
| `AGENCY_GUIDANCE` | Sub-regulatory agency guidance - 28 named sources across 15 agencies (SSA, IRS, DOJ, FTC, Copyright Office, USCIS, USPTO, DFARS, CFTC, FinCEN, Federal Reserve, OCC, FDIC, CPSC, BIS, DDTC, FCC, FERC, DOE, HHS OCR, and more). Full list in [API Coverage](/api-guide/coverage#federal). Filter to one source with `source` (see below). | federal | 21,026 |
| `SENTENCING_GUIDELINES` | U.S. Sentencing Guidelines (U.S.S.G.), the federal sentencing commission's guideline manual | federal | 302 |
| `US_TAX_TREATY` | U.S. bilateral income and estate tax treaties, citable by article, plus Treasury's Technical Explanations (article-by-article commentary on each treaty) | federal | 119 |

### State-scoped

| Token | Contains | Scope | ~Size |
|---|---|---|---|
| `STATE` | State statutory codes | state | ~2.0M across 52 jurisdictions (50 states + DC + PR) |
| `REGULATION` | State administrative regulations | state | ~1.16M across 45 states (all official-source, refreshed monthly) |
| `STATE_CONSTITUTION` | State constitutions | state | ~7.7K across 51 jurisdictions (50 states + PR) |
| `STATE_RULES` | State court rules (civil, criminal, appellate, local) | state | ~11.9K across 10 states |
| `STATE_AGENCY_GUIDANCE` | State-issued regulatory guidance (Department of Insurance bulletins and circular letters) - the state-scoped analog of `AGENCY_GUIDANCE`. Not a comprehensive 52-jurisdiction rollout; lands state by state. | state | 515 across 3 states (CA, IL, NY) |

<Info>
  These are approximate totals and expand weekly. The exact per-jurisdiction
  counts are always live via `GET /statutes/coverage`.
</Info>

## Scoping a search

<Steps>
  <Step title="corpusType alone">
    A federal corpus needs only `corpusType`. This searches the whole US Code:

    ```json
    {"query": "civil rights under color of law", "corpusType": "USC"}
    ```
  </Step>
  <Step title="corpusType plus state">
    A state corpus needs both `corpusType` and `state`. This searches only
    California's statutory code:

    ```json
    {"query": "security deposit return", "corpusType": "STATE", "state": "ca"}
    ```

    Omit `state` on a state-scoped corpus and the search spans every
    jurisdiction that has that corpus ingested.
  </Step>
</Steps>

<Note>
  `titleNumber` is only valid alongside `corpusType` `USC` or `CFR`. Sending it
  with any other corpus returns a `422`.
</Note>

## Example: state regulations

A `REGULATION` search paired with a state returns that state's administrative
rules. Here is Washington's environmental regulations:

<CodeGroup>

```bash cURL
curl -X POST https://api.vaquill.ai/api/v1/statutes/search \
  -H "Authorization: Bearer vq_key_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "stormwater discharge permit", "corpusType": "REGULATION", "state": "wa", "limit": 5}'
```

```python Python
import requests

resp = requests.post(
    "https://api.vaquill.ai/api/v1/statutes/search",
    headers={"Authorization": "Bearer vq_key_..."},
    json={
        "query": "stormwater discharge permit",
        "corpusType": "REGULATION",
        "state": "wa",
        "limit": 5,
    },
)
data = resp.json()
for r in data["results"]:
    print(r["citation"], "-", r["title"])
```

```javascript JavaScript
const resp = await fetch("https://api.vaquill.ai/api/v1/statutes/search", {
  method: "POST",
  headers: {
    Authorization: "Bearer vq_key_...",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    query: "stormwater discharge permit",
    corpusType: "REGULATION",
    state: "wa",
    limit: 5,
  }),
});
const data = await resp.json();
for (const r of data.results) {
  console.log(r.citation, "-", r.title);
}
```

</CodeGroup>

<Tip>
  Not every corpus type exists for every state. Before you scope a state
  search, call `GET /statutes/coverage` and read that jurisdiction's `corpora`
  keys to see which tokens actually have data. This avoids empty results from
  guessing.
</Tip>

## Example: Federal Register and agency guidance

Both are **federal**, so they need only a `corpusType`, no `state`.
`FEDERAL_REGISTER` searches agency rules as published (proposed and final).
`AGENCY_GUIDANCE` searches sub-regulatory guidance across 28 named sources
(SSA rulings, IRS notices, DOJ/FTC merger guidance, USPTO's MPEP/TMEP, CFTC
Staff Letters, FinCEN rulings, banking-regulator letters, and more - full
list in [API Coverage](/api-guide/coverage#federal)), plus a set of
primary-sourced **reference figures**: annually adjusted dollar thresholds
(for example the Subchapter V debt limit, or SALT and CTC values) that
don't live in USC or CFR section text.

<CodeGroup>

```bash cURL
# Agency guidance, including the annually adjusted figure records
curl -X POST https://api.vaquill.ai/api/v1/statutes/search \
  -H "Authorization: Bearer vq_key_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "2026 Subchapter V debt limit", "corpusType": "AGENCY_GUIDANCE", "limit": 5}'
```

```python Python
import requests

resp = requests.post(
    "https://api.vaquill.ai/api/v1/statutes/search",
    headers={"Authorization": "Bearer vq_key_..."},
    json={
        "query": "2026 Subchapter V debt limit",
        "corpusType": "AGENCY_GUIDANCE",
        "limit": 5,
    },
)
for r in resp.json()["results"]:
    print(r["citation"], "-", r["title"])
```

```javascript JavaScript
const resp = await fetch("https://api.vaquill.ai/api/v1/statutes/search", {
  method: "POST",
  headers: {
    Authorization: "Bearer vq_key_...",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    query: "2026 Subchapter V debt limit",
    corpusType: "AGENCY_GUIDANCE",
    limit: 5,
  }),
});
const data = await resp.json();
for (const r of data.results) console.log(r.citation, "-", r.title);
```

</CodeGroup>

Swap `corpusType` to `FEDERAL_REGISTER` to search published agency rules the same way.

<Note>
  `FEDERAL_REGISTER` and `AGENCY_GUIDANCE` are **search-only**. They are flat, not
  a title/chapter tree, so `/statutes/divisions` does not browse them, and
  `/statutes/resolve` parses statute and regulation citations (USC, CFR, state
  codes), not Federal Register or guidance citations. Reach both through
  `/statutes/search`, then `/statutes/section/{actId}` and `.../body`.
</Note>

## Filtering to one named source

`FEDERAL_RULES`, `CFR`, and `AGENCY_GUIDANCE` each fold several independently
filterable bodies of law into one token. Every result carries a `source` field
naming which one it came from; pass that value back as the `source` search
filter to scope to just it.

- `FEDERAL_RULES` sources: `frcp`, `frcrp`, `fre`, `frap`, `frbp`, `sct` (Rules
  of the Supreme Court of the United States).
- `CFR` sources: `far` (Federal Acquisition Regulation, 48 C.F.R. ch. 1) and
  `dfars` (Defense FAR Supplement, ch. 2). These split the *existing* Title 48
  data by chapter; they are not a separate ingest, and every other `CFR`
  result (all other titles, plus non-FAR/DFARS Title 48 chapters) has a null
  `source`.
- `AGENCY_GUIDANCE` sources:

  | `source` value | Name |
  |---|---|
  | `ssa_ruling` | SSA Rulings |
  | `irs_rev_proc` | IRS Revenue Procedures |
  | `irs_notice` | IRS Notices |
  | `irs_rev_rul` | IRS Revenue Rulings |
  | `irs_announcement` | IRS Announcements |
  | `merger_guidelines` | DOJ & FTC Merger Guidelines |
  | `doj_leniency` | DOJ Antitrust Division Leniency Policy |
  | `copyright_circular` | US Copyright Office Circulars |
  | `doj_justice_manual` | DOJ Justice Manual |
  | `uscis_policy_manual` | USCIS Policy Manual |
  | `mpep` | USPTO Manual of Patent Examining Procedure |
  | `tmep` | USPTO Trademark Manual of Examining Procedure |
  | `dfars_pgi` | DFARS PGI (Procedures, Guidance, and Information) |
  | `cftc_staff_letter` | CFTC Staff Letters (no-action, exemptive, interpretative, advisory) |
  | `fincen_ruling` | FinCEN Administrative Rulings |
  | `fincen_guidance` | FinCEN Guidance (alerts, advisories, notices, bulletins, fact sheets) |
  | `frb_sr_letter` | Federal Reserve SR / CA Letters |
  | `occ_bulletin` | OCC Bulletins |
  | `occ_interpretive_letter` | OCC Interpretive Letters |
  | `fdic_fil` | FDIC Financial Institution Letters |
  | `cpsc_advisory_opinion` | CPSC OGC Advisory Opinions (historical archive, 1973-2012) |
  | `cpsc_secg` | CPSC Small Entity Compliance Guides |
  | `fcc_declaratory_ruling` | FCC Declaratory Rulings |
  | `ferc_policy_statement` | FERC Policy Statements |
  | `doe_appliance_guidance` | DOE Appliance Standards Guidance and FAQs |
  | `bis_advisory_opinion` | BIS Advisory Opinions (Export Administration Regulations) |
  | `ddtc_commodity_jurisdiction` | DDTC Commodity Jurisdiction Determinations (ITAR/USML vs. EAR/CCL) |
  | `ddtc_guidance` | DDTC Policy Guidance Documents |
  | `hhs_ocr_hipaa_guidance` | HHS OCR HIPAA Guidance Materials |
  | `hhs_ocr_resolution_agreement` | HHS OCR HIPAA Resolution Agreements and Civil Money Penalties |
  | `hhs_ocr_hipaa_faq` | HHS OCR HIPAA FAQs |
  | `administrative_guidance` | Vaquill-synthesized administrative guidance |

```json
{ "query": "petition for writ of certiorari", "corpusType": "FEDERAL_RULES", "source": "sct" }
```

`source` accepts a single value or a list, so `source: ["frcp", "sct"]`
searches those two sets in one call. An unrecognized value is rejected with
`422` rather than silently returning nothing.
