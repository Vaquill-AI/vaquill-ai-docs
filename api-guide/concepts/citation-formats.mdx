title: "Citation formats"

`GET /us/statutes/resolve` turns a citation string into one exact section.
`POST /us/statutes/resolve` does the same for up to 50 at a time.
It covers statutes, regulations, constitutions and court rules. It does not resolve case citations.

## Send back the citation we gave you

Every section we return has a `citation` field.
Sending that string back always resolves to the same section.

```json Result from /us/statutes/search
{
  "actId": "STATE_GA_T51_C1_S51-1-6",
  "citation": "O.C.G.A. § 51-1-6",
  "sectionTitle": "Recovery of damages upon breach of legal duty."
}
```

```bash Feed it straight back
curl -G https://api.vaquill.ai/api/v1/us/statutes/resolve \
  -H "Authorization: Bearer vq_key_..." \
  --data-urlencode "cite=O.C.G.A. § 51-1-6"
```

Store the `citation` value we return rather than a form you build.

## Accepted variants

Bluebook and the form a state's own courts use resolve to the same section.

| Variant | Example | Note |
|---|---|---|
| State form | `Ga. Code Ann. § 51-1-6` and `O.C.G.A. § 51-1-6` | The same Georgia section |
| State form | `Wash. Rev. Code § 59.18.060` and `RCW 59.18.060` | The same Washington section |
| Code name after the section | `§ 292.290, RSMo`, `§ 162.41, Fla. Stat.` | Same as the name-first form |
| Edition year in the code name | `Ala. Code 1975, § 17-14-2` | The year is ignored |
| Doubled section symbol | `Cal. Civ. Code §§ 1950.5` | |
| Trailing period | `42 U.S.C. § 1983.` | |
| Typographic dashes | Non-breaking hyphens, figure dashes | Normalized for you |
| Pinpoint subsection | `42 U.S.C. § 1983(b)(2)` | Resolves to its section. A `pinpoint` object carries the unit. See [Pinpoints](/api-guide/concepts/pinpoints) |

## Forms that are refused

Some acronyms belong to two or more jurisdictions.
When the number after the acronym fits more than one, `resolve` returns `resolved: false`.
Pass `state` and it resolves.

| Acronym | Kind | Claimed by | Resolves without `state` when the number settles it |
|---|---|---|---|
| `MCA` | Statute | Montana and Mississippi Code Annotated | `MCA § 27-2-204` is Montana's three-part number |
| `IC` | Statute | Indiana and Idaho Code | `IC 34-11-2-1` is Indiana's four-part number, `IC 18-4001` Idaho's two-part one |
| `G.S.` | Statute | North Carolina and Connecticut General Statutes | `G.S. 1-52` is North Carolina's. `G.S. 52-577` fits both and is refused |
| `G.L.` | Statute | Massachusetts and Rhode Island General Laws | `G.L. c. 93A, § 2` can only be Massachusetts, and `G.L. 1956 § 9-1-13` Rhode Island |
| Bare `R.S.` | Statute | Louisiana and New Jersey Revised Statutes | `R.S. 2C:12-1` is New Jersey's. `R.S. 14:30` fits both and is refused |
| `CR` | Court rule | Kentucky Civil Rules and Washington Superior Court Civil Rules | Never. Pass `state` |
| `RAP` | Court rule | Washington, Kentucky and West Virginia | Never. Pass `state` |
| `TCR` | Court rule | Oregon and West Virginia | Never. Pass `state` |
| `M. R. Civ. P.` | Court rule | Montana and Maine | Never. Pass `state` |

```bash
# resolved: false - G.S. 52-577 fits North Carolina AND Connecticut
--data-urlencode "cite=G.S. 52-577"

# resolves - Conn. Gen. Stat. § 52-577
--data-urlencode "cite=G.S. 52-577" -d "state=ct"

# resolves - CR is KY and WA, so scope it: Washington Superior Court Civil Rule 56 (SRULES_WA_CR_R56)
--data-urlencode "cite=CR 56" -d "state=wa"
```

<Accordion title="Forms that name no jurisdiction">
  Virginia's in-state form is the bare word `Code`, so `cite=Code § 8.01-243&state=va` resolves.
  Connecticut and North Carolina both print `General Statutes § ...`. Pass `state`, as in `cite=General Statutes § 42a-1-101&state=ct`.
</Accordion>

## Court rules

Most court rules resolve on the set acronym alone. Punctuation and case do not matter: `I.I.R. 4`, `IIR 4` and `iir 4` are the same citation.
Acronyms shared between states are in the [refused forms table](#forms-that-are-refused).

| You send | Resolves to |
|---|---|
| `MCR 3.709` | Michigan Court Rules |
| `JuCR 7.15` | Washington Juvenile Court Rules |
| `N.D.R.Civ.P. 64` | North Dakota Rules of Civil Procedure |
| `Rule 901, SCRE` | South Carolina Rules of Evidence |

<Accordion title="More accepted forms: local rules, conduct rules, territories">
  Trial-court local rules must name the court. A bare rule number is never guessed.

  | Group | Example cite |
  |---|---|
  | Trial-court local rules | `Cook Cnty. Cir. Ct. R. 2.1`, `LRSF 16.15`, `Phila. R.J.A. 4008` |
  | Professional conduct | `Cal. R. Prof. Conduct 1.1`, `Or. RPC 1.1`, `Fla. R. Regulating Fla. Bar 4-1.1` |
  | Nevada ADR rules | `Nev. R. ADR 1`, `Nev. Arb. R. 14`, `Nev. Med. R. 9` |
  | Territory codes | `9 Guam Code Ann. § 16.10`, `Am. Samoa Code Ann. § 46.4810`, `14 V.I.C. § 1` |
  | Territory court rules | `Guam R. Civ. P. 71`, `V.I. R. Civ. P. 6-3` |
  | Vermont court rules | `Vt. R. Civ. P. 26` or `V.R.C.P. 26` |
</Accordion>

For trial courts held, see [State and territory coverage](/api-guide/coverage/states#court-rules-from-county-and-district-trial-courts).

## Scoping with state and corpusType

`state` and `corpusType` narrow a lookup. They never redirect one.
A citation that disagrees with the scope returns `resolved: false`.
For example, `cite=O.C.G.A. § 51-1-6&state=tx` does not find a Texas section with the same number.

`corpusType` on `resolve` takes `STATE`, `REGULATION`, `STATE_RULES`, `CONSTITUTION` or `STATE_CONSTITUTION`.
`STATE` covers statutes of every jurisdiction, federal ones included.
Any other value, such as `USC`, or an unrecognized `state`, returns a `422` (code `invalid_citation_input`) before any charge.

Scope only when a citation form is shared:

- `8 CCR 1206-2` is Colorado and `22 CCR 76227` is California. Pass `state`.
- If your citation names a court rule, pass `corpusType=STATE_RULES` so a same-numbered statute cannot answer.

On `POST /us/statutes/search`, `state` and `corpusType` filter the candidates before ranking.
A recognized citation passed as the `query` is pinned to rank 1. For one exact section, `/us/statutes/resolve` is cheaper.

## When the answer is not the exact unit you cited: `matchLevel`

An exact match carries none of the fields below.
These optional fields appear on `GET` and `POST /us/statutes/resolve` only when `section` is not the exact unit you cited.
`resolved` is `true` at every level, so read `matchLevel`.

| `matchLevel` | You cite | `section` is | Companion field | Example |
|---|---|---|---|---|
| absent | One section | Exactly that section | None | `42 U.S.C. § 1983` gives `USC_T42_C21_S1983` |
| `container` | A chapter, series, article, part or amendment | The first section in force inside it (the first of all when none is) | `container` | `Mo. Code Regs. Ann. tit. 10, § 40-6` gives `STATE_MO_CSR_T10_D40_C6_S010`, a chapter of 12 sections |
| `multiple` | Several sections in one citation | The first of them | `citedSections` | `42 U.S.C. §§ 1983-1985` gives `USC_T42_C21_S1983` |
| `repaired` | A recognized miscite of a code name | The section the repair names | `repair` | `N.Y. Jud. Ct. Acts Law § 475` gives `STATE_NY_AJUD_A15_S475`, read as `N.Y. Judiciary Law § 475` |
| `register_reference` | A state register page, issue or filing | The register item, or a rule whose history cites it | `registerReference` | `36 Pa. Bull. 510` gives `SREGISTER_PA_V36_P510` |

<Warning>
  A flagged answer is the first of several sections, or a correction of what you wrote.
  For strict verification, accept only responses with no `matchLevel`.
</Warning>

<AccordionGroup>
  <Accordion title="container: chapters, series, articles and amendments">
    `container` carries `kind` (`chapter`, `subchapter`, `series`, `article`, `section` or `amendment`), `label`, `childCount`, `children` (`actId`, `citation`, `status`, in document order) and `truncated`.
    `truncated` is true when `children` lists fewer than `childCount`. At most 50 are listed.

    ```bash container
    # Mo. Code Regs. Ann. tit. 10, § 40-6 is a chapter, not a section
    curl -G https://api.vaquill.ai/api/v1/us/statutes/resolve \
      -H "Authorization: Bearer vq_key_..." \
      --data-urlencode "cite=Mo. Code Regs. Ann. tit. 10, § 40-6"
    ```

    ```json container (fields beside resolved and section)
    {
      "matchLevel": "container",
      "container": {
        "kind": "chapter",
        "label": "10 CSR 40-6",
        "childCount": 12,
        "children": [
          { "actId": "STATE_MO_CSR_T10_D40_C6_S010", "citation": "10 CSR 40-6.010", "status": "in_force" },
          { "actId": "STATE_MO_CSR_T10_D40_C6_S020", "citation": "10 CSR 40-6.020", "status": "in_force" }
        ],
        "truncated": false
      }
    }
    ```

    The real response lists all twelve children.
  </Accordion>
  <Accordion title="multiple: several sections in one citation">
    `citedSections` lists the sections you named, as written. A range such as `1983-1985` is one entry.
  </Accordion>
  <Accordion title="repaired: a recognized miscite of a code name">
    `repair` has `kind` (only `code_name`), `cited` (the part we corrected), `interpretedAs`, and `alternatives` (other sections the code name could mean, often empty).

    ```json repaired (N.Y. Jud. Ct. Acts Law § 475)
    {
      "matchLevel": "repaired",
      "repair": {
        "kind": "code_name",
        "cited": "Jud. Ct. Acts Law",
        "interpretedAs": "N.Y. Judiciary Law § 475",
        "alternatives": [{ "actId": "STATE_NY_AFCT_A4_P7_S475", "citation": "N.Y. FCT Law § 475" }]
      }
    }
    ```
  </Accordion>

### Register citations

`36 Pa. Bull. 510` or `17 Ill. Reg. 10414` names a page of a state register.
The answer depends on whether we hold that register:

- **We hold the item** (`registerReference.registerItemHeld: true`). `section` is the register notice itself, `corpusType` `STATE_REGISTER`. It is a notice as printed, not codified law. See [State administrative registers](/api-guide/coverage/states#state-administrative-registers).
- **We do not hold it** (`registerItemHeld: false`). `section` is a codified rule whose history note cites that page. It is the first of `ruleCount`, with the others in `rules`.

<Accordion title="registerReference fields and samples">
  `registerReference` has `citation`, `state`, `kind`, `ruleCount`, `rules` (`actId`s, at most 25) and `registerItemHeld`.
  `kind` is `page`, `range`, `issue` or `filing`.

  ```json register item held (36 Pa. Bull. 510)
  {
    "matchLevel": "register_reference",
    "registerReference": {
      "citation": "36 Pa. Bull. 510",
      "state": "pa",
      "kind": "page",
      "ruleCount": 1,
      "rules": ["SREGISTER_PA_V36_P510"],
      "registerItemHeld": true
    }
  }
  ```

  ```json register item not held (17 Ill. Reg. 10414)
  {
    "matchLevel": "register_reference",
    "registerReference": {
      "citation": "17 Ill. Reg. 10414",
      "state": "il",
      "kind": "page",
      "ruleCount": 18,
      "rules": ["STATE_IL_IAC_T1_P100_S100_120", "STATE_IL_IAC_T1_P100_S100_210"],
      "registerItemHeld": false
    }
  }
  ```

  A register citation that no held item and no rule's history note cites returns `resolved: false`.
</Accordion>

## Checking a whole document: `POST /us/statutes/resolve`

The batch route takes up to **50 citations** per call and returns the same verdict for each.
Use it to check the citations in a brief, a memo or a model's output.

<CodeGroup>

```bash cURL
curl -X POST https://api.vaquill.ai/api/v1/us/statutes/resolve \
  -H "Authorization: Bearer vq_key_..." \
  -H "Content-Type: application/json" \
  -d '{"citations": ["42 U.S.C. 1983", "16 C.F.R. 444.1", "Cal. Civ. Code 1950.5"]}'
```

```python Python
import requests

resp = requests.post(
    "https://api.vaquill.ai/api/v1/us/statutes/resolve",
    headers={"Authorization": "Bearer vq_key_..."},
    json={
        "citations": [
            "42 U.S.C. 1983",
            "16 C.F.R. 444.1",
            "Cal. Civ. Code 1950.5",
        ]
    },
).json()

for item in resp["results"]:
    if item["resolved"]:
        print(item["inputCitation"], "->", item["section"]["actId"])
    else:
        print(item["inputCitation"], "-> unresolved")

print(resp["resolvedCount"], "of", resp["count"], "resolved")
```

</CodeGroup>

| Behavior | Rule |
|---|---|
| Every input gets an entry | An unresolved citation returns `resolved: false`, never an omission |
| Duplicates | Collapsed before pricing. The same citation sent twice costs once and returns one entry |
| Scoping | `state` and `corpusType` apply to every citation in the call. Omit them for a batch that spans jurisdictions |
| Price | Billed per citation, the same as single calls. Unresolved citations are charged. Backend errors are refunded, so read `creditsConsumed` |

## State session law citations

When a citation names a state session law (`CHAPTER 2025-12`, `S.F.No. 1552`) and no code section, the response has `matchedCorpus: "session_law"` and a `sessionLaw` block. `resolved` stays `false` because `section` is null.
`sessionLaw.status` is `matched` or `ambiguous`. There is no extra charge.
To read the law, send its `sessionLawId` or the citation to [`GET /us/session-laws/{sessionLawId}`](/api-guide/session-laws#finding-a-law).

## Treaty citations

A treaty citation is read as a treaty, never as a U.S. Code section or a Public Law.

| Form | Example | Resolves |
|---|---|---|
| Senate Treaty Document | `S. Treaty Doc. No. 98-9` | Yes |
| United States Treaties | `20 U.S.T. 361` | Yes, volumes 1 to 35 |
| Statutes at Large | `49 Stat. 3000` | Yes, volumes 1 to 64 |
| Bevans | `1 Bevans 631` | Yes |
| Treaties and Other International Acts Series | `T.I.A.S. No. 95-1121` | Yes |
| Treaty Series, Executive Agreement Series | `T.S. No. 993`, `E.A.S. No. 12` | Yes, where we hold the Statutes at Large printing |
| Social Security totalization agreement | `Social security totalization agreement, Norway, agreement, art. 2` | Yes |
| IRS income tax treaty document | `U.S.-Canada Income Tax Treaty (1980)` | Yes |
| Senate Executive Report | `S. Exec. Rep. No. 102-23` | `not_held` |
| United Nations Treaty Series | `658 U.N.T.S. 163` | `not_held` |
| League of Nations Treaty Series | `137 L.N.T.S. 11` | `not_held` |

Treaty text is served one section per article.
A cite to the instrument itself, such as `20 U.S.T. 361`, returns `matchLevel: "container"`, with every article in `container.children`.
An article pinpoint such as `Hague Service Convention art. 10, Nov. 15, 1965, 20 U.S.T. 361, T.I.A.S. No. 6638` resolves to that article.

A `not_held` answer has `resolved: false`, `missReason: "not_held"` and a `missReasonHint`. Cite the instrument by its U.S.T., T.I.A.S. or Statutes at Large citation where it has one.

To find an instrument by topic or party, search `corpusType=US_TREATY`, or `US_TAX_TREATY` for IRS income tax treaties.
See [Treaty coverage](/api-guide/coverage/treaties).

## When something does not resolve

1. Check the shared-acronym table above. If the citation is on it, add `state`.
2. Retry without `state` and `corpusType`. A scope that disagrees with the citation returns `resolved: false`.
3. Search for it with `POST /us/statutes/search`, using the citation as the `query`.
4. If a jurisdiction prints the form and we cannot read it, send it to [contact@vaquill.ai](mailto:contact@vaquill.ai).

### Miss reasons

An unresolved answer can carry a `missReason`.

| `missReason` | Meaning | Fix |
|---|---|---|
| `not_held` | The citation is valid but we do not hold that section | Read `missReasonHint` |
| `ambiguous_jurisdiction` | Several jurisdictions print this form, or it names none, and no `state` was given | Pass `state`. `candidates` lists likely sections |
| `former_law` | It names a repealed or renumbered compilation | Read `missReasonHint` for the successor |
| `malformed` | No parser reads it, such as a case citation or a string with no section number | Fix the string, or search for it |
| `out_of_scope_corpus` | It names a body of law this route does not serve | Read `missReasonHint` |
| `container_not_supported` | It cites a chapter, article, title or part in a form this route does not answer | Cite a section inside it, or use `GET /us/statutes/divisions` |
| `index_warming` | Batch only. No verdict yet. Not billed | Send it again in a few seconds |
| `lookup_failed` | Batch only. We failed to load the section. Refunded | Retry it |
| `miss_reason_unavailable` | The check that explains a miss failed. The unresolved verdict is unchanged | Resend it |
