This page reports how well `GET` and `POST /us/statutes/resolve` read real citations.
It is measured, not estimated, and it lists the gaps as plainly as the strengths.
Figures were taken on 2026-10-08 against the live corpus.

## The headline

We test two kinds of citation.
**25,112 citations should resolve to one section.**
**1,575 should not**: a whole chapter, a run of sections, a string that fits more than one law, or law we do not hold.

| Citations that should resolve (25,112) | Share |
|---|---:|
| Resolved to the right section | **94.9%** (23,843) |
| Resolved to the **wrong** section | **0** |
| No answer | 5.1% (1,269) |

| Citations that should not resolve (1,575) | Count |
|---|---:|
| Refused | 1,428 |
| Answered, and marked so you can tell (`matchLevel`) | 144 |
| Answered with a wrong section | 3 |

**A wrong answer is the number that matters most.**
A missed citation costs you a retry.
A wrong section can end up in a brief.
So the resolver is built to refuse when it is unsure, and every figure below shows wrong answers beside right ones.

## What is refused on purpose

Some citations have no single correct section.
We refuse these, or answer and say what kind of answer it is, instead of guessing.

| What the citation names | Citations | Refused | Answered with a flag | Wrong answer |
|---|---:|---:|---:|---:|
| A chapter, article or part, not one section | 597 | 562 | 35 | 0 |
| Law we do not hold | 462 | 459 | 0 | 3 |
| More than one law fits the string | 286 | 284 | 2 | 0 |
| Several sections cited together | 149 | 79 | 70 | 0 |
| Not a citation to US primary law | 81 | 44 | 37 | 0 |

When we answer a chapter or a run of sections with its first section, the response carries `matchLevel` so you can tell.
See [Citation Formats](/api-guide/concepts/citation-formats).

A bare rule-set abbreviation that several states print (`CR 56`, `RAP 2.5`) is refused unless you pass `state`.

## Pinpoints

1,116 citations carried a pinpoint (`(a)(2)`, `at 12`).
1,015 resolved to the right section, and 327 returned the pinpoint as `subsection`.

## Where coverage is thinner

**Court rules are the weakest area.**
Most of the citations that get no answer are court rules, because the rule is held but in a shape the lookup cannot reach yet (for example one record that spans several rule numbers, or a state's own short form that we do not read).
Outside court rules, no area misses more than 1.4% of its citations.

- About 649 of the 1,171 court-rule misses resolve as soon as the caller passes `state`.
  Several states print the same abbreviation (`DCR`, `SCR`, `CR`), so we refuse it without a state.
  This test set sends many of them without one, and counts each as a miss.
- When this set was measured, Vermont's court rules and the Virgin Islands Code were not held, so citations to them counted as misses. Both are held now. Most district and county local rules outside those we list on the [coverage page](/api-guide/coverage) are still not held.
- State session laws are served by their own endpoints and are not part of this resolver.
- State administrative registers resolve only where a held rule cites the register page.

## How this is measured

The test set was built by research passes that catalogued how citations are written for each jurisdiction and form, attested each against a court rule, a legislature page or an opinion where one could be fetched, and resolved the expected section from the live corpus.
Every score compares the resolver's answer with that expected section.

Read the figures with these limits in mind:

- The set is our own research.
  It is not an independent benchmark, and the forms we thought of are over-represented compared with forms we did not.
- It measures the resolver in isolation.
  Real traffic includes malformed and incomplete strings that a clean test set does not.
- Some entries were corrected after the corpus grew, so that a citation that now resolves correctly is not scored as a miss.
  Each correction is recorded with its evidence.
- The set is rerun before any change to citation parsing ships, and this page is refreshed from the latest full run.
