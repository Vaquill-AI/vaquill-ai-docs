Let an AI agent (Claude, Cursor, or your own) look up US law mid-conversation, with citations.

There are two ways. Connect an MCP-compatible client to the hosted Vaquill MCP server, or wrap the REST API as a tool for your own agent.
Both return citations and official source links.

**Endpoint:** `POST /us/statutes/search` for the custom-tool path. The hosted server needs no REST calls from you.

<Tip>
  Using an MCP-compatible client? Connect the [hosted Vaquill MCP server](/integrations/mcp/vaquill) and skip this page. It needs no glue code.
</Tip>

## Wrap the REST API as your own tool

Define a `search_statutes` function backed by `POST /us/statutes/search` and register it as a tool.
The agent decides when to call it.

<Steps>
  <Step title="Implement the tool function">
    Use `fields` to request only what the model needs. Fields you skip are never sent, and the saving grows with `limit`.
    `actId` and `citation` always come back.

    ```python Python
    import requests

    BASE_URL = "https://api.vaquill.ai/api/v1/us"
    HEADERS = {
        "Authorization": "Bearer vq_key_...",
        "Content-Type": "application/json",
    }

    # Exactly what the model needs to answer and cite, and nothing else.
    # An unknown name here is rejected with 422, so a typo cannot silently
    # drop a field you were relying on.
    TOOL_FIELDS = [
        "title",
        "excerpt",
        "govInfoHtmlUrl",
        "stateHtmlUrl",
        "htmlUrl",
    ]

    def search_statutes(
        query: str,
        corpus_type: str | None = None,
        state: str | None = None,
        limit: int = 5,
    ) -> list[dict]:
        """Search US statutes and regulations. Returns cited results."""
        payload: dict = {"query": query, "limit": limit, "fields": TOOL_FIELDS}
        if corpus_type:
            payload["corpusType"] = corpus_type
        if state:
            payload["state"] = state

        resp = requests.post(
            f"{BASE_URL}/statutes/search", headers=HEADERS, json=payload
        )
        resp.raise_for_status()

        # best_source_url(): the canonical order from Text formats and source URLs
        # (linked below). Copy it once; do not re-derive the field order.
        return [
            {
                "actId": r.get("actId"),
                "citation": r.get("citation"),
                "title": r.get("title"),
                "excerpt": r.get("excerpt"),
                "sourceUrl": best_source_url(r),
            }
            for r in resp.json()["results"]
        ]
    ```

    `best_source_url()` uses the order in [Text formats and source URLs](/api-guide/concepts/formats#picking-the-best-available-format).
  </Step>

  <Step title="Declare the tool schema">
    Give the model a schema (a name, a description, and a JSON Schema for parameters) so it knows when and how to call the function.

    ```python Python
    SEARCH_STATUTES_TOOL = {
        "name": "search_statutes",
        "description": (
            "Search US statutes and regulations (US Code, CFR, state codes, "
            "constitutions, court rules, and more). Use for any question about "
            "what the law says. Returns citations, excerpts, and source links."
        ),
        "parameters": {
            "type": "object",
            "properties": {
                "query": {
                    "type": "string",
                    "description": "Natural language question or keywords.",
                },
                # Tool argument corpus_type maps to the API's corpusType.
                # See Corpus types for every valid value.
                "corpus_type": {
                    "type": "string",
                    "description": (
                        "Optional corpus filter, e.g. USC, CFR, STATE, "
                        "REGULATION. Omit to search everything."
                    ),
                },
                "state": {
                    "type": "string",
                    "description": "Optional 2-letter lowercase state code, e.g. ca.",
                },
            },
            "required": ["query"],
        },
    }
    ```
  </Step>

  <Step title="Dispatch the call and keep answers grounded">
    When the model calls `search_statutes`, run the function and return the cited results. The wiring depends on your framework.

    ```python Python
    def dispatch_tool_call(name: str, arguments: dict) -> list[dict]:
        if name == "search_statutes":
            return search_statutes(
                query=arguments["query"],
                corpus_type=arguments.get("corpus_type"),
                state=arguments.get("state"),
            )
        raise ValueError(f"Unknown tool: {name}")
    ```

    Tell the model to cite `citation` and link `sourceUrl` for every legal claim, and to say so when nothing matches.
    See [Ground an LLM answer (RAG)](/api-guide/recipes/rag-grounding) for the prompt.
  </Step>
</Steps>

<Tip>
  For heavy agent traffic, cache the `/us/statutes/coverage` response and use it to set `corpusType` and `state` on tool calls.
</Tip>
