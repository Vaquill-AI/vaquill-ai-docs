**What this gets you:** an AI assistant that answers legal questions from statute text instead of its own memory.
Each claim carries a citation and a link to the official source, so users can check it.

You retrieve the governing sections, pull their full text, and pass it to an LLM in your stack with strict rules: answer only from the sources, cite every claim, link to the official source.
This is the standard retrieve-then-ground (RAG) loop, and the model can only draw on text you supplied.

**Endpoints used:** `POST /us/statutes/search` (retrieve), `GET /us/statutes/section/{actId}/body` (full text).

The text and links come from Vaquill AI and the reasoning from your LLM.
Vaquill AI does not replace a lawyer or a licensed research service, so carry the official link on every answer.

## The pattern in four steps

1. **Retrieve.**
   `POST /us/statutes/search` with the user question.
   Scope with `corpusType` and `state` when you know them (`USC` for federal statutes, or `STATE` with `state: "ca"`).
   Take the top few results.
2. **Fetch full text.**
   Search returns an `excerpt` of 500 characters by default (raisable to 600 with `excerptChars`), which is enough to rank but not to ground on.
   Call `GET /us/statutes/section/{actId}/body` for each result you cite and use the complete `plain` text.
3. **Build a grounded prompt.**
   Label each section with its `citation` and official source URL.
   Tell the model to answer only from those sources, cite each claim, and say so when the sources do not support an answer.
4. **Answer with links.**
   Return the answer plus the cited sources, each linking to the official text through `sourceUrl`, which every section carries when we hold an official link.

`includeBody` collapses steps 1 and 2 into one call: see the one-call tab below.

## Step 1 and 2: retrieve, then fetch full text

# 1. Retrieve candidate sections (scope to USC when the question is federal)
curl -X POST https://api.vaquill.ai/api/v1/us/statutes/search \
  -H "Authorization: Bearer $VAQUILL_API_KEY" \
  -H "Content-Type: application/json" \

```python Python
import os

import requests

BASE = "https://api.vaquill.ai/api/v1/us"
HEADERS = {"Authorization": f"Bearer {os.environ['VAQUILL_API_KEY']}"}


def search(query, corpus_type=None, state=None, limit=3):
    body = {"query": query, "limit": limit}
    if corpus_type:
        body["corpusType"] = corpus_type
    if state:
        body["state"] = state
    resp = requests.post(f"{BASE}/statutes/search", headers=HEADERS, json=body)
    resp.raise_for_status()
    return resp.json()["results"]


def fetch_body(act_id):
    resp = requests.get(f"{BASE}/statutes/section/{act_id}/body", headers=HEADERS)
    resp.raise_for_status()
    data = resp.json()
    if not data.get("available"):
        return None
    return data.get("plain") or data.get("html")
```

```python Python (one call)
# includeBody returns each hit's full text on `body` (null when unavailable).
def search_with_body(query, corpus_type=None, limit=3):
    body = {"query": query, "limit": limit, "includeBody": True}
    if corpus_type:
        body["corpusType"] = corpus_type
    resp = requests.post(f"{BASE}/statutes/search", headers=HEADERS, json=body)
    resp.raise_for_status()
    return [r for r in resp.json()["results"] if r.get("body")]
```

```javascript JavaScript
const BASE = "https://api.vaquill.ai/api/v1/us";
const HEADERS = {
  Authorization: `Bearer ${process.env.VAQUILL_API_KEY}`,
  "Content-Type": "application/json",
};

async function search(query, { corpusType, state, limit = 3 } = {}) {
  const body = { query, limit };
  if (corpusType) body.corpusType = corpusType;
  if (state) body.state = state;
  const resp = await fetch(`${BASE}/statutes/search`, {
    method: "POST",
    headers: HEADERS,
    body: JSON.stringify(body),
  });
  if (!resp.ok) throw new Error(`search failed: ${resp.status}`);
  return (await resp.json()).results;
}

async function fetchBody(actId) {
  const resp = await fetch(`${BASE}/statutes/section/${actId}/body`, {
    headers: { Authorization: HEADERS.Authorization },
  });
  if (!resp.ok) throw new Error(`body failed: ${resp.status}`);
  const data = await resp.json();
  if (!data.available) return null;
  return data.plain || data.html;
}
```

</CodeGroup>

The one-call version returns three grounded sources in one round trip instead of four.
It saves latency, not money: the cost is the search plus the ordinary body price per row that returns text, so it multiplies with `limit`.
Use the two-call version when you rank more candidates than you ground on.
[What a search costs](/api-guide/concepts/search#what-a-search-costs) defines `includeBody` billing.

## Step 3 and 4: build the grounded prompt and answer

The prompt is where grounding happens.
Give the model the retrieved text, a stable label per source, and rules it cannot skip: answer only from the sources, cite by citation and link, and refuse when the text does not support an answer.

```python Python
def build_grounded_prompt(question, sources):
    """sources: list of dicts with citation, source_url, and text."""
    blocks = []
    for i, s in enumerate(sources, start=1):
        blocks.append(
            f"[{i}] {s['citation']}\n"
            f"Source: {s['source_url']}\n"
            f"{s['text']}\n"
        )
    context = "\n---\n".join(blocks)
    return (
        "You are a careful legal research assistant. Answer the question using ONLY "
        "the numbered sources below. Do not use outside knowledge.\n\n"
        "Rules:\n"
        "1. Every factual claim must cite the source it comes from, using the "
        "citation and its Source link, e.g. (42 U.S.C. § 1983, "
        "https://uscode.house.gov/...).\n"
        "2. If the sources do not answer the question, say exactly: 'The provided "
        "sources do not answer this question.' Do not guess.\n"
        "3. Quote the statute's own words when the wording matters.\n"
        "4. End with a 'Sources' list that links each cited section to its "
        "official government text.\n\n"
        f"Sources:\n{context}\n\n"
        f"Question: {question}\n"
    )


def answer_question(question, corpus_type=None, state=None):
    results = search(question, corpus_type=corpus_type, state=state, limit=3)

    sources = []
    for r in results:
        text = fetch_body(r["actId"])
        if not text:
            continue  # skip sections whose text is unavailable
        source_url = best_source_url(r)
        sources.append(
            {
                "citation": r.get("citation") or r["actId"],
                "source_url": source_url,
                "text": text,
            }
        )

    if not sources:
        return "The provided sources do not answer this question."

    prompt = build_grounded_prompt(question, sources)
    return call_llm(prompt)  # placeholder: your LLM call, prompt string in, answer text out


def best_source_url(result):
    # First non-null link in the order sourceUrl, htmlUrl, textUrl, externalUrl.
    # The full order is under Related, "Pick the best source URL".
    for field in ("sourceUrl", "htmlUrl", "textUrl", "externalUrl"):
        if result.get(field):
            return result[field]
    return None


if __name__ == "__main__":
    print(answer_question(
        "What must a plaintiff show for a civil rights claim against a state official?",
        corpus_type="USC",
    ))
```

## Scope

<Accordion title="Scope narrows retrieval, and narrow retrieval grounds better">
  When you know the question is federal, pass `corpusType: "USC"` or `"CFR"`.
  When it is about one state, pass `corpusType: "STATE"` with the two-letter `state` code.

  Tighter scope means the top results are more likely to be the governing sections, which makes the grounded answer more precise.
  Omit both to search the whole corpus.
</Accordion>

Why this holds up, and why the model cannot cite what it was not given: [Grounding LLMs](/api-guide/grounding-llms).
