Build a chatbot that answers "what does the law say" questions from statute text and a source link.

Each user message runs one search, gets the best section's text, and returns an answer with a link to the official source. It works in Slack, Discord, a web widget or a terminal.

**Endpoints:** `POST /us/statutes/search`, `GET /us/statutes/section/{actId}/body`.

[Ground an LLM answer in statutes](/api-guide/recipes/rag-grounding) covers multi-source answers and prompt design.
To answer in one call, pass `"includeBody": true` with `"limit": 1`. The price is the same.
Keep the two-call version below if you rank three candidates and ground on one.

## The loop

<Steps>
  <Step title="Search on the user's message">
    Send the message to `POST /us/statutes/search`.
    Scope with `corpusType` and `state` if your bot already knows the jurisdiction.
  </Step>
  <Step title="Pull the best section's text">
    Take the top result and fetch its full text with `GET /us/statutes/section/{actId}/body`.
  </Step>
  <Step title="Reply, grounded and cited">
    Give an LLM the section text and citation. Have it answer only from that text.
    Add the official source link.
  </Step>
</Steps>

## The full chatbot in one function

```python Python
import os

import requests

BASE = "https://api.vaquill.ai/api/v1/us"
HEADERS = {"Authorization": f"Bearer {os.environ['VAQUILL_API_KEY']}"}


def find_section(message, state=None, corpus_type="STATE"):
    body = {"query": message, "limit": 3}
    if corpus_type:
        body["corpusType"] = corpus_type
    if state:
        body["state"] = state
    resp = requests.post(f"{BASE}/statutes/search", headers=HEADERS, json=body)
    resp.raise_for_status()
    results = resp.json()["results"]
    return results[0] if results else None


def section_text(act_id):
    resp = requests.get(f"{BASE}/statutes/section/{act_id}/body", headers=HEADERS)
    resp.raise_for_status()
    data = resp.json()
    return data.get("plain") if data.get("available") else None


def answer(message, state=None):
    hit = find_section(message, state=state)
    if not hit:
        return "I could not find a statute on that. Try rephrasing your question."

    text = section_text(hit["actId"])
    if not text:
        return "I found a matching section but its text is not available right now."

    citation = hit.get("citation") or hit["actId"]
    # sourceUrl is the official link; the fallback order is under Related.
    source_url = hit.get("sourceUrl")

    prompt = (
        "Answer the user's question using ONLY the statute text below. "
        "If it does not answer the question, say you could not find it. "
        "Cite the statute by its citation in your answer.\n\n"
        f"Citation: {citation}\n"
        f"Statute text:\n{text}\n\n"
        f"Question: {message}\n"
    )
    reply = call_llm(prompt)  # placeholder: your LLM call, prompt string in, text out
    return f"{reply}\n\nSource: {citation}\n{source_url}"


# Plain terminal loop. Replace input()/print() with your Slack, Discord,
# or web handler and the rest is unchanged.
if __name__ == "__main__":
    while True:
        message = input("You: ")
        if message.strip().lower() in {"quit", "exit"}:
            break
        print("Bot:", answer(message, state="ca"))
```

To use the loop in Slack or Discord, call `answer()` from your message handler and post the result.

## Tips

<AccordionGroup>
  <Accordion title="Set the jurisdiction once">
    If your bot serves one state, pass `state` on every search.
    If users can switch states, pass the two-letter state code from the conversation.
    Omit `corpusType` and `state` to search all US law.
  </Accordion>
  <Accordion title="Handle the empty case">
    When search returns nothing or the body is unavailable, say so, as `answer()` does above.
  </Accordion>
</AccordionGroup>
