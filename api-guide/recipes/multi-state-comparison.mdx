Build a multi-state comparison table for a rule, such as security deposits, non-competes or breach notice.

There are three ways to do it. Cost differs a lot, so start at the top.

| Approach | Calls | Credits | Gives you |
|---|---|---|---|
| `GET /us/statutes/section/{actId}/cross-state` | 1 | 6 | At most one provision per state, most similar first, up to 25 states |
| `POST /us/statutes/search` with `state` as a list | 1 | 4 | One merged ranking across the states you named |
| One search per state | 1 per state | 4 per state, so 200 for the 50 states | A guaranteed top hit for each state, including the ones with no strong match |

Current prices are at [`GET /api-credits/pricing`](/api-reference/pricing/get-api-credit-pricing). `creditsConsumed` on each response shows what the call billed.

**Endpoints:** `GET /us/statutes/section/{actId}/cross-state`, `POST /us/statutes/search`, and `GET /us/statutes/coverage` (free) to see which jurisdictions have the corpus.

## Best: start from one section you already have

If you can name the provision in one state, `cross-state` finds its analogue in other states.
It returns at most one provision per state, most similar first.

<CodeGroup>
```bash cURL
curl -G https://api.vaquill.ai/api/v1/us/statutes/section/STATE_CA_Cciv_D3_P4_T5_C2_S1950.5/cross-state \
  -H "Authorization: Bearer $VAQUILL_API_KEY" \
  --data-urlencode "limit=10"
```

```python Python
import os

import requests

BASE_URL = "https://api.vaquill.ai/api/v1/us"
HEADERS = {"Authorization": f"Bearer {os.environ['VAQUILL_API_KEY']}"}


def cross_state(act_id: str, limit: int = 10) -> list[dict]:
    resp = requests.get(
        f"{BASE_URL}/statutes/section/{act_id}/cross-state",
        headers=HEADERS,
        params={"limit": limit},
    )
    resp.raise_for_status()
    data = resp.json()
    # Each neighbor is {"state", "similarity", "section"}, most similar first,
    # at most one per state. `statesCovered` says how many states are here.
    for n in data["neighbors"]:
        state = n["state"].upper()
        citation = n["section"]["citation"]
        print(f"{state:4} {n['similarity']:.2f}  {citation}")
    return data["neighbors"]
```

```javascript JavaScript
const BASE_URL = "https://api.vaquill.ai/api/v1/us";

async function crossState(actId, limit = 10) {
  const url = new URL(`${BASE_URL}/statutes/section/${actId}/cross-state`);
  url.searchParams.set("limit", String(limit));
  const resp = await fetch(url, {
    headers: { Authorization: `Bearer ${process.env.VAQUILL_API_KEY}` },
  });
  if (!resp.ok) throw new Error(`cross-state failed: ${resp.status}`);
  const data = await resp.json();
  // data.neighbors: [{ state, similarity, section }], most similar first.
  return data.neighbors;
}
```
</CodeGroup>

Take the `actId` from a `/us/statutes/search` result. If you have none, run one search first.

<Note>
  `similarity` (0 to 1) means two provisions cover the same ground. It does not mean they impose the same obligation. Treat the response as a shortlist.
  `relevanceScore` on a search is a rank within one response. Do not compare it across responses.
</Note>

A trimmed response (`neighbors` is cut to one entry and can hold up to `limit`, at most 25):

```json
{
  "section": { "actId": "STATE_CA_Cciv_D3_P4_T5_C2_S1950.5", "citation": "Cal. Civ. Code § 1950.5" },
  "neighbors": [
    {
      "state": "ny",
      "similarity": 0.79,
      "section": { "citation": "N.Y. Gen. Oblig. Law § 7-108", "title": "..." }
    }
  ],
  "statesCovered": 1,
  "creditsConsumed": 6.0
}
```

`statesCovered` is how many other states were examined. `neighbors` can be shorter, because states with no same-subject provision are left out and `limit` caps the list.
Repealed and superseded text is not matched.
If `rankingDegraded` is true, the neighbors are in retrieval order, `matchQuality` is null, `note` explains, and the call is refunded (`creditsConsumed` 0).

<Note>
  `cross-state` works on state statute sections only.
  USC, CFR, regulations and court rules return an empty list with a `note`, and the call is refunded.
</Note>

## Next best: one search across several states

`state` accepts a list, so one call covers every state you name.
Use this when you have no starting section.

<CodeGroup>
```bash cURL
curl -X POST https://api.vaquill.ai/api/v1/us/statutes/search \
  -H "Authorization: Bearer $VAQUILL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "security deposit return deadline", "corpusType": "STATE", "state": ["ca", "ny", "tx", "fl", "wa"], "limit": 25, "fields": ["title", "excerpt", "state", "stateHtmlUrl", "htmlUrl"]}'
```

```python Python
def search_states(query: str, states: list[str], limit: int = 25) -> list[dict]:
    resp = requests.post(
        f"{BASE_URL}/statutes/search",
        headers={**HEADERS, "Content-Type": "application/json"},
        json={
            "query": query,
            "corpusType": "STATE",
            "state": states,
            "limit": limit,
            # A result carries 40+ fields, most null on any row. Ask for the
            # handful the comparison table actually renders.
            "fields": ["title", "excerpt", "state", "stateHtmlUrl", "htmlUrl"],
        },
    )
    resp.raise_for_status()
    return resp.json()["results"]


def best_per_state(results: list[dict]) -> dict[str, dict]:
    """Keep the highest-ranked hit for each state."""
    best: dict[str, dict] = {}
    for r in results:  # already in rank order
        best.setdefault(r.get("state"), r)
    return best
```
</CodeGroup>

The merged ranking has no slot reserved per state.
Raise `limit` (up to 50) and group by each result's `state`. A missing state means "not in the top N", not "no such law".

<Accordion title="Fallback: one search per state">
Loop only when you need a result slot for every named state, including weak matches.
This takes one call per state (50 for the 50 states).

**1. Drop the states that do not have the corpus.**
`GET /us/statutes/coverage` is free. Read it once and cache it.

```python Python
def states_with_corpus(token: str = "STATE") -> list[str]:
    cov = requests.get(
        f"{BASE_URL}/statutes/coverage", headers=HEADERS
    ).json()["data"]
    return [
        j["code"]
        for j in cov["jurisdictions"]
        if j["kind"] == "state" and token in j.get("corpora", {})
    ]
```

**2. Search each state and build the table.**
Record states with no match so the gaps show.

```python Python
def compare_across_states(query: str, states: list[str]) -> list[dict]:
    rows: list[dict] = []
    for state in states:
        hits = search_states(query, [state], limit=3)
        top = hits[0] if hits else None
        rows.append(
            {
                "state": state,
                "citation": top.get("citation") if top else None,
                "excerpt": (top.get("excerpt") or "")[:200] if top else None,
                # best_source_url() is the shared helper linked under Related.
                "url": best_source_url(top) if top else None,
            }
        )
    return rows


if __name__ == "__main__":
    available = set(states_with_corpus("STATE"))
    targets = [s for s in ["ca", "ny", "tx", "fl", "wa"] if s in available]
    for row in compare_across_states("security deposit return deadline", targets):
        print(f"{row['state'].upper():4}  {row['citation'] or '(no match)'}")
```

Example output:

```text
CA    Cal. Civ. Code § 1950.5
NY    N.Y. Gen. Oblig. Law § 7-108
TX    Tex. Prop. Code § 92.103
```
</Accordion>
