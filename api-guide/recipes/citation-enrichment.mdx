description: "Batch-resolve a column of citations, search the topic-only rows, and attach a canonical citation, excerpt and official source URL"

Turn a spreadsheet of topics and rough citations into verified law. Each row gets a canonical citation and an official source link.

Rows with a citation need resolving. `POST /us/statutes/resolve` handles 50 per call.
Rows with only a topic need `POST /us/statutes/search`.

**Endpoints:** `POST /us/statutes/resolve` (up to 50 citations per call), `POST /us/statutes/search` for topic-only rows, and optionally `GET /us/statutes/section/{actId}/body` for full text.

<Warning>
  Batching keeps you inside your plan's rate limits: 500 citations is 10 resolve calls.
  Honor the `Retry-After` header on a `429`. See [Errors](/api-guide/errors).
</Warning>

## Start with the rows that carry a citation

Split the citation column into batches of 50 and resolve them.
Every input gets an entry back, in order, so unresolved rows are flagged.

```python Python
import requests

BASE_URL = "https://api.vaquill.ai/api/v1/us"
HEADERS = {
    "Authorization": "Bearer vq_key_...",
    "Content-Type": "application/json",
}

BATCH_SIZE = 50  # the API's per-call maximum


def resolve_citations(citations: list[str]) -> dict[str, dict | None]:
    """Map each input citation to its resolved section, or None."""
    out: dict[str, dict | None] = {}
    for i in range(0, len(citations), BATCH_SIZE):
        chunk = citations[i : i + BATCH_SIZE]
        resp = requests.post(
            f"{BASE_URL}/statutes/resolve", headers=HEADERS, json={"citations": chunk}
        )
        resp.raise_for_status()
        for item in resp.json()["results"]:
            out[item["inputCitation"]] = item["section"] if item["resolved"] else None
    return out
```

Set `state` or `corpusType` when every row belongs to one jurisdiction or corpus. Omit both for mixed jurisdictions.

<Note>
  A resolved row has no `excerpt`, because resolving runs no query.
  Take the excerpt from search, or fetch the body for quotable text.
</Note>

## Then search the rows that are only a topic

Search the rows with no citation.
Set `corpusType` and `state` where you know them. Use `fields` to return only what you write back.

```python Python
INPUTS = [
    {"topic": "civil rights deprivation under color of law", "corpusType": "USC"},
    {"topic": "security deposit return deadline", "corpusType": "STATE", "state": "ca"},
    {"topic": "hazard communication standard", "corpusType": "CFR"},
]

# Ask for only the fields you store (see Best practices).
# `actId` and `citation` always come back.
ENRICH_FIELDS = ["title", "excerpt", "state", "govInfoHtmlUrl", "stateHtmlUrl", "htmlUrl"]


def search_topic(item: dict) -> dict | None:
    payload = {"query": item["topic"], "limit": 3, "fields": ENRICH_FIELDS}
    for key in ("corpusType", "state"):
        if key in item:
            payload[key] = item[key]
    resp = requests.post(
        f"{BASE_URL}/statutes/search", headers=HEADERS, json=payload
    )
    resp.raise_for_status()
    results = resp.json()["results"]
    return results[0] if results else None
```

Use `matchType: "phrase"` when the topic column holds a defined term or statutory phrase. It matches the exact phrase instead of using hybrid semantic ranking.

## Attach the source link and write the row back

Source URL fields can be null. Pick the link with the `best_source_url()` order in [Text formats and source URLs](/api-guide/concepts/formats#picking-the-best-available-format).

```python Python
# best_source_url() is the shared helper from the page linked above.
# Copy it once and reuse it; do not re-derive the field order per recipe.


def enrich(rows: list[dict]) -> list[dict]:
    """rows: dicts with either a 'citation' or a 'topic' key."""
    cited = [r["citation"] for r in rows if r.get("citation")]
    resolved = resolve_citations(cited)

    enriched = []
    for row in rows:
        if row.get("citation"):
            match = resolved.get(row["citation"])
        else:
            match = search_topic(row)

        enriched.append(
            {
                **row,
                "actId": match.get("actId") if match else None,
                "canonicalCitation": match.get("citation") if match else None,
                "excerpt": match.get("excerpt") if match else None,
                "sourceUrl": best_source_url(match) if match else None,
            }
        )
    return enriched
```

Example output:

```text
42 USC 1983
  -> 42 U.S.C. § 1983  https://...

security deposit return deadline
  -> Cal. Civ. Code § 1950.5  https://...

42 U.S.C. 19833
  -> (unresolved, flag for review)
```

On an unresolved item, read `missReason` and `candidates` to see why it missed.

## Optionally attach full text

For the whole section, take the `actId` from a match and call `GET /us/statutes/section/{actId}/body` (see the [body endpoint](/api-guide/concepts/formats#text-from-the-body-endpoint)).
It returns text only when `available` is true, and is free otherwise.

```python Python
def fetch_body(act_id: str) -> str | None:
    resp = requests.get(
        f"{BASE_URL}/statutes/section/{act_id}/body",
        headers={"Authorization": HEADERS["Authorization"]},
    )
    resp.raise_for_status()
    data = resp.json()
    return data["plain"] if data.get("available") else None
```

<Accordion title="Cost and bookkeeping notes">

- Duplicates are collapsed before pricing. A citation on forty rows costs one resolution. Read `creditsConsumed` on the response.
- Fetch bodies only for rows that need quotable text. For a topic row, `"includeBody": true` on the search returns the text inline for the same 4 + 6 credits per row.
- Store the returned `actId` on your record. A later job can use it to re-fetch the section without searching again.

</Accordion>
