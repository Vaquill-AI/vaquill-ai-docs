Search US court decisions, read opinions and follow citations.
For totals and court codes, see [Case law coverage](/api-guide/coverage/case-law).

A **case** is one decision. It can have several **opinions**, such as a majority and a dissent.

## Quickstart

Look up a citation, read the opinion, then list the cases that cite it.
The three calls cost 9 credits ($0.09). You need an [API key](/api-guide/authentication).

<CodeGroup>

```python Python
import os
import requests

API = "https://api.vaquill.ai/api/v1/us"
HEADERS = {"Authorization": f"Bearer {os.environ['VAQUILL_API_KEY']}"}


def call(method, path, **kwargs):
    resp = requests.request(method, f"{API}{path}", headers=HEADERS, timeout=60, **kwargs)
    resp.raise_for_status()
    return resp.json()


# 1. Citation to case (2 credits)
found = call("POST", "/cases/resolve", json={"citations": ["347 F.3d 1000"]})["results"][0]
if found["status"] != "resolved":
    raise SystemExit(found["status"])
case = found["case"]

# 2. Main opinion (6 credits)
if case["leadOpinionId"]:
    opinion = call("GET", f"/opinions/{case['leadOpinionId']}", params={"format": "text"})
    print(opinion["body"][:500])

# 3. Cases that cite it (1 credit)
citing = call("GET", f"/cases/{case['caseId']}/citations", params={"limit": 5})
for row in citing["results"]:
    print(row["case"]["caseName"])
```

```bash cURL
API=https://api.vaquill.ai/api/v1/us
AUTH="Authorization: Bearer $VAQUILL_API_KEY"

# 1. Citation to case (2 credits)
curl -X POST "$API/cases/resolve" -H "$AUTH" \
  -H "Content-Type: application/json" \
  -d '{"citations": ["347 F.3d 1000"]}'

# Copy caseId and leadOpinionId from that response.
CASE_ID="USCASE_..."
OPINION_ID="USOP_..."

# 2. Main opinion (6 credits)
curl "$API/opinions/$OPINION_ID?format=text" -H "$AUTH"

# 3. Cases that cite it (1 credit)
curl "$API/cases/$CASE_ID/citations?limit=5" -H "$AUTH"
```

</CodeGroup>

Citing lists for landmark cases can time out with a `503`. You are not charged. Retry after a few seconds.

## Before you build

- **Empty pages cost credits.** Failed lookups (`404`), bad requests (`422`) and server errors do not.
- **Paging differs.** `/cases/list` and `/cases/changes` use `cursor`. Other lists use `offset`, up to 10,000.
- **Some cases are left out of search.** You can still get them by id or citation.
- **Withdrawn cases return `410`.** This covers privacy, sealed cases and legal orders.
- **Some cases appear twice or more.** Match on citation and docket number before you count or display them.
- **Some old dates are wrong.** Check `decisionDate` against the citation before you rely on it.
- **Scans can have errors.** Check quotes when `textFromOcr` is `true`.
- **Retries can be free.** Send an `Idempotency-Key` of 16 to 255 characters with no spaces, such as a UUID. It works for 24 hours.

## Keep a copy in sync

`GET /cases/changes` returns case ids that changed after `since`, oldest first.

- `upsert`: fetch the case again.
- `removed`: take it out of your synced copy. It was withdrawn or taken out of search. See [withdrawn cases](/api-guide/rights-and-licensing#withdrawn-cases).

Save `asOf` after a full run and send it as the next `since`.

```python Python
import os
import requests

URL = "https://api.vaquill.ai/api/v1/us/cases/changes"
HEADERS = {"Authorization": f"Bearer {os.environ['VAQUILL_API_KEY']}"}


def sync(since, handle):
    params = {"since": since, "limit": 100}
    while True:
        resp = requests.get(URL, headers=HEADERS, params=params, timeout=60)
        resp.raise_for_status()
        page = resp.json()
        for row in page["results"]:
            handle(row)
        if not page["hasMore"]:
            return page["asOf"]
        params["cursor"] = page["nextCursor"]
```

<Warning>
  Start from a recent date.
  Reading the whole feed takes 100,000+ credits ($1,000+) and returns ids only.
  Add `courtId` to follow one court.
</Warning>
