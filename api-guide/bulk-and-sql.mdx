The API answers one question at a time.
For the corpus itself, use the bulk files.

Every dated snapshot ships as Parquet in a public object store.
You can query it in place, load it into your own warehouse, or download all of it.

```sql
-- Runs as-is. No key, no download, no signup.
INSTALL httpfs; LOAD httpfs;

SELECT citation, word_count, text
FROM read_parquet('https://oss-data-us.vaquill.ai/v2026.09.1/us_ak_constitutions.parquet')
WHERE text ILIKE '%unreasonable searches%';
```

## What ships

One Parquet file per jurisdiction and corpus, such as `us_ak_constitutions.parquet` or `us_tx_statutes.parquet`.
Versions are immutable. Pin `v2026.09.1` to keep results reproducible.

| Resource | URL | Notes |
|---|---|---|
| Manifest | `https://oss-data-us.vaquill.ai/index.json` | Lists every file with its byte size, SHA-256 and URL. |
| Browsable index | `https://oss-data-us.vaquill.ai/index.html` | |
| Per-corpus files | `https://oss-data-us.vaquill.ai/v2026.09.1/us_ak_constitutions.parquet` | 308 Parquet files in `v2026.09.1`. |
| Combined tarball | `https://oss-data-us.vaquill.ai/v2026.09.1/open-us-law-v2026.09.1-parquet.tar` | About 6.9 GB in `v2026.09.1`. |
| Canonical mirror | [Hugging Face](https://huggingface.co/datasets/vaquill/open-us-law) | |
| Source code | [GitHub](https://github.com/Vaquill-AI/open-us-law) | |

## Schema

Every Parquet file carries the same 27 columns.
`official_status`, `currency_note` and `adopting_citations` are null for most rows.

<Accordion title="All 27 columns">

| Column | Type | What it holds |
|---|---|---|
| `act_id` | VARCHAR | Stable identifier for the provision. See [Section IDs](/api-guide/concepts/section-ids). |
| `citation` | VARCHAR | Full form |
| `citation_short` | VARCHAR | Abbreviated form |
| `state` | VARCHAR | Two-letter code, null for federal |
| `jurisdiction` | VARCHAR | Name |
| `document_type` | VARCHAR | Corpus type. See [Corpus types](/api-guide/concepts/corpus-types). |
| `title_number` | VARCHAR | Title or code number |
| `title_name` | VARCHAR | Title or code name |
| `chapter` | VARCHAR | Number |
| `chapter_name` | VARCHAR | Name |
| `section_number` | VARCHAR | Number |
| `section_title` | VARCHAR | Heading |
| `breadcrumb` | VARCHAR | Full hierarchy path |
| `display_path` | VARCHAR | Human-readable path |
| `act_status` | VARCHAR | `in_force`, `repealed`, `reserved`, and related states |
| `text` | VARCHAR | The provision text |
| `word_count` | BIGINT | Words in `text` |
| `source_url` | VARCHAR | The official publisher page this came from |
| `last_amended_year` | BIGINT | Most recent amendment year |
| `subsection_count` | BIGINT | Subsections parsed |
| `cross_references_usc` | VARCHAR | US Code sections this provision cites |
| `cross_references_cfr` | VARCHAR | CFR sections this provision cites |
| `public_laws_referenced` | VARCHAR | Public laws this provision cites |
| `year` | BIGINT | Snapshot year |
| `official_status` | VARCHAR | The publisher's own label for the copy. Null means unlabelled. |
| `currency_note` | VARCHAR | The publisher's own "current through" line |
| `adopting_citations` | VARCHAR[] | Instruments that adopted or amended the rule (register citations, adopting orders, session laws) |

</Accordion>

## Load it into your own database

<CodeGroup>

```sql DuckDB
-- Whole corpus into a local database file. Globs are not supported over plain
-- HTTPS, so read the file list out of the manifest and pass it as an array.
INSTALL httpfs; LOAD httpfs; INSTALL json; LOAD json;

CREATE TABLE law AS
SELECT * FROM read_parquet(
  (SELECT list(f.url)
   FROM (SELECT unnest(files) AS f
         FROM read_json_auto('https://oss-data-us.vaquill.ai/index.json'))
   WHERE f.file LIKE '%.parquet')
);
```

```sql Postgres
-- After downloading the tarball and unpacking
CREATE TABLE law (
  act_id text PRIMARY KEY, citation text, citation_short text,
  state text, jurisdiction text, document_type text,
  title_number text, title_name text, chapter text, chapter_name text,
  section_number text, section_title text, breadcrumb text, display_path text,
  act_status text, text text, word_count bigint, source_url text,
  last_amended_year bigint, subsection_count bigint,
  cross_references_usc text, cross_references_cfr text,
  public_laws_referenced text, year bigint,
  official_status text, currency_note text, adopting_citations text[]
);
-- then COPY from a Parquet-aware loader, or convert with DuckDB first
```

```bash Verify a sync
curl -s https://oss-data-us.vaquill.ai/index.json \
  | jq -r '.files[] | select(.file|endswith(".parquet")) | "\(.sha256)  \(.file)"' \
  > SHA256SUMS
shasum -a 256 -c SHA256SUMS
```

</CodeGroup>
