Each row below links to a runnable recipe. Pick the one closest to your goal.

If you are new, start with the [Quickstart](/api-guide/quickstart).
The endpoint list is on the [API overview](/api-guide/overview), and live credit prices are on the [pricing endpoint](/api-reference/pricing/get-api-credit-pricing).

| What you are building | Start from |
|---|---|
| An assistant that answers legal questions and quotes the section it relied on | [Statute chatbot](/api-guide/recipes/statute-chatbot) |
| RAG or an agent that must cite real law instead of guessing | [RAG grounding](/api-guide/recipes/rag-grounding) |
| A check that a citation or quoted passage is real before you ship it | [Citation lookup](/api-guide/recipes/citation-lookup) |
| The exact text of the subsection a citation names, with no parsing | [Get one subsection](/api-guide/recipes/pinpoint-subsection) |
| A map from a control, policy or obligation to the law behind it | [Compliance mapping](/api-guide/recipes/compliance-mapping) |
| The same question run across several states, lined up side by side | [Multi-state comparison](/api-guide/recipes/multi-state-comparison) |
| A backfill of an existing citation table with text, metadata and source links | [Citation enrichment](/api-guide/recipes/citation-enrichment) |
| Statute lookup exposed to an agent as callable tools | [MCP tool](/api-guide/recipes/mcp-tool) |
| A watch on what is queryable, and on how it grows | [Coverage monitoring](/api-guide/recipes/coverage-monitoring) |
| A webhook or email when a jurisdiction or corpus actually changes | [Law Change Alerts](/api-guide/alerts) |
