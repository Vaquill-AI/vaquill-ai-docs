The Vaquill Data API searches and retrieves the US Code, the Code of Federal Regulations, all 50 state statutory codes plus DC and Puerto Rico, state and US constitutions, court rules, executive orders, Federal Register agency rules, and agency guidance.

Every section comes back with a citation, status and currency signals, full text in more than one format, and a link to the official government source.
Typical uses are grounding AI (RAG and agents), compliance and RegTech work, and putting authoritative legal text inside your own product.

**Start here:** the [Quickstart](/api-guide/quickstart) makes a first call, and [Authentication](/api-guide/authentication) covers keys.
To pick a recipe by what you are building, see [Use cases](/api-guide/use-cases).

## Capabilities

Every path is prefixed with `/api/v1`.

| Capability | Endpoint |
|---|---|
| Hybrid semantic and keyword search, scoped by corpus, jurisdiction, and code. `includeBody: true` returns each hit's text in the same call | `POST /us/statutes/search` |
| Resolve a Bluebook citation to its exact section | `GET /us/statutes/resolve` |
| Browse the hierarchy (titles to chapters or parts to sections) in statutory order | `GET /us/statutes/divisions` |
| Section metadata, full text, and neighboring sections | `GET /us/statutes/section/{actId}`, `.../body`, `.../related` |
| Defined terms resolved from the chapter's definitions section | `GET /us/statutes/section/{actId}/definitions` |
| The same subject in other states, for a 50-state survey | `GET /us/statutes/section/{actId}/cross-state` |
| Sections that cite this one, and observed changes to it | `GET /us/statutes/section/{actId}/cited-by`, `.../changes` |
| Batch metadata for up to 50 sections in one call | `POST /us/statutes/sections` |
| Live coverage: which jurisdictions hold which corpora | `GET /us/statutes/coverage` |
| State session laws as enacted: list by state and date, search the text, fetch by id or citation, read the text | `GET /us/session-laws/list`, `POST /us/session-laws/search`, `GET /us/session-laws/{sessionLawId}`, `.../body` |
| Subscribe to a jurisdiction or corpus and get a webhook or email when it changes, section by section, with before/after text on amendments | `GET /boards`, `POST /watches`, `GET /watches/{id}/changes`, `.../diff` |

<Accordion title="Search with includeBody">
  `POST /us/statutes/search` accepts `includeBody: true`, which attaches each hit's full text on the result's `body` instead of making you call `/section/{actId}/body` once per hit.
  A row whose text cannot be resolved comes back with `body: null` and is not charged.
  This saves round trips. It does not lower the cost of the rows that return text.
</Accordion>

### Corpora

Scope any search with the `corpusType` token. [Corpus types](/api-guide/concepts/corpus-types) lists what each holds.

| Scope | `corpusType` | What it is |
|---|---|---|
| Federal | `USC` | US Code |
| Federal | `CFR` | Code of Federal Regulations |
| Federal | `CFR_ANNUAL` | CFR annual editions |
| Federal | `FEDERAL_REGISTER` | Federal Register agency rules |
| Federal | `FEDERAL_REGISTER_NOTICE` | A curated slice of Federal Register notices |
| Federal | `AGENCY_GUIDANCE` | Agency guidance |
| Federal | `EXECUTIVE_ACTION` | Executive orders |
| Federal | `FEDERAL_RULES` | Federal Rules of Procedure |
| Federal | `FEDERAL_LOCAL_RULES` | Local rules of federal courts |
| Federal | `CONSTITUTION` | US Constitution |
| Federal | `SESSION_LAW` | Session laws as enacted |
| Federal | `STATUTE_COMPILATION` | Statute compilations as amended |
| Federal | `SENTENCING_GUIDELINES` | US Sentencing Guidelines |
| Federal | `AGENCY_ADJUDICATION` | Administrative adjudications |
| Federal | `US_TAX_TREATY` | US income tax treaties and their Treasury explanations |
| Federal | `US_TREATY` | Senate treaty record, including resolutions of advice and consent |
| State, across 56 jurisdictions | `STATE` | Statutory codes |
| State | `REGULATION` | Administrative regulations |
| State | `STATE_CONSTITUTION` | Constitutions |
| State | `STATE_RULES` | Court rules |
| State | `STATE_REGISTER` | State register notices (not codified law) |
| State | `STATE_AGENCY_GUIDANCE` | State regulator guidance (insurance bulletins), not itself law |

State session laws cover the 50 states, DC and Puerto Rico, sessions from 1975, and are served by `/us/session-laws` rather than a `corpusType`.
Coverage is partial for many sessions, and `GET /us/statutes/coverage` reports it live.
See [State session laws](/api-guide/session-laws).

<Note>
  Coverage expands weekly. Call `/us/statutes/coverage` at runtime to see exactly what is queryable rather than hardcoding jurisdiction counts.
</Note>
